# 开发工具配置速查手册

> 本文整理常见开发工具的安装、配置和常用命令，包括 JetBrains 配置清理、Git、Docker、Scrapy、OpenClaw、ClawHub 等内容。  
> 涉及许可证、Token、API Key 等敏感信息时，请使用自己的合法授权和私有密钥，不要在文档或仓库中保存明文密钥。

## 1. JetBrains 配置清理

### 1.1 清理旧配置目录

#### Windows

配置目录：

```text
C:\Users\你的系统用户名\AppData\Roaming\JetBrains
```

可以删除不再使用的旧版本配置文件夹，例如：

```text
IntelliJIdea2024.x
WebStorm2024.x
PyCharm2024.x
```

---

#### macOS

配置目录：

```text
/Users/你的用户名/Library/Application Support/JetBrains
```

终端快速打开：

```bash
open ~/Library/Application\ Support/JetBrains
```

---

### 1.2 清理旧 VM Options 中的 javaagent 配置

如果曾经修改过 JetBrains 的 VM Options，建议检查并删除异常的 `javaagent` 配置。

#### 情况 A：软件能正常打开

操作步骤：

```text
1. 打开 JetBrains 软件
2. 菜单栏选择 Help
3. 点击 Edit Custom VM Options
4. 删除所有包含 javaagent 的行
5. 保存
6. 完全退出并重启软件
```

---

#### 情况 B：软件无法打开

可以直接编辑本地 `.vmoptions` 文件。

Windows 示例路径：

```text
C:\Users\你的用户名\AppData\Roaming\JetBrains\IntelliJIdea2026.1\idea.exe.vmoptions
```

macOS 示例路径：

```text
/Users/用户名/Library/Application Support/JetBrains/IntelliJIdea2026.1/idea.vmoptions
```

删除其中包含 `javaagent` 的行后，重新启动软件。

## 2. Git 配置

### 2.1 全局 Git 基础配置

```bash
git config --global user.name "你的用户名"
git config --global user.email "你的邮箱"
git config --global init.defaultBranch main
```

查看配置：

```bash
git config --global --list
```

---

### 2.2 生成 SSH 密钥

使用 Ed25519 算法生成 SSH Key：

```bash
ssh-keygen -t ed25519 -C "你的邮箱"
```

一路回车即可。

查看并复制公钥：

```bash
cat ~/.ssh/id_ed25519.pub
```

将输出内容复制到：

```text
GitHub → Settings → SSH and GPG keys
Gitee  → 设置 → SSH 公钥
```

---

### 2.3 仓库远程地址操作

添加远程仓库：

```bash
git remote add gitee https://gitee.com/你的用户名/你的仓库名.git
```

推送所有分支：

```bash
git push gitee --all
```

查看远程仓库：

```bash
git remote -v
```

---

### 2.4 Git 代理配置

设置代理：

```bash
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897
```

取消代理：

```bash
git config --global --unset http.proxy
git config --global --unset https.proxy
```

查看代理是否生效：

```bash
git config --global --get http.proxy
git config --global --get https.proxy
```

## 3. Docker 安装与配置

### 3.1 下载 Docker Desktop

官网地址：

```text
https://www.docker.com/products/docker-desktop/
```

根据系统选择 Windows / macOS 版本下载。

---

### 3.2 Windows 安装注意事项

安装时建议勾选：

```text
Use WSL 2 instead of Hyper-V
```

安装完成后重启电脑。

---

### 3.3 初始化 Docker Desktop

第一次打开 Docker Desktop 时，可能会自动初始化环境。

常见步骤：

```text
1. 自动配置 WSL 2
2. 初始化 Docker 环境
3. 等待进入主界面
```

---

### 3.4 验证安装成功

打开 PowerShell 或终端：

```bash
docker --version
docker ps
```

如果没有报错，说明 Docker 已经可用。

---

### 3.5 一键安装 Redis

```bash
docker run -d --name redis -p 6379:6379 redis
```

查看容器运行状态：

```bash
docker ps
```

如果看到 `redis` 容器处于运行状态，即安装成功。

---

### 3.6 限制 Docker 虚拟磁盘大小

Docker Desktop 设置路径：

```text
Settings → Resources → Advanced
```

推荐配置：

```text
Memory：4 GB
CPU：2 核
Swap：1 GB
Disk image size：30 GB
```

修改后点击：

```text
Apply & restart
```

## 4. Scrapy 基础命令

### 4.1 创建 Scrapy 项目

```bash
scrapy startproject mySpider
```

命令格式：

```bash

```

---

### 4.2 创建爬虫

```bash
scrapy genspider baidu baidu.com
```

命令格式：

```bash
scrapy genspider 爬虫名 允许爬取的域名
```

---

### 4.3 启动爬虫

```bash
scrapy crawl baidu
```

注意：

```text
启动命令中的爬虫名称，需要和创建时设置的爬虫名称保持一致。
```

## 5. OpenClaw 操作指南

### 5.1 启动网关

旧版命令：

```bash
openclaw gateway --port 18789 --token "你的访问Token"
```

新版命令：

```bash
openclaw-cn gateway --port 18789 --token "你的访问Token"
```

说明：

```text
--port  指定本地网关端口
--token 指定访问令牌
```

访问地址格式：

```text
http://127.0.0.1:18789/?token=你的访问Token
```

---

### 5.2 打开配置

旧版命令：

```bash
openclaw config
```

新版命令：

```bash
openclaw-cn config
```

---

### 5.3 停止网关

旧版命令：

```bash
openclaw gateway stop
```

新版命令：

```bash
openclaw-cn gateway stop
```

---

### 5.4 再次启动网关

旧版命令：

```bash
openclaw gateway
```

新版命令：

```bash
openclaw-cn gateway
```

## 6. OpenClaw 彻底卸载步骤：macOS

### 6.1 停止并卸载自启动服务

```bash
sudo launchctl bootout gui/$(id -u)/ai.openclaw.gateway
```

说明：

```text
如果提示 Boot-out failed: 3: No such process，说明服务未运行，可以跳过。
如果提示权限错误，输入当前用户登录密码，不是 Apple ID 密码。
```

---

### 6.2 删除自启动配置文件

```bash
rm ~/Library/LaunchAgents/ai.openclaw.gateway.plist
rm ~/Library/LaunchAgents/com.openclaw.gateway.plist
```

说明：

```text
如果提示 No such file or directory，说明文件不存在或已删除，可以跳过。
```

---

### 6.3 删除运行数据和缓存

```bash
rm -rf ~/clawd
rm -rf ~/.openclaw
rm -rf ~/.config/openclaw
```

---

### 6.4 最终验证

```bash
ls ~/Library/LaunchAgents/ | grep -E "clawdbot|openclaw"
launchctl list | grep -E "clawdbot|openclaw"
```

如果没有输出相关内容，说明残留基本清理完成。

## 10. 安全注意事项

### 10.1 不要明文保存密钥

以下内容不要直接写进公开文档、代码仓库、截图或聊天记录：

```text
API Key
Access Token
Secret Key
SSH 私钥
数据库密码
网关 Token
中转服务 Token
```

---

### 10.2 已经暴露过的密钥要立即处理

如果 Token、API Key、私钥曾经出现在文档或聊天记录中，建议：

```text
1. 立即到对应平台撤销旧密钥
2. 重新生成新密钥
3. 更新本地配置
4. 检查是否提交到 Git 仓库
5. 如已提交，清理 Git 历史记录
```

---

### 10.3 推荐使用环境变量

例如：

```bash
export OPENROUTER_API_KEY="你的_OpenRouter_API_Key"
```

在代码或配置中读取环境变量，而不是硬编码密钥。
