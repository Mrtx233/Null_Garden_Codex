# Scrapy Official Document

## 项目定位

这是一个多项目 Scrapy 采集仓库，不是单一爬虫。仓库按业务域拆分多个独立项目，覆盖教育、民政、财政、司法、人社、科技、生态环境以及网易资讯等场景。

## 技术栈

- Python
- Scrapy
- MySQL
- Crawlab
- itemloaders

## 核心能力

- 面向政府公开信息网站的结构化采集
- 面向新闻和资讯站点的文章抓取
- 正文、附件、HTML 源码统一落盘
- 增量采集和日期过滤
- GUI 工具快速生成 Spider 模板

## 适合场景

适合持续维护多站点采集任务、调度到 Crawlab 或作为采集框架参考。
