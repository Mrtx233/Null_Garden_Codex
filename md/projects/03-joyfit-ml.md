# JoyFit 乐练健身管理系统

## 项目定位

JoyFit 以连锁健身品牌为业务背景，围绕游客、会员、教练、店长和管理员五类角色，提供内容展示、门店查询、动作库、课程库、论坛互动和后台主数据维护。

## 技术栈

- Java 17
- Spring Boot 3
- MyBatis
- Spring Security
- Vue 3
- Element Plus
- MySQL

## 核心能力

- 游客首页、门店地图、动作库、课程库、活动和论坛浏览
- 会员注册登录、收藏、个人中心、发帖和评论
- 店长排课、门店人员查看、同店信息维护
- 管理员对用户、门店、课程、动作、活动等基础数据的统一维护
- JWT、RBAC 和拦截器权限控制

## 适合场景

适合做健身行业信息化系统、毕业设计或前后端分离业务练习。
