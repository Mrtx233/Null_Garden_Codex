# UCan Football Management

## 项目定位

UCFM 面向平台管理员、俱乐部经理人和普通球员三类角色，提供首页展示、认证、俱乐部资料、成员管理、公告、训练计划、比赛信息、战术板和头像上传。

## 技术栈

- Java 17
- Spring Boot 3.5.12
- Spring Security
- MyBatis
- Vue 3
- Element Plus
- MySQL 8

## 核心能力

- 用户注册、登录、刷新 Token、退出登录
- 管理员后台数据看板和基础数据维护
- 经理人维护俱乐部资料、成员、训练和战术板
- 球员查看俱乐部公告、比赛和训练计划
- 头像上传与静态资源访问

## 适合场景

适合足球俱乐部管理系统、课程设计和 Java 全栈练习项目。
