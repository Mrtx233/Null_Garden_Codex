# CosVerse

## 项目定位

CosVerse 面向 Cosplay 场景，提供活动资讯、漫展宣传、服务市场、作品集展示、预约申请、档期管理、论坛浏览和后台数据维护。

## 技术栈

- Java 17
- Spring Boot 3.5.13
- Spring Security
- MyBatis
- Vue 3
- Element Plus
- MySQL

## 核心能力

- 公共前台内容展示和服务浏览
- 用户注册登录和个人预约管理
- 服务者作品集、档期和预约处理
- 管理员对用户、服务、资讯和论坛数据维护
- JWT、权限和头像上传能力

## 适合场景

适合做二次元活动平台、服务预约平台或毕业设计展示项目。
