文件：`app/utils/auth.py`

```python
from functools import wraps

from flask import flash, redirect, request, session, url_for

from app.models import User


def get_current_user():
    user_id = session.get("user_id")
    if not user_id:
        return None
    return User.query.get(user_id)


def login_required(view_func):
    @wraps(view_func)
    def wrapper(*args, **kwargs):
        user = get_current_user()
        if not user:
            flash("请先登录后再访问后台。", "warning")
            return redirect(url_for("auth.login", next=request.full_path))
        if not user.is_active:
            session.clear()
            flash("当前账号已被禁用。", "danger")
            return redirect(url_for("auth.login"))
        return view_func(*args, **kwargs)

    return wrapper
```

- **要点**：`get_current_user` 从会话（Session）读取 `user_id` 并查询数据库，无登录状态时返回 `None`。
- **要点**：`login_required` 装饰器对未登录请求执行重定向（Redirect）至登录页，并携带 `next` 参数保留原始目标地址。
- **要点**：被禁用账号（`is_active` 为 False）的会话将被立即清除并跳转登录页。
- **要点**：`@wraps(view_func)` 保留被装饰函数的元信息，确保 Flask 路由注册正常。

## 3. 注册模板上下文和命令

修改文件：`app/__init__.py`

```python
import os

from flask import Flask, render_template

from config import config_map
from .extensions import db, migrate


def create_app(config_name=None):
    app = Flask(__name__)

    env_name = config_name or os.getenv("FLASK_ENV", "development")
    app.config.from_object(config_map.get(env_name, config_map["development"]))

    register_extensions(app)

    from . import models

    register_blueprints(app)
    register_commands(app)
    register_template_context(app)
    register_error_handlers(app)

    return app


def register_extensions(app):
    db.init_app(app)
    migrate.init_app(app, db)


def register_blueprints(app):
    from .blueprints.admin import admin_bp
    from .blueprints.auth import auth_bp
    from .blueprints.web import web_bp

    app.register_blueprint(web_bp)
    app.register_blueprint(auth_bp, url_prefix="/auth")
    app.register_blueprint(admin_bp, url_prefix="/admin")


def register_commands(app):
    from .commands import register_cli_commands

    register_cli_commands(app)


def register_template_context(app):
    from .utils.auth import get_current_user

    @app.context_processor
    def inject_current_user():
        return {"current_user": get_current_user()}


def register_error_handlers(app):
    @app.errorhandler(404)
    def page_not_found(error):
        return render_template("errors/404.html"), 404

    @app.errorhandler(500)
    def internal_server_error(error):
        return render_template("errors/500.html"), 500
```

- **要点**：`register_template_context` 使用 `@app.context_processor` 将 `current_user` 注入所有模板上下文，模板可直接引用。
- **要点**：`register_commands` 在应用工厂内统一注册 CLI 命令，与蓝图注册并列执行。
- **要点**：`from . import models` 置于扩展初始化之后，确保 SQLAlchemy 模型在数据库绑定完成后加载。

## 4. 初始化管理员命令

文件：`app/commands.py`

```python
import click
from flask.cli import with_appcontext

from app.extensions import db
from app.models import Role, User, UserProfile


def register_cli_commands(app):
    app.cli.add_command(init_admin)


@click.command("init-admin")
@click.option("--username", default="admin", help="管理员用户名")
@click.option("--password", default="123456", help="管理员密码")
@with_appcontext
def init_admin(username, password):
    admin_role = Role.query.filter_by(role_code="admin").first()
    if not admin_role:
        admin_role = Role(role_code="admin", role_name="超级管理员")
        db.session.add(admin_role)
        db.session.flush()

    user = User.query.filter_by(username=username).first()
    if not user:
        user = User(
            role_id=admin_role.id,
            username=username,
            real_name="系统管理员",
            phone="",
            status=1,
        )
        user.set_password(password)
        db.session.add(user)
        db.session.flush()

        profile = UserProfile(user_id=user.user_id)
        db.session.add(profile)
        click.echo(f"已创建管理员账号：{username}")
    else:
        user.role_id = admin_role.id
        user.status = 1
        user.set_password(password)
        click.echo(f"已重置管理员账号：{username}")

    db.session.commit()
    click.echo("初始化完成。")
```

执行：

```bash
flask init-admin --username admin --password 123456
```

- **要点**：命令使用 Click 框架编写，`@with_appcontext` 装饰器使命令可访问 Flask 应用上下文与数据库。
- **要点**：管理员角色（role_code="admin"）不存在时自动创建，保证命令幂等。
- **要点**：密码通过模型的 `set_password` 方法执行哈希存储，不直接写入明文。
- **要点**：已存在同名用户时执行重置逻辑，更新角色、状态与密码。

## 5. 登录和退出路由

修改文件：`app/blueprints/auth/routes.py`

```python
from flask import flash, redirect, render_template, request, session, url_for

from app.models import User
from . import auth_bp


@auth_bp.route("/login", methods=["GET", "POST"])
def login():
    if request.method == "POST":
        username = request.form.get("username", "").strip()
        password = request.form.get("password", "")
        next_url = request.args.get("next") or url_for("admin.dashboard")

        user = User.query.filter_by(username=username).first()
        if not user or not user.check_password(password):
            flash("用户名或密码错误。", "danger")
            return render_template("auth/login.html")

        if not user.is_active:
            flash("当前账号已被禁用，请联系管理员。", "danger")
            return render_template("auth/login.html")

        session.clear()
        session["user_id"] = user.user_id
        session["username"] = user.username
        flash("登录成功。", "success")
        return redirect(next_url)

    return render_template("auth/login.html")


@auth_bp.route("/logout")
def logout():
    session.clear()
    flash("已退出登录。", "success")
    return redirect(url_for("auth.login"))
```

- **要点**：登录成功前执行 `session.clear()` 清除旧会话数据，防止会话固定攻击。
- **要点**：`next_url` 取自请求参数，未指定时默认重定向至后台首页。
- **要点**：账号不存在与密码错误返回同一提示文案，避免暴露账号存在性。
- **要点**：退出路由仅执行 `session.clear()` 并跳转至登录页。

## 常见问题与排查

| 现象 | 原因 | 处理方式 |
|------|------|----------|
| 访问 `/admin/` 返回 500 而非跳转登录页 | `login_required` 中 `url_for("auth.login")` 端点名不匹配，或蓝图 `url_prefix` 配置错误 | 检查 auth_bp 注册时 `url_prefix="/auth"` 与路由函数名 `login` 拼写一致 |
| 登录提交后仍停留在登录页，无跳转 | POST 请求被 CSRF 拦截或模板 `method` 属性缺失 | 确认表单 `<form method="post">` 存在；若启用 CSRF 保护需在模板中加入 `{{ csrf_token }}` |
| `flask init-admin` 执行报错 "Working outside of application context" | 命令函数未添加 `@with_appcontext` 装饰器 | 确保 `init_admin` 函数上方有 `@with_appcontext` |
| 后台模板中 `current_user` 为空导致属性访问异常 | `register_template_context` 未在 `create_app` 中调用 | 检查 `app/__init__.py` 中 `register_template_context(app)` 是否已执行 |
| 登录成功后刷新页面仍被拦截 | Session 配置中 `SECRET_KEY` 缺失或每次启动变更 | 在配置文件中固定 `SECRET_KEY`，确保应用重启后会话签名密钥一致 |
