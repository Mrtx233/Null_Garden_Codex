## 阶段导语

本阶段基于第七阶段活动与首页配置模块继续开发，实现帖子列表、发布帖子、帖子详情、评论、二级评论（嵌套评论，Nested Comment）、点赞（Like）功能，以及后台管理帖子和评论。完成本阶段后：前台用户可以浏览帖子；登录用户可以发布帖子、发表评论与二级评论；登录用户可以点赞或取消点赞帖子；后台可以管理帖子状态和评论状态。

论坛模块沿用前序阶段确立的蓝图路由、权限装饰器与 Jinja2 模板结构：前台路由位于 web 蓝图，发帖、评论与点赞三类写操作受 `login_required` 保护；后台路由位于 admin 蓝图，统一受 `forum:manage` 权限控制。作为合辑的终点，本阶段第 10 节给出八个阶段完成后全项目的模块关系与最终访问路径。

## 3. 论坛后台管理路由

文件：`app/blueprints/admin/forum_routes.py`

```python
from flask import flash, redirect, render_template, url_for

from app.extensions import db
from app.models import ForumComment, ForumPost
from app.utils.auth import permission_required
from . import admin_bp


@admin_bp.route("/forum/posts")
@permission_required("forum:manage")
def forum_posts():
    posts = ForumPost.query.order_by(ForumPost.post_id.desc()).all()
    return render_template("admin/forum_posts.html", posts=posts)


@admin_bp.route("/forum/posts/<int:post_id>/toggle")
@permission_required("forum:manage")
def forum_post_toggle(post_id):
    post = ForumPost.query.get_or_404(post_id)
    post.status = 0 if post.status == 1 else 1
    db.session.commit()
    flash("帖子状态已更新。", "success")
    return redirect(url_for("admin.forum_posts"))


@admin_bp.route("/forum/comments")
@permission_required("forum:manage")
def forum_comments():
    comments = ForumComment.query.order_by(ForumComment.comment_id.desc()).all()
    return render_template("admin/forum_comments.html", comments=comments)


@admin_bp.route("/forum/comments/<int:comment_id>/toggle")
@permission_required("forum:manage")
def forum_comment_toggle(comment_id):
    comment = ForumComment.query.get_or_404(comment_id)
    comment.status = 0 if comment.status == 1 else 1
    db.session.commit()
    flash("评论状态已更新。", "success")
    return redirect(url_for("admin.forum_comments"))
```

- **要点**：帖子与评论管理路由均受 `forum:manage` 权限控制，菜单可见性与服务端校验口径一致。
- **要点**：状态切换采用 `0/1` 翻转的单路由实现，管理页无需独立的编辑表单。
- **要点**：两个列表均按主键倒序排列，最新内容优先展示。

## 4. 前台论坛路由

在第七阶段 `app/blueprints/web/routes.py` 的基础上继续增加以下路由和导入。

```python
from datetime import datetime

from flask import request

from app.models import ForumComment, ForumLike, ForumPost


@web_bp.route("/forum")
def forum_post_list():
    posts = ForumPost.query.filter_by(status=1).order_by(ForumPost.post_id.desc()).all()
    return render_template("web/forum_posts.html", posts=posts)


@web_bp.route("/forum/create", methods=["GET", "POST"])
@login_required
def forum_post_create():
    user = get_current_user()
    if request.method == "POST":
        post = ForumPost(
            user_id=user.user_id,
            title=request.form.get("title", "").strip(),
            content=request.form.get("content", "").strip(),
            created_at=datetime.utcnow(),
            status=1,
        )
        db.session.add(post)
        db.session.commit()
        flash("帖子已发布。", "success")
        return redirect(url_for("web.forum_post_detail", post_id=post.post_id))
    return render_template("web/forum_post_form.html")


@web_bp.route("/forum/<int:post_id>")
def forum_post_detail(post_id):
    post = ForumPost.query.get_or_404(post_id)
    comments = (
        ForumComment.query
        .filter_by(post_id=post.post_id, parent_id=None, status=1)
        .order_by(ForumComment.comment_id.asc())
        .all()
    )
    user = get_current_user()
    liked = False
    if user:
        liked = ForumLike.query.filter_by(post_id=post.post_id, user_id=user.user_id).first() is not None
    return render_template("web/forum_post_detail.html", post=post, comments=comments, liked=liked)


@web_bp.route("/forum/<int:post_id>/comments", methods=["POST"])
@login_required
def forum_comment_create(post_id):
    user = get_current_user()
    post = ForumPost.query.get_or_404(post_id)
    comment = ForumComment(
        post_id=post.post_id,
        user_id=user.user_id,
        parent_id=request.form.get("parent_id") or None,
        content=request.form.get("content", "").strip(),
        created_at=datetime.utcnow(),
        status=1,
    )
    db.session.add(comment)
    post.comment_count = (post.comment_count or 0) + 1
    db.session.commit()
    flash("评论已发布。", "success")
    return redirect(url_for("web.forum_post_detail", post_id=post.post_id))


@web_bp.route("/forum/<int:post_id>/like", methods=["POST"])
@login_required
def forum_post_like(post_id):
    user = get_current_user()
    post = ForumPost.query.get_or_404(post_id)
    like = ForumLike.query.filter_by(post_id=post.post_id, user_id=user.user_id).first()
    if like:
        db.session.delete(like)
        post.like_count = max((post.like_count or 0) - 1, 0)
        flash("已取消点赞。", "success")
    else:
        db.session.add(ForumLike(post_id=post.post_id, user_id=user.user_id, created_at=datetime.utcnow()))
        post.like_count = (post.like_count or 0) + 1
        flash("已点赞。", "success")
    db.session.commit()
    return redirect(url_for("web.forum_post_detail", post_id=post.post_id))
```

发帖、评论与点赞三类写操作均受 `login_required` 保护；帖子列表与详情页对未登录用户开放，列表仅输出 `status=1` 的帖子。一级评论与二级评论存储于同一张 ForumComment 表：查询以 `parent_id=None` 过滤一级评论，二级评论通过 `comment.children` 关系在模板中嵌套渲染。评论路由通过表单字段 `parent_id` 判定层级，发帖与评论请求提交时同步维护帖子表上的 `comment_count` 与 `like_count` 冗余计数。

- **要点**：帖子列表只展示 `status=1` 的内容，与后台状态切换构成同一套显示控制。
- **要点**：评论层级由 `parent_id` 是否为空区分，单表自关联即可支持二级评论。
- **要点**：点赞为开关式逻辑：已存在点赞记录则删除并递减计数，否则新增并递增，`max(..., 0)` 防止计数为负。
- **要点**：详情页需判断当前用户是否已点赞（`liked`），未登录用户固定为非点赞态。

- **要点**：未登录用户的作者信息回退为"匿名"，内容展示不依赖登录态。

## 9. 本阶段验证

访问：

```text
前台论坛：http://127.0.0.1:5000/forum
发布帖子：http://127.0.0.1:5000/forum/create
帖子管理：http://127.0.0.1:5000/admin/forum/posts

```

验收标准：

- [ ] 帖子列表：展示状态为显示的帖子
- [ ] 发布帖子：登录用户可以发布
- [ ] 帖子详情：展示内容、点赞数、评论数
- [ ] 评论：登录用户可以评论
- [ ] 二级评论：可以回复一级评论
- [ ] 点赞：可以点赞和取消点赞
- [ ] 后台帖子管理：可以隐藏/显示帖子
- [ ] 后台评论管理：可以隐藏/显示评论

- **要点**：验证需分别使用登录账号与未登录访客执行：发帖、评论、点赞为登录态操作，列表与详情为开放访问。
- **要点**：后台管理项须使用具备 `forum:manage` 权限的账号执行，同时确认无权账号访问对应路由被拦截。
- **要点**：隐藏帖子或评论后需回到前台确认其不再出现，以验证前后端状态口径一致。

## 10. 全项目最终串联

完成第一至第八阶段后，系统模块关系如下：

```text
项目基础搭建
  ↓
登录认证
  ↓
RBAC 权限
  ↓
用户与门店
  ↓
课程业务
  ↓
动作库业务
  ↓
活动与首页配置
  ↓
论坛社区
```

最终访问路径：

```text
前台首页：http://127.0.0.1:5000/
课程列表：http://127.0.0.1:5000/courses
动作库：http://127.0.0.1:5000/actions
活动列表：http://127.0.0.1:5000/activities
论坛社区：http://127.0.0.1:5000/forum
后台首页：http://127.0.0.1:5000/admin/
```

- **要点**：八个阶段按依赖顺序串联，论坛社区位于链路末端，复用前序阶段建立的认证、权限与布局体系。
- **要点**：最终访问路径覆盖前台四类内容、社区与后台首页，交付前逐条访问确认路由可达。
- **要点**：至此《Flask 系统阶段开发手册》全部阶段完成，后续扩展方向见「合辑收尾与进阶方向」。

## 阶段小结

| 知识模块 | 核心内容 | 在本阶段中的作用 |
| --- | --- | --- |
| 后台论坛路由 | 帖子与评论列表、`0/1` 状态切换，受 `forum:manage` 控制 | 提供内容的后台治理能力 |
| 前台论坛路由 | 帖子列表/详情、发布帖子、评论与点赞，写操作受 `login_required` 保护 | 承载社区内容的浏览与互动 |
| 二级评论 | 单表 `parent_id` 自关联区分一级与二级评论，模板按状态过滤渲染 | 实现评论的嵌套回复能力 |
| 点赞机制 | ForumLike 记录增删与 `like_count` 冗余计数同步，开关式切换 | 表达用户偏好并防止重复点赞 |
| 模板与样式 | 后台 `data-table` 列表页、前台卡片列表、详情页与 `comment-*` 样式 | 复用既有布局体系，保持前后台视觉统一 |
| 全项目串联 | 八阶段模块依赖关系与最终访问路径 | 确认整体交付形态，完成合辑收尾 |

## 常见问题与排查

| 现象 | 原因 | 处理方式 |
| --- | --- | --- |
| 发布帖子或提交评论被跳转到登录页 | 写操作路由包裹 `login_required`，当前会话未登录或已过期 | 先完成登录再执行操作，确认会话未失效 |
| 后台切换状态后前台计数或列表无变化 | toggle 路由未提交事务，或前台查询仍命中旧数据 | 确认切换后执行了 `db.session.commit()`，刷新页面核对 `status` 字段值 |
| 详情页看不到二级评论 | ForumComment 的 `children` 关系未定义，或子评论 `status=0` 被模板过滤 | 检查模型自关联关系配置，在后台确认子评论处于显示状态 |
| 点赞数与 ForumLike 记录数不一致 | `like_count` 冗余字段被单独修改导致漂移 | 以 ForumLike 表统计值为准修正冗余计数，后续变更统一走点赞路由 |
| 访问 `/forum` 返回 404 | 论坛路由未导入或未挂载到 web 蓝图 | 确认新增路由已写入 `app/blueprints/web/routes.py` 并重启开发服务器 |

## 合辑收尾与进阶方向

《Flask 系统阶段开发手册》的八个阶段至此完结：项目基础、登录认证、RBAC 权限、用户与门店、课程业务、动作库业务、活动与首页配置、论坛社区依次衔接，形成一个后台管理与前台展示齐备的健身平台系统，权限体系、业务数据与内容社区已全线贯通。后续进阶可沿四条方向展开：其一为接口化改造，将页面渲染路由重构为 RESTful API 并配合前端框架分离展示层；其二为富文本与图片存储，引入富文本编辑器与对象存储方案，升级帖子与封面图能力；其三为内容审核，为发帖与评论链路接入敏感词校验或第三方审核服务；其四为部署上线与性能优化，引入 Gunicorn 与 Nginx、数据库索引、缓存与列表分页，使系统具备真实的生产承载能力。
