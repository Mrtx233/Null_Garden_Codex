> **合辑**：Flask 系统阶段开发手册 ｜ **阶段**：7 / 8 ｜ **定位**：实现 Slogan 与赛事活动的后台维护，以及前台首页配置展示、活动列表与活动详情 ｜ **建议学时**：6–8 小时

大家好，我是小马不起床。

## 阶段导语

本阶段基于第六阶段动作库业务模块继续开发，构建系统的"运营配置"层：后台提供 Slogan 与赛事活动两类内容的维护入口，前台首页聚合展示启用的 Slogan、课程、动作与活动，并提供活动列表与活动详情页面。

与前几个阶段的纯内容管理不同，本阶段的核心是首页展示配置：Slogan 依据启用状态（status）过滤并按创建时间倒序展示，活动按赛事日期倒序排列，同时服务于首页推荐位与独立列表页。完成本阶段后，系统的前台展示链路与后台管理链路均告完整。

## 3. Slogan 和活动后台路由

文件：`app/blueprints/admin/activity_routes.py`

```python
from flask import flash, redirect, render_template, request, url_for

from app.extensions import db
from app.models import ActivityEvent, SloganInfo
from app.utils.auth import permission_required
from . import admin_bp


@admin_bp.route("/slogans")
@permission_required("activity:manage")
def slogans():
    items = SloganInfo.query.order_by(SloganInfo.slogan_id.desc()).all()
    return render_template("admin/slogans.html", slogans=items)


@admin_bp.route("/slogans/create", methods=["GET", "POST"])
@permission_required("activity:manage")
def slogan_create():
    if request.method == "POST":
        item = SloganInfo(
            slogan_name=request.form.get("slogan_name", "").strip(),
            slogan_content=request.form.get("slogan_content", "").strip(),
            slogan_image_url=request.form.get("slogan_image_url", "").strip(),
            status=int(request.form.get("status", 1)),
        )
        db.session.add(item)
        db.session.commit()
        flash("Slogan 已创建。", "success")
        return redirect(url_for("admin.slogans"))
    return render_template("admin/slogan_form.html", slogan=None)


@admin_bp.route("/slogans/<int:slogan_id>/edit", methods=["GET", "POST"])
@permission_required("activity:manage")
def slogan_edit(slogan_id):
    item = SloganInfo.query.get_or_404(slogan_id)
    if request.method == "POST":
        item.slogan_name = request.form.get("slogan_name", "").strip()
        item.slogan_content = request.form.get("slogan_content", "").strip()
        item.slogan_image_url = request.form.get("slogan_image_url", "").strip()
        item.status = int(request.form.get("status", 1))
        db.session.commit()
        flash("Slogan 已更新。", "success")
        return redirect(url_for("admin.slogans"))
    return render_template("admin/slogan_form.html", slogan=item)


@admin_bp.route("/activities")
@permission_required("activity:manage")
def activities():
    items = ActivityEvent.query.order_by(ActivityEvent.event_date.desc()).all()
    return render_template("admin/activities.html", activities=items)


@admin_bp.route("/activities/create", methods=["GET", "POST"])
@permission_required("activity:manage")
def activity_create():
    if request.method == "POST":
        item = ActivityEvent(
            title=request.form.get("title", "").strip(),
            event_date=request.form["event_date"],
            location=request.form.get("location", "").strip(),
            status=request.form.get("status", "预告").strip(),
            description=request.form.get("description", "").strip(),
            tags=request.form.get("tags", "").strip(),
            prize=request.form.get("prize", "").strip(),
            scale=request.form.get("scale", "").strip(),
        )
        db.session.add(item)
        db.session.commit()
        flash("活动已创建。", "success")
        return redirect(url_for("admin.activities"))
    return render_template("admin/activity_form.html", activity=None)


@admin_bp.route("/activities/<int:event_id>/edit", methods=["GET", "POST"])
@permission_required("activity:manage")
def activity_edit(event_id):
    item = ActivityEvent.query.get_or_404(event_id)
    if request.method == "POST":
        item.title = request.form.get("title", "").strip()
        item.event_date = request.form["event_date"]
        item.location = request.form.get("location", "").strip()
        item.status = request.form.get("status", "预告").strip()
        item.description = request.form.get("description", "").strip()
        item.tags = request.form.get("tags", "").strip()
        item.prize = request.form.get("prize", "").strip()
        item.scale = request.form.get("scale", "").strip()
        db.session.commit()
        flash("活动已更新。", "success")
        return redirect(url_for("admin.activities"))
    return render_template("admin/activity_form.html", activity=item)
```

- **要点**：全部路由均受 `@permission_required("activity:manage")` 保护，未授权用户访问会被权限拦截。
- **要点**：新增与编辑共用同一表单模板，通过向模板传入 `slogan=None` 或 `activity=None` 区分两种状态。
- **要点**：`event_date` 采用 `request.form["event_date"]` 直接访问，表单必须提交该字段，否则触发 `KeyError`；其余字段使用 `request.form.get` 提供默认值。
- **要点**：列表排序规则为 Slogan 按 `slogan_id` 倒序、活动按 `event_date` 倒序，前台展示沿用同一排序口径。
- **要点**：保存成功后统一执行 `flash` 提示并 `redirect` 回列表页，遵循 Post/Redirect/Get 模式，避免刷新重复提交。

## 4. 前台首页和活动路由

在第六阶段 `app/blueprints/web/routes.py` 的基础上整理为以下完整版本，整文件替换原有内容。

```python
from flask import flash, redirect, render_template, url_for

from app.extensions import db
from app.models import (
    Action,
    ActionCategory,
    ActivityEvent,
    Course,
    CourseCategory,
    SloganInfo,
    UserActionFavorite,
    UserCourseFavorite,
)
from app.utils.auth import get_current_user, login_required
from . import web_bp


@web_bp.route("/")
def index():
    slogans = SloganInfo.query.filter_by(status=1).order_by(SloganInfo.slogan_id.desc()).limit(3).all()
    courses = Course.query.filter_by(status=1).order_by(Course.course_id.desc()).limit(6).all()
    actions = Action.query.order_by(Action.action_id.desc()).limit(6).all()
    activities = ActivityEvent.query.order_by(ActivityEvent.event_date.desc()).limit(4).all()
    return render_template(
        "web/index.html",
        slogans=slogans,
        courses=courses,
        actions=actions,
        activities=activities,
    )


@web_bp.route("/activities")
def activity_list():
    activities = ActivityEvent.query.order_by(ActivityEvent.event_date.desc()).all()
    return render_template("web/activities.html", activities=activities)


@web_bp.route("/activities/<int:event_id>")
def activity_detail(event_id):
    activity = ActivityEvent.query.get_or_404(event_id)
    return render_template("web/activity_detail.html", activity=activity)


@web_bp.route("/courses")
def course_list():
    categories = CourseCategory.query.filter_by(status=1).order_by(CourseCategory.category_id.asc()).all()
    courses = Course.query.filter_by(status=1).order_by(Course.course_id.desc()).all()
    return render_template("web/courses.html", categories=categories, courses=courses)


@web_bp.route("/courses/<int:course_id>")
def course_detail(course_id):
    course = Course.query.get_or_404(course_id)
    user = get_current_user()
    is_favorite = False
    if user:
        is_favorite = UserCourseFavorite.query.filter_by(user_id=user.user_id, course_id=course.course_id).first() is not None
    return render_template("web/course_detail.html", course=course, is_favorite=is_favorite)


@web_bp.route("/courses/<int:course_id>/favorite", methods=["POST"])
@login_required
def course_favorite(course_id):
    user = get_current_user()
    favorite = UserCourseFavorite.query.filter_by(user_id=user.user_id, course_id=course_id).first()
    if favorite:
        db.session.delete(favorite)
        flash("已取消收藏课程。", "success")
    else:
        db.session.add(UserCourseFavorite(user_id=user.user_id, course_id=course_id))
        flash("已收藏课程。", "success")
    db.session.commit()
    return redirect(url_for("web.course_detail", course_id=course_id))


@web_bp.route("/actions")
def action_list():
    categories = ActionCategory.query.order_by(ActionCategory.category_id.asc()).all()
    actions = Action.query.order_by(Action.action_id.desc()).all()
    return render_template("web/actions.html", categories=categories, actions=actions)


@web_bp.route("/actions/<int:action_id>")
def action_detail(action_id):
    action = Action.query.get_or_404(action_id)
    user = get_current_user()
    is_favorite = False
    if user:
        is_favorite = UserActionFavorite.query.filter_by(user_id=user.user_id, action_id=action.action_id).first() is not None
    return render_template("web/action_detail.html", action=action, is_favorite=is_favorite)


@web_bp.route("/actions/<int:action_id>/favorite", methods=["POST"])
@login_required
def action_favorite(action_id):
    user = get_current_user()
    favorite = UserActionFavorite.query.filter_by(user_id=user.user_id, action_id=action_id).first()
    if favorite:
        db.session.delete(favorite)
        flash("已取消收藏动作。", "success")
    else:
        db.session.add(UserActionFavorite(user_id=user.user_id, action_id=action_id))
        flash("已收藏动作。", "success")
    db.session.commit()
    return redirect(url_for("web.action_detail", action_id=action_id))
```

- **要点**：首页查询条件存在差异：Slogan 与课程按 `status=1` 过滤启用数据，动作与活动不过滤状态，仅按主键或日期倒序截取条数。
- **要点**：首页四块数据（Slogan 3 条、课程 6 条、动作 6 条、活动 4 条）在 `index` 视图一次性组装完成，模板只负责渲染。
- **要点**：活动列表 `/activities` 与详情 `/activities/<int:event_id>` 同后台管理共用 `ActivityEvent` 模型，构成前后台双入口模式。
- **要点**：课程与动作收藏路由为第六阶段既有功能，整理完整版本时须一并保留，禁止遗漏导致既有页面失效。

- **要点**：主标题取 `slogans[0].slogan_content`，无启用 Slogan 时回退为固定文案，保证 hero 区域不为空白。
- **要点**：热门课程、动作库、赛事活动三个内容区使用统一的 `card-grid` + `content-card` 结构，新增展示区块时沿用该布局。
- **要点**：课程与动作卡片对分类为空的情况以"未分类"兜底，关联对象访问需先判空。
- **要点**：活动卡片以 `event_id` 构造详情链接，指向第 4 节定义的 `web.activity_detail` 视图。

## 7. 前台活动模板

文件：`app/templates/web/activities.html`

```html
{% extends "web/layout.html" %}
{% block title %}赛事活动{% endblock %}
{% block content %}
<section class="content-section">
    <h1>赛事活动</h1>
    <div class="card-grid">
        {% for activity in activities %}
            <a class="content-card" href="{{ url_for('web.activity_detail', event_id=activity.event_id) }}">
                <strong>{{ activity.title }}</strong>
                <span>{{ activity.event_date }} · {{ activity.location }}</span>
                <p>{{ activity.status }}</p>
            </a>
        {% endfor %}
    </div>
</section>
{% endblock %}
```

文件：`app/templates/web/activity_detail.html`

```html
{% extends "web/layout.html" %}
{% block title %}{{ activity.title }}{% endblock %}
{% block content %}
<section class="content-section">
    <h1>{{ activity.title }}</h1>
    <p>{{ activity.event_date }} · {{ activity.location }} · {{ activity.status }}</p>
    <p>标签：{{ activity.tags or "-" }}</p>
    <p>奖品：{{ activity.prize or "-" }}</p>
    <p>规模：{{ activity.scale or "-" }}</p>
    <article>{{ activity.description }}</article>
</section>
{% endblock %}
```

- **要点**：活动列表页与首页活动区渲染结构相同，差异仅在数据范围（全量 versus 前 4 条）。
- **要点**：详情页可空字段（标签、奖品、规模）使用 `or "-"` 兜底，避免标签后出现空白。
- **要点**：详情页 `title` block 直接引用 `activity.title`，页面标题随数据动态变化。

## 8. 后台菜单

修改文件：`app/templates/admin/layout.html` 的菜单区域。

```html
{% if has_permission("activity:manage") %}
    <a href="{{ url_for('admin.slogans') }}">Slogan 管理</a>
    <a href="{{ url_for('admin.activities') }}">赛事活动</a>
{% endif %}
```

- **要点**：菜单项包裹在 `has_permission("activity:manage")` 判断内，无权限角色不渲染对应入口。
- **要点**：菜单权限键必须与后台路由 `@permission_required` 的参数完全一致，否则会出现"菜单可见、页面被拦截"的不一致状态。

## 常见问题与排查

| 现象 | 原因 | 处理方式 |
|------|------|----------|
| 访问 `/admin/slogans` 返回 404 | `admin/__init__.py` 未追加 `from . import activity_routes` | 补充导入语句并重启服务 |
| 进入后台页面提示无权限 | 当前用户角色未分配 `activity:manage` 权限 | 在 RBAC 中为该角色授权后重新登录 |
| 首页主标题始终为固定兜底文案 | 不存在 `status=1` 的启用 Slogan | 在后台新增或启用一条 Slogan |
| 提交活动表单报 KeyError | `event_date` 未提交，路由以 `request.form["event_date"]` 直接访问 | 确认表单包含必填的日期输入项 |
| 后台菜单看不到 Slogan / 活动入口 | `has_permission` 判断的权限键与权限数据不一致 | 核对权限键拼写并重新登录刷新权限上下文 |
