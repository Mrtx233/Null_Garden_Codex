> **合辑**：Flask 系统阶段开发手册 ｜ **阶段**：1 / 8 ｜ **定位**：搭建 `flask_joyfit_fullstack` 的应用工厂骨架、数据库连接与全部数据模型，为后续功能模块提供工程基础 ｜ **建议学时**：8–12 小时

大家好，我是小马不起床。

## 阶段导语

本阶段搭建 `flask_joyfit_fullstack` 的 Flask 项目骨架：完成数据库连接、SQLAlchemy 扩展、应用工厂（Application Factory）、基础蓝图（Blueprint）、前后台基础模板、静态资源目录，并依据已有 SQL 补全 20 张表的 SQLAlchemy 数据模型。

作为本合辑的起点，本阶段交付的是一个可正常启动的工程底座：项目能够通过启动入口运行，并能借助 Flask-Migrate 生成与执行数据库迁移（Migration）。只有骨架与模型层稳定，后续登录认证、门店、课程、动作、活动与论坛等阶段才有统一的扩展入口。

## 学习目标

- [ ] 能够按应用工厂结构创建完整的项目目录，并说明 `app`、`templates`、`static`、`migrations` 各目录的职责
- [ ] 能够创建虚拟环境，安装 Flask、Flask-SQLAlchemy、Flask-Migrate、PyMySQL、python-dotenv 五个依赖并生成 `requirements.txt`
- [ ] 能够通过 `.env` 环境变量与 `config.py` 配置类实现开发、测试、生产三环境配置
- [ ] 能够编写应用工厂 `create_app`，统一完成配置加载、扩展初始化、蓝图注册与错误页处理
- [ ] 能够完成前台、后台、认证三个基础蓝图及对应占位路由
- [ ] 能够依据已有 SQL 编写 20 张业务表的 SQLAlchemy 模型，并通过 `flask db migrate` / `flask db upgrade` 验证模型层

- **要点**：bash 与 PowerShell 两种创建方式等价，按操作系统选择其一执行。

## 5. 项目配置文件

文件：`config.py`

```python
import os
from urllib.parse import quote_plus

from dotenv import load_dotenv


load_dotenv()


class BaseConfig:
    SECRET_KEY = os.getenv("SECRET_KEY", "dev-secret-key")

    DB_HOST = os.getenv("DB_HOST", "127.0.0.1")
    DB_PORT = int(os.getenv("DB_PORT", "3306"))
    DB_USER = os.getenv("DB_USER", "root")
    DB_PASSWORD = os.getenv("DB_PASSWORD", "123456")
    DB_NAME = os.getenv("DB_NAME", "flask_joyfit_fullstack")
    DB_CHARSET = os.getenv("DB_CHARSET", "utf8mb4")

    SQLALCHEMY_DATABASE_URI = (
        f"mysql+pymysql://{DB_USER}:{quote_plus(DB_PASSWORD)}"
        f"@{DB_HOST}:{DB_PORT}/{DB_NAME}?charset={DB_CHARSET}"
    )
    SQLALCHEMY_TRACK_MODIFICATIONS = False
    SQLALCHEMY_ENGINE_OPTIONS = {
        "pool_pre_ping": True,
        "pool_recycle": 280,
    }

    JSON_AS_ASCII = False


class DevelopmentConfig(BaseConfig):
    DEBUG = True


class TestingConfig(BaseConfig):
    TESTING = True
    SQLALCHEMY_DATABASE_URI = "sqlite:///:memory:"


class ProductionConfig(BaseConfig):
    DEBUG = False


config_map = {
    "development": DevelopmentConfig,
    "testing": TestingConfig,
    "production": ProductionConfig,
}
```

- **要点**：`BaseConfig` 从环境变量拼装 SQLAlchemy 连接串，并统一设置 `pool_pre_ping`、`pool_recycle` 连接池参数。
- **要点**：开发、测试、生产三套环境经 `config_map` 按名称切换，测试环境使用内存 SQLite 与真实数据库隔离。
- **要点**：连接串中使用 `quote_plus` 对密码做 URL 编码，避免特殊字符导致解析错误。

## 7. 应用工厂

文件：`app/__init__.py`

```python
import os

from flask import Flask, render_template

from config import config_map
from .extensions import db, migrate


def create_app(config_name=None):
    app = Flask(__name__)

    env_name = config_name or os.getenv("FLASK_ENV", "development")
    app.config.from_object(config_map.get(env_name, config_map["development"]))

    register_extensions(app)

    from . import models

    register_blueprints(app)
    register_error_handlers(app)

    return app


def register_extensions(app):
    db.init_app(app)
    migrate.init_app(app, db)


def register_blueprints(app):
    from .blueprints.admin import admin_bp
    from .blueprints.auth import auth_bp
    from .blueprints.web import web_bp

    app.register_blueprint(web_bp)
    app.register_blueprint(auth_bp, url_prefix="/auth")
    app.register_blueprint(admin_bp, url_prefix="/admin")


def register_error_handlers(app):
    @app.errorhandler(404)
    def page_not_found(error):
        return render_template("errors/404.html"), 404

    @app.errorhandler(500)
    def internal_server_error(error):
        return render_template("errors/500.html"), 500
```

- **要点**：`create_app` 按"加载配置 → 初始化扩展 → 导入模型 → 注册蓝图 → 注册错误处理"的顺序完成应用装配。
- **要点**：`from . import models` 必须位于 `register_extensions(app)` 之后、`register_blueprints(app)` 之前，确保迁移工具能够发现全部模型。
- **要点**：`/auth`、`/admin` 前缀统一在工厂中注册，蓝图自身不硬编码 URL 前缀。

### 10.2 系统、权限、用户模型

文件：`app/models/system.py`

```python
from datetime import datetime

from werkzeug.security import check_password_hash, generate_password_hash

from app.extensions import db


class Permission(db.Model):
    __tablename__ = "sys_permission"

    id = db.Column(db.BigInteger, primary_key=True, autoincrement=True, comment="权限ID")
    permission_code = db.Column(db.String(64), nullable=False, unique=True, comment="权限标识符")
    permission_name = db.Column(db.String(64), nullable=False, comment="权限名称")
    menu_path = db.Column(db.String(255), comment="前端路由路径")

    role_permissions = db.relationship("RolePermission", back_populates="permission")

    def __repr__(self):
        return f"<Permission {self.permission_code}>"


class Role(db.Model):
    __tablename__ = "sys_role"

    id = db.Column(db.BigInteger, primary_key=True, autoincrement=True, comment="角色ID")
    role_code = db.Column(db.String(64), nullable=False, unique=True, comment="角色代码")
    role_name = db.Column(db.String(64), nullable=False, comment="角色名称")

    users = db.relationship("User", back_populates="role")
    role_permissions = db.relationship("RolePermission", back_populates="role", cascade="all, delete-orphan")

    def __repr__(self):
        return f"<Role {self.role_code}>"


class RolePermission(db.Model):
    __tablename__ = "sys_role_permission"

    id = db.Column(db.BigInteger, primary_key=True, autoincrement=True, comment="关联ID")
    role_id = db.Column(db.BigInteger, db.ForeignKey("sys_role.id"), nullable=False, comment="角色ID")
    permission_id = db.Column(db.BigInteger, db.ForeignKey("sys_permission.id"), nullable=False, comment="权限ID")

    role = db.relationship("Role", back_populates="role_permissions")
    permission = db.relationship("Permission", back_populates="role_permissions")


class User(db.Model):
    __tablename__ = "sys_user"

    user_id = db.Column(db.BigInteger, primary_key=True, autoincrement=True, comment="用户ID")
    role_id = db.Column(db.BigInteger, db.ForeignKey("sys_role.id"), nullable=False, comment="角色ID")
    username = db.Column(db.String(64), nullable=False, unique=True, comment="用户名")
    password = db.Column(db.String(255), nullable=False, comment="密码")
    real_name = db.Column(db.String(64), comment="真实姓名")
    phone = db.Column(db.String(20), comment="手机号")
    status = db.Column(db.Integer, default=1, comment="状态")

    role = db.relationship("Role", back_populates="users")
    profile = db.relationship("UserProfile", back_populates="user", uselist=False, cascade="all, delete-orphan")

    def set_password(self, raw_password):
        self.password = generate_password_hash(raw_password)

    def check_password(self, raw_password):
        return check_password_hash(self.password, raw_password)

    @property
    def is_active(self):
        return self.status == 1

    def __repr__(self):
        return f"<User {self.username}>"


class UserProfile(db.Model):
    __tablename__ = "sys_user_profile"

    profile_id = db.Column(db.BigInteger, primary_key=True, autoincrement=True, comment="档案ID")
    user_id = db.Column(db.BigInteger, db.ForeignKey("sys_user.user_id"), nullable=False, unique=True, comment="用户ID")
    level = db.Column(db.Integer, comment="等级")
    gender = db.Column(db.Integer, comment="性别")
    birthday = db.Column(db.Date, comment="生日")
    height_cm = db.Column(db.Numeric(5, 2), comment="身高(cm)")
    weight_kg = db.Column(db.Numeric(5, 2), comment="体重(kg)")
    avatar_url = db.Column(db.String(255), comment="头像地址")
    intro = db.Column(db.Text, comment="简介")
    create_time = db.Column(db.DateTime, default=datetime.utcnow, comment="账号创建时间")
    join_time = db.Column(db.DateTime, comment="入职/开卡时间")
    expire_date = db.Column(db.Date, comment="到期/停卡时间")

    user = db.relationship("User", back_populates="profile")
```

CREATE DATABASE IF NOT EXISTS `flask_joyfit_fullstack`

### 13.2 初始化迁移

首次使用 Flask-Migrate 时执行：

```powershell
flask db init
```

生成迁移脚本：

```powershell
flask db migrate -m "init database models"
```

执行迁移：

```powershell
flask db upgrade
```

如果模型没有被识别，确认 `app/models/__init__.py` 已导入全部模型，并在 `app/__init__.py` 中加入下面这一行：

```python
from . import models
```

该语句需放在 `register_extensions(app)` 之后、`register_blueprints(app)` 之前：

```python
def create_app(config_name=None):
    app = Flask(__name__)

    env_name = config_name or os.getenv("FLASK_ENV", "development")
    app.config.from_object(config_map.get(env_name, config_map["development"]))

    register_extensions(app)

    from . import models

    register_blueprints(app)
    register_error_handlers(app)

    return app
```

- **要点**：创建数据库须先于 `flask db init` 执行，`init`、`migrate`、`upgrade` 三条命令按顺序使用且不可跳步。
- **要点**：迁移脚本为空时，应优先检查 `app/models/__init__.py` 的模型导入完整性与 `from . import models` 在工厂函数中的位置。

## 14. 推荐补充：让模型自动被迁移工具发现

为避免遗漏模型导入，最终版 `app/__init__.py` 建议采用以下实现：

```python
import os

from flask import Flask, render_template

from config import config_map
from .extensions import db, migrate


def create_app(config_name=None):
    app = Flask(__name__)

    env_name = config_name or os.getenv("FLASK_ENV", "development")
    app.config.from_object(config_map.get(env_name, config_map["development"]))

    register_extensions(app)

    from . import models

    register_blueprints(app)
    register_error_handlers(app)

    return app


def register_extensions(app):
    db.init_app(app)
    migrate.init_app(app, db)


def register_blueprints(app):
    from .blueprints.admin import admin_bp
    from .blueprints.auth import auth_bp
    from .blueprints.web import web_bp

    app.register_blueprint(web_bp)
    app.register_blueprint(auth_bp, url_prefix="/auth")
    app.register_blueprint(admin_bp, url_prefix="/admin")


def register_error_handlers(app):
    @app.errorhandler(404)
    def page_not_found(error):
        return render_template("errors/404.html"), 404

    @app.errorhandler(500)
    def internal_server_error(error):
        return render_template("errors/500.html"), 500
```

- **要点**：该版本将模型导入固定在扩展初始化与蓝图注册之间，确保 Alembic 在任意启动路径下均能发现全部 20 张表。
- **要点**：后续阶段对配置、扩展、蓝图的调整均以本文件为基准落位，保持工厂函数结构稳定。

## 18. 问题记录：TemplateNotFound

### 18.1 报错现象

启动项目并访问前台首页 `/` 时，页面报错：

```text
jinja2.exceptions.TemplateNotFound: web/index.html
```

对应路由代码为：

```python
@web_bp.route("/")
def index():
    return render_template("web/index.html")
```

### 18.2 问题原因

该报错说明 Flask 已成功找到并执行路由函数，但 Jinja2 未在模板目录中定位到 `web/index.html`。

`render_template("web/index.html")` 对应的实际文件路径必须为：

```text
flask_joyfit_fullstack/app/templates/web/index.html
```

常见原因：

| 原因 | 说明 |
| --- | --- |
| 未创建模板文件 | 缺少 `app/templates/web/index.html` |
| 模板目录命名错误 | 必须为 `templates`，而非 `template` |
| 文件位置放置错误 | 必须位于 `app/templates/web/` 下 |
| 项目运行目录不一致 | 实际运行的是另一个 `flask_joyfit_fullstack` 项目 |
| 文件名不一致 | 必须为 `index.html`，禁止写成 `index.htm` 或其他名称 |

### 18.3 修改方法

进入实际运行的 Flask 项目根目录：

```bash
cd <flask_joyfit_fullstack 项目根目录>
```

创建模板目录：

```bash
mkdir -p app/templates/web
```

确认或创建文件：

```text
app/templates/web/index.html
```

内容如下：

```html
{% extends "web/layout.html" %}

{% block title %}JoyFit 首页{% endblock %}

{% block content %}
<section class="hero">
    <div>
        <p class="eyebrow">JoyFit Training</p>
        <h1>训练、课程、门店和社区的一体化健身平台</h1>
        <p class="hero-text">这里是前台首页基础模板。后续阶段会接入 Banner、Slogan、活动、课程和论坛数据。</p>
    </div>
</section>
{% endblock %}
```

同时确认前台基础布局文件也存在：

```text
app/templates/web/layout.html
```

如不存在，按照本文 11.1 节创建 `app/templates/web/layout.html`。

### 18.4 验证方法

重新启动 Flask：

```bash
python run.py
```

访问：

```text
http://127.0.0.1:5000/
```

页面正常显示 JoyFit 首页即表示问题已解决。

- **要点**：`TemplateNotFound` 意味着路由可达而模板路径不匹配，排查应首先核对模板目录与文件路径。
- **要点**：处理顺序固定为"确认实际运行的项目根目录 → 核对目录与文件命名 → 重启验证"。

## 常见问题与排查

| 现象 | 原因 | 处理方式 |
| --- | --- | --- |
| 访问 `/` 报 `TemplateNotFound: web/index.html` | 模板文件缺失或目录命名错误（`template` 与 `templates` 混用） | 按 18 节核对 `app/templates/web/` 下的文件路径与命名后重启服务 |
| `flask db migrate` 生成的脚本为空 | 模型未被导入，`from . import models` 缺失或位置错误 | 补全 `app/models/__init__.py` 的导入，并将模型导入置于 `register_extensions(app)` 之后 |
| 启动或建表时报数据库连接失败 | `.env` 未复制或未安装 python-dotenv，MySQL 账号、密码、端口与实际环境不符 | 复制 `.env.example` 为 `.env`，将 `DB_PASSWORD` 等占位符替换为实际值并确认 MySQL 服务已启动 |
| 访问 `/admin/` 返回 404 | 应用工厂中未注册 `admin_bp` 或 URL 前缀拼写错误 | 检查 `register_blueprints` 中 `url_prefix="/admin"` 的配置 |
| `flask` 命令不可用 | 虚拟环境未激活 | 执行 `.\.venv\Scripts\activate`（Windows）或 `source .venv/bin/activate`（macOS / Linux）后重试 |
