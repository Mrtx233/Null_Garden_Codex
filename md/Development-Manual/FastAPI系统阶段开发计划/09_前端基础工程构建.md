# 09_前端基础工程构建

## 一、阶段目标

本阶段目标是在后端接口已经基本稳定、OpenAPI 已经可以导出的基础上，创建 Vue3 前端工程，并完成前端基础设施。

完成本阶段后，前端应具备以下能力：

1. 使用 Vite 创建 Vue3 + TypeScript 工程。
2. 安装 Vue Router、Pinia、Axios、Element Plus。
3. 配置开发环境 API 代理。
4. 创建全局请求封装。
5. 创建基础路由。
6. 创建基础布局。
7. 创建前端首页骨架。
8. 可以通过 `npm run dev` 启动前端服务。

本阶段只搭建前端基础工程，不实现登录表单和权限守卫。登录权限放到下一阶段。

## 二、本阶段开发顺序

```text
1. 使用 Vite 创建 frontend 项目
2. 安装前端依赖
3. 配置 Vite 代理
4. 配置环境变量
5. 配置 main.ts
6. 配置 App.vue
7. 创建路由
8. 创建 Axios 请求封装
9. 创建基础布局
10. 创建首页和 404 页面
11. 启动前端服务验证
```

## 五、步骤 1：创建 Vue3 前端项目

### 执行位置

确保当前目录是：

```text
FastAPI_Vue3_JoyFit
```

也就是和 `backend` 同级。

### 创建命令

```bash
npm create vite@latest frontend -- --template vue-ts
```

进入前端目录：

```bash
cd frontend
```

安装 Vite 默认依赖：

```bash
npm install
```

### 注意事项

1. 项目名固定为 `frontend`。
2. 模板选择 `vue-ts`，也就是 Vue3 + TypeScript。
3. 如果提示是否安装 `create-vite`，输入 `y`。

## 八、步骤 4：配置 Vite

### 相对路径

```text
frontend/vite.config.ts
```

### 完整代码

```ts
import { fileURLToPath, URL } from 'node:url'

import vue from '@vitejs/plugin-vue'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
  server: {
    host: '0.0.0.0',
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://127.0.0.1:8000',
        changeOrigin: true,
      },
    },
  },
})
```

### 注意事项

1. 前端访问 `/api` 时，Vite 会代理到后端 `http://127.0.0.1:8000`。
2. 这样开发阶段不需要直接处理浏览器跨域。
3. 后端仍然保留 CORS 配置，方便 Swagger 和其他工具访问。

### 相对路径

```text

```

### 完整代码

```ts
import { createRouter, createWebHistory, type RouteRecordRaw } from 'vue-router'

const routes: RouteRecordRaw[] = [
  {
    path: '/',
    component: () => import('../layouts/BasicLayout.vue'),
    children: [
      {
        path: '',
        name: 'home',
        component: () => import('../views/HomeView.vue'),
        meta: {
          title: '首页',
        },
      },
    ],
  },
  {
    path: '/:pathMatch(.*)*',
    name: 'not-found',
    component: () => import('../views/NotFoundView.vue'),
    meta: {
      title: '页面不存在',
    },
  },
]

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes,
})

router.afterEach((to) => {
  const title = to.meta.title ? `${String(to.meta.title)} - JoyFit` : 'JoyFit'
  document.title = title
})

export default router
```

### 注意事项

1. 当前只配置首页和 404。
2. 登录页、后台页面、用户端页面在后续阶段逐步加入。
3. `BasicLayout` 作为主布局，后续后台菜单会挂在这里。

## 十四、步骤 10：创建 Axios 请求封装

### 相对路径

```text
frontend/src/api/http.ts
```

### 完整代码

```ts
import axios, {
  type AxiosError,
  type AxiosInstance,
  type AxiosRequestConfig,
  type InternalAxiosRequestConfig,
} from 'axios'
import { ElMessage } from 'element-plus'

import type { ApiResponse } from './types'

const http: AxiosInstance = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || '/api',
  timeout: 10000,
})

http.interceptors.request.use((config: InternalAxiosRequestConfig) => {
  const token = localStorage.getItem('joyfit_token')

  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }

  return config
})

http.interceptors.response.use(
  (response) => {
    const body = response.data as ApiResponse

    if (body && typeof body.code === 'number' && body.code !== 200) {
      ElMessage.error(body.message || '请求失败')
      return Promise.reject(body)
    }

    return response
  },
  (error: AxiosError<ApiResponse>) => {
    const status = error.response?.status
    const message = error.response?.data?.message || error.message || '网络请求失败'

    if (status !== 401) {
      ElMessage.error(message)
    }

    return Promise.reject(error)
  },
)

export async function request<T = unknown>(config: AxiosRequestConfig): Promise<T> {
  const response = await http.request<ApiResponse<T>>(config)
  return response.data.data
}

export default http
```

### 注意事项

1. Token 暂时从 `localStorage.joyfit_token` 读取，下一阶段会由登录模块写入。
2. 后端业务错误如果 `code !== 200`，前端统一提示。
3. HTTP 401 暂时不弹错误，下一阶段由登录权限模块统一处理跳转。

## 二十二、常见问题

### 1. `npm create vite@latest` 很慢或失败

原因：

网络连接 npm registry 不稳定。

修复：

稍后重试，或切换你本机常用的 npm 镜像源。

### 2. `npm run dev` 提示端口被占用

原因：

5173 端口已经有其他前端服务。

修复：

使用 Vite 提示的新端口访问，或者关闭占用端口的进程。

### 3. 页面空白

原因：

常见是 `main.ts`、`router/index.ts` 或组件路径写错。

修复：

1. 打开浏览器控制台查看报错。
2. 确认 `src/router/index.ts` 存在。
3. 确认 `BasicLayout.vue`、`HomeView.vue`、`NotFoundView.vue` 文件路径正确。

### 4. TypeScript 提示找不到模块

原因：

依赖未安装，或 IDE 没刷新 TypeScript 服务。

修复：

执行：

```bash
npm install
```

然后重启编辑器 TypeScript 服务。

### 5. 前端请求 `/api` 失败

原因：

后端没有启动，或者 Vite proxy 配置不正确。

修复：

1. 确认后端运行在 `http://127.0.0.1:8000`。
2. 确认 `vite.config.ts` 中配置了 `/api` proxy。
3. 重新启动 `npm run dev`。

### 问题 1：Vue 报 `Element is missing end tag`

#### 报错现象

执行：

```bash
npm run dev
```

Vite 报错：

```text
Internal server error: Element is missing end tag.
Plugin: vite:vue
File: frontend/src/layouts/BasicLayout.vue
```

或者：

```text
File: frontend/src/views/HomeView.vue
```

#### 原因分析

`BasicLayout.vue`、`HomeView.vue` 或 `NotFoundView.vue` 的 `<style scoped>` 没有写结束标签：

```vue
</style>
```

Vue 单文件组件必须保证 `<template>`、`<script>`、`<style>` 标签都完整闭合。编译器通常会在扫到 `<style scoped>` 时才发现前面的结构没有完整结束，所以报错位置看起来像是 CSS，其实是 SFC 标签没有闭合。

#### 修复办法

在每个 `.vue` 文件 CSS 最后补上：

```vue
</style>
```

#### 需要修改的文件

- 相对路径：`frontend/src/layouts/BasicLayout.vue`
- 修改说明：在文件最后补充 `</style>`
- 补丁：

```vue
@media (max-width: 760px) {
  .content-area {
    padding: 18px 16px;
  }
}
</style>
```

- 相对路径：`frontend/src/views/HomeView.vue`
- 修改说明：在文件最后补充 `</style>`
- 补丁：

```vue
@media (max-width: 640px) {
  .module-grid {
    grid-template-columns: 1fr;
  }
}
</style>
```

- 相对路径：`frontend/src/views/NotFoundView.vue`
- 修改说明：如果该文件也按文档创建了，同样在文件最后补充 `</style>`
- 补丁：

```vue
.not-found p {
  margin: 0 0 18px;
  color: #6b7280;
}
</style>
```

#### 处理完后再验证

重新运行：

```bash
npm run dev
```

如果标签闭合正确，`Element is missing end tag` 会消失，页面可以正常编译。

### 问题 2：TS2307 找不到 `.vue` 组件模块

#### 报错现象

TypeScript 报错：

```text
TS2307: Cannot find module '../layouts/BasicLayout.vue' or its corresponding type declarations.
TS2307: Cannot find module '../views/HomeView.vue' or its corresponding type declarations.
TS2307: Cannot find module '../views/NotFoundView.vue' or its corresponding type declarations.
```

#### 原因分析

`router/index.ts` 中导入的是 `.vue` 单文件组件：

```ts
component: () => import('../layouts/BasicLayout.vue')
```

如果项目缺少 Vite/Vue 的类型声明文件，TypeScript 不知道 `.vue` 文件可以作为模块导入，就会报 TS2307。

Vite 创建的 Vue + TypeScript 项目通常会生成 `src/vite-env.d.ts`，如果该文件被删除或没有创建，就需要手动补上。

#### 修复办法

新增 `frontend/src/vite-env.d.ts`，声明 Vite 环境类型和 `.vue` 模块类型。

#### 需要修改的文件

- 相对路径：`frontend/src/vite-env.d.ts`
- 修改说明：新增 Vue 单文件组件类型声明
- 完整代码：

```ts
/// <reference types="vite/client" />

declare module '*.vue' {
  import type { DefineComponent } from 'vue'

  const component: DefineComponent<Record<string, never>, Record<string, never>, unknown>
  export default component
}
```

#### 处理完后再验证

执行：

```bash
npm run build
```

如果类型声明生效，`router/index.ts` 中导入 `.vue` 文件的 TS2307 会消失。
