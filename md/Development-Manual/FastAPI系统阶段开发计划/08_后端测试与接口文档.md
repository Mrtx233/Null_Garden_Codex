## 一、阶段目标

本阶段目标是在后端主要业务模块已经完成的基础上，补充稳定的自动化测试、检查 OpenAPI 接口文档，并整理后端交付给前端前的接口验收清单。

完成本阶段后，后端应具备以下能力：

1. 自动检查核心接口是否出现在 OpenAPI 文档中。
2. 自动检查初始化角色和权限是否完整。
3. 自动检查核心 Schema 字段校验是否生效。
4. 自动检查统一响应结构是否稳定。
5. 可以导出 `openapi.json` 供前端、Apifox 或 Postman 使用。
6. 形成后端接口验收清单，供进入前端阶段前逐项确认。

## 二、本阶段开发顺序

```text
1. 创建 OpenAPI 路径测试

```

## 三、本阶段测试策略说明

本阶段先补充不依赖真实数据库写入的自动化测试。

原因：

1. 当前项目使用 MySQL，直接在自动化测试中写真实开发库，容易污染手动测试的数据。
2. SQLite 内存库和 MySQL 在 `BigInteger` 自增、日期时间、外键行为上并不完全一致，直接替换数据库容易出现假通过或假失败。
3. 当前阶段的重点是确认接口注册、文档生成、权限种子、字段校验和响应格式稳定。

因此本阶段自动化测试重点是：

1. OpenAPI 路由完整性。
2. 权限种子完整性。
3. Schema 字段校验。
4. 响应结构契约。

真实 CRUD 接口通过 Swagger 或 Apifox 按验收清单进行人工联调。后续引入更完整测试体系时，可单独配置 MySQL 测试库。

### 完整代码

```python
from app.main import app


def test_openapi_contains_core_paths() -> None:
    schema = app.openapi()
    paths = set(schema["paths"].keys())

    expected_paths = {
        "/api/health",
        "/api/auth/token",
        "/api/auth/login",
        "/api/auth/me",
        "/api/auth/permissions",
        "/api/auth/menus",
        "/api/system/roles",
        "/api/system/permissions",
        "/api/users",
        "/api/stores",
        "/api/course-categories",
        "/api/courses",
        "/api/action-categories",
        "/api/actions",
        "/api/content/slogans",
        "/api/content/events",
        "/api/home",
    }

    missing_paths = expected_paths - paths
    assert not missing_paths, f"missing openapi paths: {sorted(missing_paths)}"


def test_openapi_has_security_scheme() -> None:
    schema = app.openapi()
    components = schema.get("components", {})
    security_schemes = components.get("securitySchemes", {})

    assert security_schemes
    assert any(
        scheme.get("type") == "oauth2"
        for scheme in security_schemes.values()
    )
```

### 注意事项

1. 该测试不连接数据库，仅检查 FastAPI 已注册的接口文档。
2. 若新增业务模块后遗漏路由注册，该测试可较早发现问题。
3. 若后续接口路径调整，需同步修改 `expected_paths`。

```python
    permission_codes = {
        permission_code
        for permission_code, permission_name, menu_path in DEFAULT_PERMISSIONS

    assert REQUIRED_PERMISSIONS.issubset(permission_codes)

    permission_codes = [
        permission_code
        for permission_code, permission_name, menu_path in DEFAULT_PERMISSIONS

    assert len(permission_codes) == len(set(permission_codes))


def test_menu_permissions_have_expected_paths() -> None:
    permission_paths = {
        permission_code: menu_path
        for permission_code, permission_name, menu_path in DEFAULT_PERMISSIONS

    assert permission_paths["user:list"] == "/users"
    assert permission_paths["role:list"] == "/system/roles"
    assert permission_paths["permission:list"] == "/system/permissions"
    assert permission_paths["store:list"] == "/stores"
    assert permission_paths["course:list"] == "/courses"
    assert permission_paths["action:list"] == "/actions"
    assert permission_paths["event:list"] == "/content/events"
    assert permission_paths["slogan:list"] == "/content/slogans"
```

3. 菜单路径仅检查具有前端菜单含义的权限。

## 七、步骤 3：创建 Schema 校验测试

### 相对路径

```text
backend/tests/test_schema_validation.py
```

### 完整代码

```python
import pytest
from pydantic import ValidationError

from app.schemas.action import ActionCreate
from app.schemas.content import ActivityEventCreate, SloganCreate
from app.schemas.user import UserCreate


def test_action_create_rejects_invalid_difficulty() -> None:
    with pytest.raises(ValidationError):
        ActionCreate(
            action_name="杠铃卧推",
            category_id=1,
            action_difficulty=6,
            applicable_store_type=1,
        )


def test_action_create_rejects_invalid_store_type() -> None:
    with pytest.raises(ValidationError):
        ActionCreate(
            action_name="杠铃卧推",
            category_id=1,
            action_difficulty=3,
            applicable_store_type=3,
        )


def test_slogan_create_rejects_invalid_status() -> None:
    with pytest.raises(ValidationError):
        SloganCreate(
            slogan_name="首页主标语",
            slogan_content="用每一次训练，靠近更强的自己",
            status=2,
        )


def test_activity_event_create_accepts_date_string() -> None:
    event = ActivityEventCreate(
        title="JoyFit 夏季力量挑战赛",
        event_date="2026-07-18",
        location="上海 JoyFit 徐汇店",
        status="报名中",
        description="面向会员开放的力量挑战赛。",
    )

    assert event.event_date.isoformat() == "2026-07-18"


def test_user_create_rejects_bcrypt_unsafe_password_length() -> None:
    with pytest.raises(ValidationError):
        UserCreate(
            role_id=1,
            username="too_long_password_user",
            password="x" * 73,
        )
```

### 注意事项

1. `bcrypt` 对密码存在 72 字节限制，因此用户密码 Schema 限制最大长度为 72。
2. 动作难度限定为 1 到 5。
3. 动作适用门店类型限定为 1 到 2。
4. Slogan 状态限定为 0 或 1。

## 八、步骤 4：创建统一响应结构测试

### 相对路径

```text
backend/tests/test_response_contract.py
```

### 完整代码

```python
from datetime import date, datetime

from app.utils.response import fail, success


def test_success_response_contract() -> None:
    body = success(data={"name": "JoyFit"})

    assert body["code"] == 200
    assert body["message"] == "success"
    assert body["data"] == {"name": "JoyFit"}


def test_fail_response_contract() -> None:
    body = fail(message="permission denied", code=403)

    assert body["code"] == 403
    assert body["message"] == "permission denied"
    assert body["data"] is None


def test_response_json_encodes_date_and_datetime() -> None:
    body = success(
        data={
            "event_date": date(2026, 7, 18),
            "created_at": datetime(2026, 7, 18, 9, 30, 0),
        }
    )

    assert body["data"]["event_date"] == "2026-07-18"
    assert body["data"]["created_at"] == "2026-07-18T09:30:00"
```

### 注意事项

1. 所有接口响应应统一为 `code`、`message`、`data`。
2. 日期和时间由 `jsonable_encoder` 转换为字符串，便于前端消费。
3. 若后续修改统一响应结构，需同步调整本测试。

## 九、步骤 5：创建 OpenAPI 导出脚本

### 相对路径

```text
backend/scripts/export_openapi.py
```

### 完整代码

```python
import json
from pathlib import Path

from app.main import app


OUTPUT_PATH = Path("docs/openapi.json")


def main() -> None:
    schema = app.openapi()
    OUTPUT_PATH.parent.mkdir(parents=True, exist_ok=True)
    OUTPUT_PATH.write_text(
        json.dumps(schema, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )
    print(f"OpenAPI schema exported to {OUTPUT_PATH}")


if __name__ == "__main__":
    main()
```

### 运行命令

确保当前目录是：

```text

```

执行：

```bash
python scripts/export_openapi.py
```

运行后生成：

```text

```

### 注意事项

1. 运行脚本前无需启动 Uvicorn。
2. 该脚本仅读取 FastAPI 路由和 Schema，不会写入业务数据库。
3. 前端可将 `openapi.json` 导入 Apifox 或 Postman 查看接口。

## 十二、常见问题

### 1. `test_openapi_contains_core_paths` 失败

原因：

通常为新增接口未注册到 `backend/app/api/router.py`，或测试中的路径与实际接口路径不一致。

修复：

1. 打开 Swagger 查看真实路径。
2. 若路由遗漏注册，补充 `api_router.include_router(...)`。
3. 若接口路径已调整，同步修改 `expected_paths`。

### 2. `test_default_permissions_are_complete` 失败

原因：

`backend/app/db/seed.py` 中缺少某个业务权限。

修复：

1. 对照失败信息中的权限代码。
2. 将缺失权限补充到 `DEFAULT_PERMISSIONS`。
3. 重启服务，使种子数据自动补齐到数据库。

### 3. `test_schema_validation` 失败

原因：

Schema 字段范围被改动，或测试用例与当前业务规则不一致。

修复：

1. 若业务规则未变，修复 Schema。
2. 若业务规则已调整，修改测试期望。

### 4. `python scripts/export_openapi.py` 提示找不到 `app`

原因：

命令未在 `backend` 目录下执行。

修复：

先进入：

```bash
cd backend
```

再执行：

```bash
python scripts/export_openapi.py
```

### 5. 导出的 OpenAPI 没有最新接口

原因：

路由未注册，或导出前代码未保存。

修复：

1. 确认对应路由文件已被 `backend/app/api/router.py` 引入。
2. 重新执行导出脚本。
3. 打开 `docs/openapi.json` 搜索接口路径。

### 问题追加格式


### 问题 1：执行 `python3 scripts/export_openapi.py` 提示找不到 `app`

#### 报错现象

在 `backend` 目录下执行：

```bash
python3 scripts/export_openapi.py
```

报错：

```text
ModuleNotFoundError: No module named 'app'
```

#### 原因分析

直接以下列方式运行脚本时：

```bash
python3 scripts/export_openapi.py
```

Python 会优先将脚本所在目录 `backend/scripts` 加入模块搜索路径，而不会稳定地将 `backend` 根目录加入其中。

因此脚本中的：

```python
from app.main import app
```

无法找到 `backend/app` 这个包。

#### 修复办法

在脚本开头将 `backend` 根目录加入 `sys.path`。

#### 需要修改的文件

- 相对路径：`backend/scripts/export_openapi.py`
- 修改说明：导入 `app.main` 前，先将项目后端根目录加入 Python 模块搜索路径
- 完整代码：

```python
import json
import sys
from pathlib import Path


BACKEND_DIR = Path(__file__).resolve().parents[1]
if str(BACKEND_DIR) not in sys.path:
    sys.path.insert(0, str(BACKEND_DIR))

from app.main import app


OUTPUT_PATH = BACKEND_DIR / "docs" / "openapi.json"


def main() -> None:
    schema = app.openapi()
    OUTPUT_PATH.parent.mkdir(parents=True, exist_ok=True)
    OUTPUT_PATH.write_text(
        json.dumps(schema, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )
    print(f"OpenAPI schema exported to {OUTPUT_PATH}")


if __name__ == "__main__":
    main()
```
