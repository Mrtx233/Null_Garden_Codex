# 01_后端基础工程构建

## 一、阶段目标

本阶段目标是完成 FastAPI 后端项目的最小可运行基础工程。

完成本阶段后，后端应具备以下能力：

1. FastAPI 服务可以正常启动。
2. Swagger 文档可以正常访问。
3. 后端可以读取 `.env` 配置。
4. 后端可以连接 MySQL 数据库。
5. 后端具备统一响应格式。
6. 后端具备全局异常处理。
7. 后端具备健康检查接口。
8. 后续阶段可以直接在此基础上继续开发 ORM 模型、登录认证和业务接口。

## 二、本阶段开发顺序

本阶段只做后端基础工程，不做前端。

开发顺序：

```text
1. 创建 backend 目录
2. 创建 Python 虚拟环境
3. 安装后端依赖
4. 创建 FastAPI 基础目录结构
5. 创建环境变量配置文件
6. 编写配置读取模块
7. 编写数据库连接模块
8. 编写统一响应模块
9. 编写异常处理模块
10. 编写健康检查路由
11. 编写总路由
12. 编写 FastAPI 入口文件
13. 启动后端服务
14. 验证 Swagger、健康检查和数据库连接
```

## 九、文件 3：配置读取模块

### 相对路径

```text
backend/app/core/config.py
```

### 文件作用

读取 `.env` 配置，并提供全局 `settings` 对象。

后续数据库连接、JWT、CORS 都从这个文件读取配置。

### 完整代码

```python
from functools import lru_cache
from urllib.parse import quote_plus

from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        case_sensitive=True,
        extra="ignore",
    )

    APP_NAME: str = "FastAPI_Vue3_JoyFit"
    APP_ENV: str = "development"
    DEBUG: bool = True
    API_PREFIX: str = "/api"

    MYSQL_HOST: str = "127.0.0.1"
    MYSQL_PORT: int = 3306
    MYSQL_USER: str = "root"
    MYSQL_PASSWORD: str = ""
    MYSQL_DATABASE: str = "FastAPI_Vue3_JoyFit"
    MYSQL_CHARSET: str = "utf8mb4"
    SQLALCHEMY_ECHO: bool = False

    JWT_SECRET_KEY: str = "please-change-this-secret-key"
    JWT_ALGORITHM: str = "HS256"
    ACCESS_TOKEN_EXPIRE_MINUTES: int = 1440

    CORS_ORIGINS: str = "http://localhost:5173,http://127.0.0.1:5173"

    @property
    def SQLALCHEMY_DATABASE_URL(self) -> str:
        password = quote_plus(self.MYSQL_PASSWORD)
        return (
            f"mysql+pymysql://{self.MYSQL_USER}:{password}"
            f"@{self.MYSQL_HOST}:{self.MYSQL_PORT}/{self.MYSQL_DATABASE}"
            f"?charset={self.MYSQL_CHARSET}"
        )

    @property
    def BACKEND_CORS_ORIGINS(self) -> list[str]:
        return [
            origin.strip()
            for origin in self.CORS_ORIGINS.split(",")
            if origin.strip()
        ]


@lru_cache
def get_settings() -> Settings:
    return Settings()


settings = get_settings()
```

### 重点说明

1. `env_file=".env"` 表示程序运行时会读取 `backend/.env`。
2. `CORS_ORIGINS` 使用字符串保存，避免 `pydantic-settings` 把 `list[str]` 环境变量强制当 JSON 解析。
3. `quote_plus` 用于处理数据库密码中包含特殊字符的情况。
4. `settings` 是全局配置对象，其他文件可以直接导入使用。

## 十一、文件 5：数据库连接模块

### 相对路径

```text
backend/app/db/session.py
```

### 文件作用

创建数据库连接 Engine、数据库 Session，并提供 FastAPI 依赖函数 `get_db()`。

后续所有需要访问数据库的接口都通过 `Depends(get_db)` 获取数据库会话。

### 完整代码

```python
from collections.abc import Generator

from sqlalchemy import create_engine
from sqlalchemy.orm import Session, sessionmaker

from app.core.config import settings


engine = create_engine(
    settings.SQLALCHEMY_DATABASE_URL,
    echo=settings.SQLALCHEMY_ECHO,
    pool_pre_ping=True,
    pool_recycle=3600,
)

SessionLocal = sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine,
)


def get_db() -> Generator[Session, None, None]:
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

### 重点说明

| 配置 | 说明 |
| --- | --- |
| `pool_pre_ping=True` | 每次使用连接前先检测连接是否有效 |
| `pool_recycle=3600` | 避免 MySQL 长连接超时 |
| `autocommit=False` | 不自动提交事务 |
| `autoflush=False` | 不自动刷新对象状态 |

## 十二、文件 6：统一响应模块

### 相对路径

```text
backend/app/utils/response.py
```

### 文件作用

统一所有接口返回格式。

前端可以固定按 `code`、`message`、`data` 读取后端返回结果。

### 完整代码

```python
from typing import Any

from fastapi.encoders import jsonable_encoder


def build_response(
    code: int = 200,
    message: str = "success",
    data: Any = None,
) -> dict[str, Any]:
    return {
        "code": code,
        "message": message,
        "data": jsonable_encoder(data),
    }


def success(
    data: Any = None,
    message: str = "success",
    code: int = 200,
) -> dict[str, Any]:
    return build_response(code=code, message=message, data=data)


def fail(
    message: str = "error",
    code: int = 400,
    data: Any = None,
) -> dict[str, Any]:
    return build_response(code=code, message=message, data=data)
```

### 返回示例

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "status": "ok"
  }
}
```

## 十三、文件 7：全局异常处理模块

### 相对路径

```text
backend/app/core/exceptions.py
```

### 文件作用

统一处理业务异常、HTTP 异常、参数校验异常和未知异常。

这样前端接收到的错误也能保持统一结构。

### 完整代码

```python
from typing import Any

from fastapi import FastAPI, HTTPException, Request, status
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse

from app.utils.response import fail


class BusinessException(Exception):
    def __init__(
        self,
        message: str = "business error",
        code: int = 400,
        data: Any = None,
    ) -> None:
        self.message = message
        self.code = code
        self.data = data


async def business_exception_handler(
    request: Request,
    exc: BusinessException,
) -> JSONResponse:
    return JSONResponse(
        status_code=status.HTTP_200_OK,
        content=fail(message=exc.message, code=exc.code, data=exc.data),
    )


async def http_exception_handler(
    request: Request,
    exc: HTTPException,
) -> JSONResponse:
    message = exc.detail if isinstance(exc.detail, str) else "http error"
    return JSONResponse(
        status_code=exc.status_code,
        content=fail(message=message, code=exc.status_code),
    )


async def validation_exception_handler(
    request: Request,
    exc: RequestValidationError,
) -> JSONResponse:
    return JSONResponse(
        status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
        content=fail(
            message="request validation error",
            code=status.HTTP_422_UNPROCESSABLE_ENTITY,
            data=exc.errors(),
        ),
    )


async def unhandled_exception_handler(
    request: Request,
    exc: Exception,
) -> JSONResponse:
    return JSONResponse(
        status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
        content=fail(
            message="internal server error",
            code=status.HTTP_500_INTERNAL_SERVER_ERROR,
        ),
    )


def register_exception_handlers(app: FastAPI) -> None:
    app.add_exception_handler(BusinessException, business_exception_handler)
    app.add_exception_handler(HTTPException, http_exception_handler)
    app.add_exception_handler(RequestValidationError, validation_exception_handler)
    app.add_exception_handler(Exception, unhandled_exception_handler)
```

### 重点说明

1. `BusinessException` 用于后续业务主动抛错。
2. `HTTPException` 用于处理 FastAPI 标准 HTTP 错误。
3. `RequestValidationError` 用于处理请求参数校验失败。
4. `Exception` 用于兜底处理未知异常。

## 十四、文件 8：健康检查路由

### 相对路径

```text
backend/app/api/v1/health.py
```

### 文件作用

提供后端服务健康检查接口和数据库连接检查接口。

前端联调前，可以先调用这些接口确认后端是否正常。

### 完整代码

```python
from fastapi import APIRouter, Depends
from sqlalchemy import text
from sqlalchemy.orm import Session

from app.db.session import get_db
from app.utils.response import success


router = APIRouter(tags=["健康检查"])


@router.get("/health")
def health_check() -> dict:
    return success(
        data={
            "status": "ok",
            "service": "FastAPI_Vue3_JoyFit",
        }
    )


@router.get("/health/db")
def database_health_check(db: Session = Depends(get_db)) -> dict:
    db.execute(text("SELECT 1"))
    return success(
        data={
            "status": "ok",
            "database": "connected",
        }
    )
```

### 接口说明

| 接口 | 作用 |
| --- | --- |
| `GET /api/health` | 检查 FastAPI 服务是否正常 |
| `GET /api/health/db` | 检查 MySQL 数据库连接是否正常 |

## 十六、文件 10：FastAPI 主入口

### 相对路径

```text
backend/app/main.py
```

### 文件作用

创建 FastAPI 应用，注册 CORS、异常处理器和 API 路由。

运行后端时，Uvicorn 会加载这个文件中的 `app` 对象。

### 完整代码

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

from app.api.router import api_router
from app.core.config import settings
from app.core.exceptions import register_exception_handlers


def create_app() -> FastAPI:
    app = FastAPI(
        title=settings.APP_NAME,
        debug=settings.DEBUG,
        version="0.1.0",
        docs_url="/docs",
        redoc_url="/redoc",
        openapi_url="/openapi.json",
    )

    app.add_middleware(
        CORSMiddleware,
        allow_origins=settings.BACKEND_CORS_ORIGINS,
        allow_credentials=True,
        allow_methods=["*"],
        allow_headers=["*"],
    )

    register_exception_handlers(app)
    app.include_router(api_router, prefix=settings.API_PREFIX)

    return app


app = create_app()
```

### 重点说明

1. `create_app()` 方便后续测试或扩展应用初始化逻辑。
2. `allow_origins` 从 `.env` 读取，后续前端地址变更时不用改代码。
3. `app.include_router(api_router, prefix=settings.API_PREFIX)` 表示所有接口统一以 `/api` 开头。

### 问题 1：pydantic-settings 解析 CORS 环境变量失败

#### 报错现象

执行 `pytest` 或启动 `uvicorn` 时出现：

```text
pydantic_settings.exceptions.SettingsError: error parsing value for field "BACKEND_CORS_ORIGINS" from source "DotEnvSettingsSource"
json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)
```

#### 原因分析

原始写法中，`backend/app/core/config.py` 把 `BACKEND_CORS_ORIGINS` 定义成了：

```python
BACKEND_CORS_ORIGINS: list[str]
```

但是 `.env` 中写的是普通逗号字符串：

```env
BACKEND_CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

`pydantic-settings` 遇到 `list[str]` 类型时，会优先尝试把环境变量内容当成 JSON 解析。上面的逗号字符串不是合法 JSON，所以会抛出 `JSONDecodeError`。

#### 修复办法

不要直接把环境变量字段定义成 `list[str]`。

改成：

1. `.env` 中使用 `CORS_ORIGINS` 保存原始字符串。
2. `config.py` 中使用 `CORS_ORIGINS: str` 接收。
3. 再通过 `BACKEND_CORS_ORIGINS` 属性把字符串拆成列表。

#### 需要修改的文件 1

相对路径：

```text
backend/.env
```

修改说明：

把：

```env
BACKEND_CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

改成：

```env
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

#### 需要修改的文件 2

相对路径：

```text
backend/.env.example
```

修改说明：

把：

```env
BACKEND_CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

改成：

```env
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

#### 需要修改的文件 3

相对路径：

```text
backend/app/core/config.py
```

完整代码：

```python
from functools import lru_cache
from urllib.parse import quote_plus

from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        case_sensitive=True,
        extra="ignore",
    )

    APP_NAME: str = "FastAPI_Vue3_JoyFit"
    APP_ENV: str = "development"
    DEBUG: bool = True
    API_PREFIX: str = "/api"

    MYSQL_HOST: str = "127.0.0.1"
    MYSQL_PORT: int = 3306
    MYSQL_USER: str = "root"
    MYSQL_PASSWORD: str = ""
    MYSQL_DATABASE: str = "FastAPI_Vue3_JoyFit"
    MYSQL_CHARSET: str = "utf8mb4"
    SQLALCHEMY_ECHO: bool = False

    JWT_SECRET_KEY: str = "please-change-this-secret-key"
    JWT_ALGORITHM: str = "HS256"
    ACCESS_TOKEN_EXPIRE_MINUTES: int = 1440

    CORS_ORIGINS: str = "http://localhost:5173,http://127.0.0.1:5173"

    @property
    def SQLALCHEMY_DATABASE_URL(self) -> str:
        password = quote_plus(self.MYSQL_PASSWORD)
        return (
            f"mysql+pymysql://{self.MYSQL_USER}:{password}"
            f"@{self.MYSQL_HOST}:{self.MYSQL_PORT}/{self.MYSQL_DATABASE}"
            f"?charset={self.MYSQL_CHARSET}"
        )

    @property
    def BACKEND_CORS_ORIGINS(self) -> list[str]:
        return [
            origin.strip()
            for origin in self.CORS_ORIGINS.split(",")
            if origin.strip()
        ]


@lru_cache
def get_settings() -> Settings:
    return Settings()


settings = get_settings()
```

在 `backend` 目录执行：

```bash

```

再执行：

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

如果不再出现 `SettingsError`，说明该问题修复成功。

### 问题 2：pytest 显示 ModuleNotFoundError: No module named 'app'

#### 报错现象

执行 `pytest` 时出现：

```text
ImportError while importing test module 'tests/test_health.py'
ModuleNotFoundError: No module named 'app'
```

有时错误栈中还会出现类似路径：

```text
.../FastAPI_Vue3_JoyFit/backend/backend/tests/test_health.py
```

#### 原因分析

当前实际目录截图中，`app/` 位于 `backend/` 下，这个结构是正确的：

```text
FastAPI_Vue3_JoyFit/
  backend/
    app/
    tests/
```

但是 `backend` 根目录下多了一个：

```text
backend/__init__.py
```

这个文件会让 pytest 把 `backend` 目录也当成 Python 包处理，导致测试导入路径变成 `backend.tests.test_health`，从而引发路径混乱，错误信息里可能显示成 `backend/backend/tests/test_health.py`。

第一阶段文档里的 `__init__.py` 只需要放在这些目录中：

```text
backend/app/__init__.py
backend/app/api/__init__.py
backend/app/api/v1/__init__.py
backend/app/core/__init__.py
backend/app/db/__init__.py
backend/app/models/__init__.py
backend/app/schemas/__init__.py
backend/app/services/__init__.py
backend/app/utils/__init__.py
backend/tests/__init__.py
```

不需要创建：

```text
backend/__init__.py
```

#### 修复办法

删除 `backend` 根目录下的 `__init__.py`。

注意：这里删除的是：

```text
backend/__init__.py
```

不是：

```text
backend/app/__init__.py
```

#### 需要执行的命令

确保当前目录是：

```text
FastAPI_Vue3_JoyFit/backend
```

执行：

```bash
rm __init__.py
```

如果 pytest 仍然显示旧路径，可以再清理 Python 缓存和 pytest 缓存：

```bash
find . -name "__pycache__" -type d -prune -exec rm -rf {} +
rm -rf .pytest_cache
```

#### 修复后验证

确保当前目录是：

```text
FastAPI_Vue3_JoyFit/backend
```

执行：

```bash
pytest
```

如果导入问题消失，说明该问题修复成功。

### 问题 3：确认 uvicorn 启动目录和命令

#### 报错现象

启动服务时出现：

```text
ModuleNotFoundError: No module named 'app'
```

#### 原因分析

`uvicorn app.main:app` 要求当前执行目录下面必须直接存在 `app` 目录。

正确执行目录应该是：

```text
FastAPI_Vue3_JoyFit/backend
```

该目录下必须能看到：

```text
app/main.py
```

#### 修复办法

进入后端目录后再启动：

```bash
cd /你的项目路径/FastAPI_Vue3_JoyFit/backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

如果当前人在项目根目录 `FastAPI_Vue3_JoyFit/`，也可以这样启动：

```bash
uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```

但推荐第一种方式，后续所有后端命令都统一在 `backend` 目录执行。
