# 02_后端数据库模型与通用能力

## 一、阶段目标

本阶段目标是在第一阶段 FastAPI 基础工程之上，完成后端数据库模型层和通用能力层。

完成本阶段后，后端应具备以下能力：

1. 根据 `sql/ddl.sql` 完成 SQLAlchemy ORM 模型。
2. 所有业务表都能在 `Base.metadata.tables` 中被识别。
3. 建立主要外键关系和 ORM relationship。
4. 准备通用分页请求与分页响应结构。
5. 准备基础 CRUD Service，后续业务模块可复用。
6. 增强异常日志记录，方便排查后续业务错误。
7. 增加模型注册测试，确保模型和表名不漏。

本阶段仍然只做后端，不做前端页面。

## 三、重要原则

### 1. 不使用 ORM 自动建表

当前项目已经有完整的：

```text
sql/ddl.sql
```

所以本阶段不要在代码中执行：

```python
Base.metadata.create_all(bind=engine)
```

原因：

1. 数据库表结构由 DDL 统一管理。
2. ORM 只负责映射已有表。
3. 避免 ORM 自动建表和手写 DDL 不一致。

### 2. 模型字段必须对齐 DDL

需要重点对齐：

- 表名
- 主键字段名
- 外键字段名
- 字段类型
- 字符串长度
- 是否允许为空
- 唯一索引
- 普通索引
- 默认值

### 3. 主键名称不要统一改成 id

本项目 DDL 中有些表主键不是 `id`：

| 表名 | 主键 |
| --- | --- |
| `sys_user` | `user_id` |
| `sys_user_profile` | `profile_id` |
| `t_slogan_info` | `slogan_id` |
| `t_activity_event` | `event_id` |
| `t_store_province` | `province_id` |
| `t_store` | `store_id` |
| `t_course_category` | `category_id` |
| `t_course` | `course_id` |
| `y_user_course_favorite` | `favorite_id` |
| `t_action_category` | `category_id` |
| `t_action` | `action_id` |
| `y_user_action_favorite` | `favorite_id` |

ORM 模型必须保持这些字段名。

## 五、步骤 1：创建系统权限模型

### 要做什么

创建权限、角色、角色权限关联三张表的 ORM 模型。

### 为什么做

后续第三阶段登录认证与 RBAC 权限会依赖这些模型。

### 相对路径

```text
backend/app/models/system.py
```

### 完整代码

```python
from sqlalchemy import BigInteger, Column, ForeignKey, String
from sqlalchemy.orm import relationship

from app.db.base import Base


class SysPermission(Base):
    __tablename__ = "sys_permission"

    id = Column(BigInteger, primary_key=True, autoincrement=True, comment="权限ID")
    permission_code = Column(String(64), nullable=False, comment="权限标识符")
    permission_name = Column(String(64), nullable=False, comment="权限名称")
    menu_path = Column(String(255), nullable=True, comment="前端路由路径")

    role_permissions = relationship(
        "SysRolePermission",
        back_populates="permission",
        cascade="all, delete-orphan",
    )


class SysRole(Base):
    __tablename__ = "sys_role"

    id = Column(BigInteger, primary_key=True, autoincrement=True, comment="角色ID")
    role_code = Column(String(64), nullable=False, comment="角色代码")
    role_name = Column(String(64), nullable=False, comment="角色名称")

    role_permissions = relationship(
        "SysRolePermission",
        back_populates="role",
        cascade="all, delete-orphan",
    )
    users = relationship("SysUser", back_populates="role")
    user_stores = relationship("UserStore", back_populates="role")


class SysRolePermission(Base):
    __tablename__ = "sys_role_permission"

    id = Column(BigInteger, primary_key=True, autoincrement=True, comment="关联ID")
    role_id = Column(
        BigInteger,
        ForeignKey("sys_role.id"),
        nullable=False,
        comment="角色ID",
    )
    permission_id = Column(
        BigInteger,
        ForeignKey("sys_permission.id"),
        nullable=False,
        comment="权限ID",
    )

    role = relationship("SysRole", back_populates="role_permissions")
    permission = relationship("SysPermission", back_populates="role_permissions")
```

### 注意事项

1. `SysRole.users` 关联的是后面 `user.py` 中的 `SysUser`。
2. `SysRole.user_stores` 关联的是后面 `store.py` 中的 `UserStore`。
3. relationship 中使用字符串类名，可以避免直接导入造成循环依赖。

```python
    __tablename__ = "sys_user_profile"

    profile_id = Column(BigInteger, primary_key=True, autoincrement=True, comment="档案ID")
    user_id = Column(
        BigInteger,
        ForeignKey("sys_user.user_id"),
        nullable=False,
        comment="用户ID",
    )
    level = Column(Integer, nullable=True, comment="等级")
    gender = Column(Integer, nullable=True, comment="性别")
    birthday = Column(Date, nullable=True, comment="生日")
    height_cm = Column(DECIMAL(5, 2), nullable=True, comment="身高(cm)")
    weight_kg = Column(DECIMAL(5, 2), nullable=True, comment="体重(kg)")
    avatar_url = Column(String(255), nullable=True, comment="头像地址")
    intro = Column(Text, nullable=True, comment="简介")
    create_time = Column(DateTime, nullable=True, comment="账号创建时间")

    user = relationship("SysUser", back_populates="profile")
```

```python
    store_lng = Column(DECIMAL(10, 6), nullable=True, comment="门店经度")
    store_lat = Column(DECIMAL(10, 6), nullable=True, comment="门店纬度")

    province = relationship("StoreProvince", back_populates="stores")
    user_stores = relationship(
        "UserStore",
        back_populates="store",
        cascade="all, delete-orphan",
    )


class UserStore(Base):
    __tablename__ = "y_user_store"
    __table_args__ = (
        Index("idx_user_time", "user_id", "created_at"),
        Index("idx_user_store", "user_id", "store_id"),
        Index("idx_user_role_store", "user_id", "role_id", "store_id"),
    )

    id = Column(BigInteger, primary_key=True, autoincrement=True, comment="记录ID")
    user_id = Column(
        BigInteger,
        ForeignKey("sys_user.user_id"),
        nullable=False,
        comment="用户ID",
    )
    role_id = Column(
        BigInteger,
        ForeignKey("sys_role.id"),
        nullable=False,
        comment="角色ID",
    )
    store_id = Column(
        BigInteger,
        ForeignKey("t_store.store_id"),
        nullable=False,
        comment="门店ID",
    )
    created_at = Column(
        DateTime,
        server_default=text("CURRENT_TIMESTAMP"),
        nullable=True,
        comment="关联时间",
    )

    user = relationship("SysUser", back_populates="user_stores")
    role = relationship("SysRole", back_populates="user_stores")
    store = relationship("Store", back_populates="user_stores")
```

### 注意事项

1. `UserStore` 同时关联用户、角色、门店。
2. `__table_args__` 中补充了 DDL 中的三个索引。
3. `created_at` 使用数据库默认时间。

```python
from sqlalchemy.orm import relationship

from app.db.base import Base


class CourseCategory(Base):

        back_populates="course",

class UserCourseFavorite(Base):
    __tablename__ = "y_user_course_favorite"
    __table_args__ = (
        UniqueConstraint("user_id", "course_id", name="uk_user_course"),
    )

    favorite_id = Column(BigInteger, primary_key=True, autoincrement=True, comment="收藏记录ID")
    user_id = Column(
        BigInteger,
        ForeignKey("sys_user.user_id"),
        nullable=False,
        comment="用户ID",
    )
    course_id = Column(
        BigInteger,
        ForeignKey("t_course.course_id"),
        nullable=False,
        comment="课程ID",
    )
    created_at = Column(
        DateTime,
        server_default=text("CURRENT_TIMESTAMP"),
        nullable=True,
        comment="收藏时间",
```

```python
from typing import Generic, TypeVar

from pydantic import BaseModel, ConfigDict, Field


T = TypeVar("T")


class ORMBaseModel(BaseModel):
    model_config = ConfigDict(from_attributes=True)


class PageQuery(BaseModel):
    page: int = Field(default=1, ge=1, description="页码")
    page_size: int = Field(default=10, ge=1, le=100, description="每页数量")


class PageResult(BaseModel, Generic[T]):
    items: list[T]
    total: int
    page: int
    page_size: int
    pages: int


class IdResponse(BaseModel):
    id: int
```

## 十三、步骤 9：创建通用分页工具

### 要做什么

创建 SQLAlchemy 查询分页工具。

### 为什么做

后续所有列表接口都可以复用，不需要每个模块重复写分页逻辑。

### 相对路径

```text
backend/app/utils/pagination.py
```

### 完整代码

```python
from math import ceil
from typing import Any

from sqlalchemy import Select, func, select
from sqlalchemy.orm import Session

from app.schemas.common import PageResult


def paginate(
    db: Session,
    stmt: Select,
    page: int = 1,
    page_size: int = 10,
) -> PageResult[Any]:
    page = max(page, 1)
    page_size = min(max(page_size, 1), 100)

    count_stmt = select(func.count()).select_from(stmt.order_by(None).subquery())
    total = db.scalar(count_stmt) or 0

    offset = (page - 1) * page_size
    items = db.execute(stmt.offset(offset).limit(page_size)).scalars().all()
    pages = ceil(total / page_size) if total else 0

    return PageResult(
        items=list(items),
        total=total,
        page=page,
        page_size=page_size,
        pages=pages,
    )
```

### 使用示例

```python
from sqlalchemy import select

from app.models.user import SysUser
from app.utils.pagination import paginate


stmt = select(SysUser).order_by(SysUser.user_id.desc())
result = paginate(db, stmt, page=1, page_size=10)
```

### 注意事项

该分页工具适合：

```python
select(Model)
```

如果后续接口使用多表查询并返回多个字段，需要单独扩展分页函数。

### 完整代码

```python
from typing import Any, Generic, TypeVar

from pydantic import BaseModel
from sqlalchemy.orm import Session

from app.db.base import Base


ModelType = TypeVar("ModelType", bound=Base)
CreateSchemaType = TypeVar("CreateSchemaType", bound=BaseModel)
UpdateSchemaType = TypeVar("UpdateSchemaType", bound=BaseModel)


class BaseService(Generic[ModelType, CreateSchemaType, UpdateSchemaType]):
    def __init__(self, model: type[ModelType]) -> None:
        self.model = model

    def get(self, db: Session, primary_key: Any) -> ModelType | None:
        return db.get(self.model, primary_key)

    def create(self, db: Session, obj_in: CreateSchemaType) -> ModelType:
        obj_data = obj_in.model_dump()
        db_obj = self.model(**obj_data)
        db.add(db_obj)
        db.commit()
        db.refresh(db_obj)
        return db_obj

    def update(
        self,
        db: Session,
        db_obj: ModelType,
        obj_in: UpdateSchemaType | dict[str, Any],
    ) -> ModelType:
        if isinstance(obj_in, dict):
            update_data = obj_in
        else:
            update_data = obj_in.model_dump(exclude_unset=True)

        for field, value in update_data.items():
            if hasattr(db_obj, field):
                setattr(db_obj, field, value)

        db.add(db_obj)
        db.commit()
        db.refresh(db_obj)
        return db_obj

    def delete(self, db: Session, db_obj: ModelType) -> None:
        db.delete(db_obj)
        db.commit()
```

### 注意事项

1. `BaseService` 只放通用逻辑。
2. 复杂业务不要硬塞到这里，应放到具体模块 Service。
3. 删除方法接收 `db_obj`，避免直接按 ID 删除时误删或绕过业务校验。

### 完整代码

```python
import logging
from typing import Any

from fastapi import FastAPI, HTTPException, Request, status
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse

from app.utils.response import fail


logger = logging.getLogger(__name__)


class BusinessException(Exception):
    def __init__(
        self,
        message: str = "business error",
        code: int = 400,
        data: Any = None,
    ) -> None:
        self.message = message
        self.code = code
        self.data = data


async def business_exception_handler(
    request: Request,
    exc: BusinessException,
) -> JSONResponse:
    return JSONResponse(
        status_code=status.HTTP_200_OK,
        content=fail(message=exc.message, code=exc.code, data=exc.data),
    )


async def http_exception_handler(
    request: Request,
    exc: HTTPException,
) -> JSONResponse:
    message = exc.detail if isinstance(exc.detail, str) else "http error"
    return JSONResponse(
        status_code=exc.status_code,
        content=fail(message=message, code=exc.status_code),
    )


async def validation_exception_handler(
    request: Request,
    exc: RequestValidationError,
) -> JSONResponse:
    return JSONResponse(
        status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
        content=fail(
            message="request validation error",
            code=status.HTTP_422_UNPROCESSABLE_ENTITY,
            data=exc.errors(),
        ),
    )


async def unhandled_exception_handler(
    request: Request,
    exc: Exception,
) -> JSONResponse:
    logger.exception(
        "Unhandled exception: method=%s path=%s",
        request.method,
        request.url.path,
    )
    return JSONResponse(
        status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
        content=fail(
            message="internal server error",
            code=status.HTTP_500_INTERNAL_SERVER_ERROR,
        ),
    )


def register_exception_handlers(app: FastAPI) -> None:
    app.add_exception_handler(BusinessException, business_exception_handler)
    app.add_exception_handler(HTTPException, http_exception_handler)
    app.add_exception_handler(RequestValidationError, validation_exception_handler)
    app.add_exception_handler(Exception, unhandled_exception_handler)
```

### 注意事项

1. `logger.exception(...)` 会自动记录异常堆栈。
2. 返回给前端的内容仍然保持统一格式。
3. 不要把真实异常堆栈直接返回给前端。

## 二十二、常见问题

### 1. relationship 找不到类名

#### 报错示例

```text
sqlalchemy.exc.InvalidRequestError: expression 'SysUser' failed to locate a name
```

#### 原因

某个模型没有在 `backend/app/models/__init__.py` 中导入，SQLAlchemy 没有完成模型注册。

#### 修复

检查：

```text
backend/app/models/__init__.py
```

确认所有模型都已经导入。

### 2. 表名没有注册到 Base.metadata

#### 报错示例

```text
AssertionError: EXPECTED_TABLES.issubset(registered_tables)
```

#### 原因

模型文件没有被导入，或者 `__tablename__` 写错。

#### 修复

1. 检查模型文件中的 `__tablename__`。
2. 检查 `models/__init__.py` 是否导入该模型。
3. 重新执行 `pytest`。

### 3. ImportError: cannot import name

#### 原因

通常是文件名、类名、导入路径不一致。

#### 修复

确认导入路径统一使用：

```python
from app.models.xxx import Xxx
```

不要写成：

```python
from backend.app.models.xxx import Xxx
```

前提是命令执行目录为：

```text
FastAPI_Vue3_JoyFit/backend
```

### 补充 1：未执行 SQL 文件时，使用 ORM 自动创建数据库和数据表

#### 需求说明

如果没有执行：

```text
sql/ddl.sql
```

那么 MySQL 中可能还没有：

```text
FastAPI_Vue3_JoyFit
```

也没有任何业务表。

这种情况下，第二阶段需要增加 ORM 自动建表能力。

开发环境推荐流程：

```text
启动 FastAPI -> 检查数据库是否存在 -> 不存在则创建数据库 -> 导入所有 ORM 模型 -> 自动创建数据表
```

#### 重要说明

ORM 自动建表适合开发阶段快速启动项目。

但是需要知道：

1. `Base.metadata.create_all()` 只会创建不存在的表。
2. `Base.metadata.create_all()` 不会自动修改已经存在的表结构。
3. `Base.metadata.create_all()` 不会删除多余字段。
4. `Base.metadata.create_all()` 不负责插入初始化数据。
5. MySQL 的 `ON UPDATE CURRENT_TIMESTAMP` 这类细节，ORM 自动建表可能和手写 DDL 不完全一致。
6. 后续正式项目仍建议使用 Alembic 或 SQL 文件管理结构变更。

```python
        )

    @property
    def BACKEND_CORS_ORIGINS(self) -> list[str]:
        return [
            origin.strip()
            for origin in self.CORS_ORIGINS.split(",")
            if origin.strip()
        ]


@lru_cache
def get_settings() -> Settings:
    return Settings()


settings = get_settings()
```

#### 需要新增的文件

相对路径：

```text
backend/app/db/init_db.py
```

文件作用：

1. 先连接 MySQL 服务。
2. 自动创建数据库 `FastAPI_Vue3_JoyFit`。
3. 导入全部 ORM 模型。
4. 调用 `Base.metadata.create_all()` 自动创建数据表。

完整代码：

```python
import logging
import re

from sqlalchemy import create_engine, text

from app.core.config import settings
from app.db.base import Base
from app.db.session import engine


logger = logging.getLogger(__name__)


def validate_database_name(database_name: str) -> str:
    if not re.fullmatch(r"[A-Za-z0-9_]+", database_name):
        raise ValueError("MYSQL_DATABASE can only contain letters, numbers, and underscores")
    return database_name


def create_database_if_not_exists() -> None:
    database_name = validate_database_name(settings.MYSQL_DATABASE)

    server_engine = create_engine(
        settings.SQLALCHEMY_SERVER_URL,
        isolation_level="AUTOCOMMIT",
        pool_pre_ping=True,
    )

    create_database_sql = text(
        f"CREATE DATABASE IF NOT EXISTS `{database_name}` "
        f"CHARACTER SET {settings.MYSQL_CHARSET} "
        "COLLATE utf8mb4_general_ci"
    )

    with server_engine.connect() as connection:
        connection.execute(create_database_sql)

    server_engine.dispose()
    logger.info("Database checked: %s", database_name)


def create_tables_if_not_exists() -> None:
    import app.models  # noqa: F401

    Base.metadata.create_all(bind=engine)
    logger.info("Database tables checked")


def init_db() -> None:
    create_database_if_not_exists()
    create_tables_if_not_exists()
```

#### 需要修改的文件 4

相对路径：

```text
backend/app/main.py
```

修改说明：

1. 增加 `lifespan`。
2. 启动时判断 `AUTO_CREATE_TABLES`。
3. 如果为 `true`，自动创建数据库和数据表。

完整代码：

```python
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

from app.api.router import api_router
from app.core.config import settings
from app.core.exceptions import register_exception_handlers
from app.core.logging import setup_logging
from app.db.init_db import init_db


@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    if settings.AUTO_CREATE_TABLES:
        init_db()
    yield


def create_app() -> FastAPI:
    setup_logging()

    app = FastAPI(
        title=settings.APP_NAME,
        debug=settings.DEBUG,
        version="0.1.0",
        docs_url="/docs",
        redoc_url="/redoc",
        openapi_url="/openapi.json",
        lifespan=lifespan,
    )

    app.add_middleware(
        CORSMiddleware,
        allow_origins=settings.BACKEND_CORS_ORIGINS,
        allow_credentials=True,
        allow_methods=["*"],
        allow_headers=["*"],
    )

    register_exception_handlers(app)
    app.include_router(api_router, prefix=settings.API_PREFIX)

    return app


app = create_app()
```

#### 常见报错 1：Access denied

报错示例：

```text
pymysql.err.OperationalError: (1044, "Access denied for user ...")
```

原因：

当前 MySQL 用户没有创建数据库的权限。

修复：

1. 换成有建库权限的 MySQL 用户。
2. 或者先手动创建数据库，再让 ORM 自动创建表。

手动创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS `FastAPI_Vue3_JoyFit`
CHARACTER SET utf8mb4
COLLATE utf8mb4_general_ci;
```

#### 常见报错 2：Unknown database

报错示例：

```text
pymysql.err.OperationalError: (1049, "Unknown database 'FastAPI_Vue3_JoyFit'")
```

原因：

直接使用了连接具体数据库的 Engine，但数据库还不存在。

修复：

必须先用 `SQLALCHEMY_SERVER_URL` 连接 MySQL 服务本身，创建数据库后，再使用 `SQLALCHEMY_DATABASE_URL` 创建表。

上面的 `init_db.py` 已经按这个顺序处理。

#### 常见报错 3：NoReferencedTableError

报错示例：

```text
sqlalchemy.exc.NoReferencedTableError
```

原因：

某些模型没有被导入，导致外键引用的父表没有注册到 `Base.metadata`。

修复：

确认：

```text
backend/app/models/__init__.py
```

已经导入所有模型。

并且 `init_db.py` 中有：

```python
import app.models  # noqa: F401
```

#### 阶段建议

开发阶段可以保持：

```env
AUTO_CREATE_TABLES=true
```

后续如果开始使用 Alembic 管理迁移，建议改成：

```env
AUTO_CREATE_TABLES=false
```
