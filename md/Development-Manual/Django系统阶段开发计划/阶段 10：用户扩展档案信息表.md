# 一、本阶段要实现的表
你给的 SQL 是：

```sql
CREATE TABLE `sys_user_profile` (
    `profile_id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '档案ID',
    `user_id` BIGINT NOT NULL COMMENT '用户ID',
    `level` INT DEFAULT NULL COMMENT '等级',
    `gender` INT DEFAULT NULL COMMENT '性别',
    `birthday` DATE DEFAULT NULL COMMENT '生日',
    `height_cm` DECIMAL(5,2) DEFAULT NULL COMMENT '身高(cm)',
    `weight_kg` DECIMAL(5,2) DEFAULT NULL COMMENT '体重(kg)',
    `avatar_url` VARCHAR(255) DEFAULT NULL COMMENT '头像地址',
    `intro` TEXT DEFAULT NULL COMMENT '简介',
    `create_time` DATETIME DEFAULT NULL COMMENT '账号创建时间',
    `join_time` DATETIME DEFAULT NULL COMMENT '入职/开卡时间',
    `expire_date` DATE DEFAULT NULL COMMENT '到期/停卡时间',
    PRIMARY KEY (`profile_id`),
    CONSTRAINT `fk_profile_user` FOREIGN KEY (`user_id`) REFERENCES `sys_user` (`user_id`)
) ENGINE=InnoDB COMMENT='用户扩展档案信息';
```

它的关系是：

```latex
sys_user
  ↓ user_id
sys_user_profile
```

也就是：

```latex
一个用户可以有一份扩展档案信息
```

注意：你给的 SQL 里没有给 `user_id` 加唯一约束，所以数据库层面允许一个用户有多条档案记录。我们这一阶段先严格按照你的 SQL 来实现。

# 二、修改模型文件
打开文件：

```latex
backend/rbac/models.py
```

在文件最下面，也就是 `SysUser` 类后面，继续追加下面这个模型。

## `backend/rbac/models.py`
```python
class SysUserProfile(models.Model):
    """
    用户扩展档案信息表
    对应 MySQL 表：sys_user_profile
    """

    GENDER_CHOICES = (
        (0, "未知"),
        (1, "男"),
        (2, "女"),
    )

    profile_id = models.BigAutoField(
        primary_key=True,
        verbose_name="档案ID"
    )

    user = models.ForeignKey(
        SysUser,
        on_delete=models.PROTECT,
        db_column="user_id",
        related_name="profiles",
        verbose_name="用户ID"
    )

    level = models.IntegerField(
        null=True,
        blank=True,
        verbose_name="等级"
    )

    gender = models.IntegerField(
        null=True,
        blank=True,
        choices=GENDER_CHOICES,
        verbose_name="性别"
    )

    birthday = models.DateField(
        null=True,
        blank=True,
        verbose_name="生日"
    )

    height_cm = models.DecimalField(
        max_digits=5,
        decimal_places=2,
        null=True,
        blank=True,
        verbose_name="身高(cm)"
    )

    weight_kg = models.DecimalField(
        max_digits=5,
        decimal_places=2,
        null=True,
        blank=True,
        verbose_name="体重(kg)"
    )

    avatar_url = models.CharField(
        max_length=255,
        null=True,
        blank=True,
        verbose_name="头像地址"
    )

    intro = models.TextField(
        null=True,
        blank=True,
        verbose_name="简介"
    )

    create_time = models.DateTimeField(
        null=True,
        blank=True,
        verbose_name="账号创建时间"
    )

    join_time = models.DateTimeField(
        null=True,
        blank=True,
        verbose_name="入职/开卡时间"
    )

    expire_date = models.DateField(
        null=True,
        blank=True,
        verbose_name="到期/停卡时间"
    )

    class Meta:
        db_table = "sys_user_profile"
        verbose_name = "用户扩展档案"
        verbose_name_plural = "用户扩展档案"

    def __str__(self):
        return f"{self.user.username} 的档案"
```

# 三、解释这个模型
## 1. `profile_id`
对应 SQL：

```sql
profile_id BIGINT NOT NULL AUTO_INCREMENT
```

Django 写法：

```python
profile_id = models.BigAutoField(primary_key=True)
```

作用：

```latex
档案表主键，自增 ID
```

---

## 2. `user`
对应 SQL：

```sql
user_id BIGINT NOT NULL
CONSTRAINT fk_profile_user FOREIGN KEY (`user_id`) REFERENCES `sys_user` (`user_id`)
```

Django 写法：

```python
user = models.ForeignKey(
    SysUser,
    on_delete=models.PROTECT,
    db_column="user_id"
)
```

作用：

```latex
当前档案属于哪个用户
```

例如：

```latex
admin 用户 -> admin 的档案
zhangsan 用户 -> zhangsan 的档案
```

这里使用：

```python
on_delete=models.PROTECT
```

意思是：

```latex
如果这个用户还有档案，不允许直接删除用户
```

这样比较安全。

---

## 3. `gender`
我们设置了：

```python
GENDER_CHOICES = (
    (0, "未知"),
    (1, "男"),
    (2, "女"),
)
```

所以数据库里存数字：

```latex
0 未知
1 男
2 女
```

Admin 后台会显示中文。

---

## 4. `height_cm` 和 `weight_kg`
对应 SQL：

```sql
DECIMAL(5,2)
```

Django 写法：

```python
models.DecimalField(max_digits=5, decimal_places=2)
```

意思是最多 5 位数字，其中 2 位小数。

例如：

```latex
180.50
65.20
```
