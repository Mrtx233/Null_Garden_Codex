## 1. 阶段目标与接口范围

本阶段目标：

```text
1. 查询省份/区域列表
2. 查询门店列表
3. 查询门店详情
4. 查询当前登录用户关联的门店
```

实现基于以下三张表：

```text
t_store_province   门店所属省份/区域表
t_store            门店基础信息表
y_user_store       用户与门店关联表
```

三张表的结构来自已定稿的业务表设计：`t_store` 通过 `province_id` 关联省份表，`y_user_store` 通过 `user_id`、`role_id`、`store_id` 关联用户、角色和门店。

本阶段暂不实现的内容：

```text
新增门店
修改门店
删除门店
Vue 页面
RBAC 菜单权限
```

**本章要点**：

- **要点**：本阶段只做查询（只读）接口，写操作与前端页面均排除在外。
- **要点**：4 个接口分别落在省份表、门店表与用户门店关系表之上，覆盖三张表的全部典型查询形态。
- **要点**：本阶段形成的视图-序列化-路由三层模式将直接复用于阶段 15、16。

## 2. 接口规划

门店相关接口统一放在 `/api/store/` 前缀下。最终接口如下：

| 方法 | 路径 | 参数 | 返回说明 | 是否需要登录 |
|------|------|------|----------|--------------|
| GET | `/api/store/provinces/` | 无 | 省份/区域列表 | 需要 |
| GET | `/api/store/stores/` | 查询参数（均可选）：`province_id`、`city`、`store_type`、`keyword`、`is_operating` | 门店列表，支持条件筛选 | 需要 |
| GET | `/api/store/stores/<store_id>/` | 路径参数：`store_id` | 单个门店详情；ID 不存在时返回 404 | 需要 |
| GET | `/api/store/my-stores/` | 无 | 当前登录用户关联的门店列表 | 需要 |

门店列表接口的筛选参数含义：

| 筛选参数 | 作用 |
|----------|------|
| `province_id` | 按省份筛选 |
| `city` | 按城市筛选 |
| `store_type` | 按门店类型筛选 |
| `keyword` | 按门店名称模糊搜索 |
| `is_operating` | 按是否营业筛选 |

**本章要点**：

- **要点**：4 个接口均为 GET 只读接口，统一受登录保护。
- **要点**：列表与详情的区分依靠路径中是否携带 `<store_id>` 参数。
- **要点**：`my-stores` 不接收任何参数，用户身份完全由登录 token 决定。

## 4. 视图层实现

打开文件：

```text
backend/store/views.py
```

将内容替换为以下完整代码。文件内部按职责分为两部分：`format_decimal_value`、`format_datetime_value` 两个格式化工具函数与 `serialize_province`、`serialize_store`、`serialize_user_store` 三个序列化函数负责把模型对象转为 JSON 字典；4 个类视图各负责一个接口，均通过 `@login_required` 装饰器要求登录。

`backend/store/views.py`：

```python
from django.views import View

from rbac.auth import login_required
from rbac.responses import json_response

from .models import StoreProvince, Store, UserStore


def format_decimal_value(value):
    """
    Decimal 转字符串，避免 JSON 序列化问题。
    """

    if value is None:
        return None

    return str(value)


def format_datetime_value(value):
    """
    datetime 转字符串。
    """

    if value is None:
        return None

    return value.strftime("%Y-%m-%d %H:%M:%S")


def serialize_province(province):
    """
    省份对象转 JSON 字典。
    """

    return {
        "province_id": province.province_id,
        "province_name": province.province_name,
        "center_lng": format_decimal_value(province.center_lng),
        "center_lat": format_decimal_value(province.center_lat),
    }


def serialize_store(store):
    """
    门店对象转 JSON 字典。
    """

    return {
        "store_id": store.store_id,
        "store_name": store.store_name,
        "store_type": store.store_type,
        "store_type_text": store.get_store_type_display(),

        "province_id": store.province_id,
        "province_name": store.province_name or store.province.province_name,

        "city": store.city,
        "district": store.district,
        "address": store.address,

        "store_phone": store.store_phone,
        "store_image_url": store.store_image_url,
        "store_introduction": store.store_introduction,
        "business_hours": store.business_hours,

        "is_operating": store.is_operating,
        "is_operating_text": store.get_is_operating_display(),

        "store_lng": format_decimal_value(store.store_lng),
        "store_lat": format_decimal_value(store.store_lat),
    }


def serialize_user_store(user_store):
    """
    用户门店关系对象转 JSON 字典。
    """

    store = user_store.store
    user = user_store.user
    role = user_store.role

    return {
        "id": user_store.id,

        "user_id": user.user_id,
        "username": user.username,
        "real_name": user.real_name,

        "role_id": role.id,
        "role_code": role.role_code,
        "role_name": role.role_name,

        "store": serialize_store(store),

        "created_at": format_datetime_value(user_store.created_at),
    }


class StoreProvinceListView(View):
    """
    省份/区域列表接口

    GET /api/store/provinces/
    """

    @login_required
    def get(self, request):
        provinces = StoreProvince.objects.all().order_by("province_id")

        data = []

        for province in provinces:
            data.append(serialize_province(province))

        return json_response(
            data=data,
            message="获取省份列表成功",
        )


class StoreListView(View):
    """
    门店列表接口

    GET /api/store/stores/

    可选查询参数：
    province_id
    city
    store_type
    keyword
    is_operating
    """

    @login_required
    def get(self, request):
        queryset = Store.objects.select_related("province").all().order_by("store_id")

        province_id = request.GET.get("province_id")
        city = request.GET.get("city")
        store_type = request.GET.get("store_type")
        keyword = request.GET.get("keyword")
        is_operating = request.GET.get("is_operating")

        if province_id:
            queryset = queryset.filter(province_id=province_id)

        if city:
            queryset = queryset.filter(city=city)

        if store_type:
            queryset = queryset.filter(store_type=store_type)

        if keyword:
            queryset = queryset.filter(store_name__icontains=keyword)

        if is_operating in ["0", "1"]:
            queryset = queryset.filter(is_operating=int(is_operating))

        data = []

        for store in queryset:
            data.append(serialize_store(store))

        return json_response(
            data=data,
            message="获取门店列表成功",
        )


class StoreDetailView(View):
    """
    门店详情接口

    GET /api/store/stores/<store_id>/
    """

    @login_required
    def get(self, request, store_id):
        store = Store.objects.select_related("province").filter(
            store_id=store_id
        ).first()

        if store is None:
            return json_response(
                message="门店不存在",
                code=404,
                status=404,
            )

        return json_response(
            data=serialize_store(store),
            message="获取门店详情成功",
        )


class MyStoreListView(View):
    """
    当前登录用户关联门店接口

    GET /api/store/my-stores/
    """

    @login_required
    def get(self, request):
        current_user = request.current_user

        user_stores = UserStore.objects.select_related(
            "user",
            "role",
            "store",
            "store__province",
        ).filter(
            user=current_user
        ).order_by("-created_at")

        data = []

        for item in user_stores:
            data.append(serialize_user_store(item))

        return json_response(
            data=data,
            message="获取当前用户关联门店成功",
        )
```

**本章要点**：

- **要点**：Decimal 与 datetime 字段无法直接被 JSON 序列化，统一在 `format_decimal_value`、`format_datetime_value` 中转为字符串。
- **要点**：`serialize_store` 通过 `get_store_type_display()`、`get_is_operating_display()` 附带枚举值的中文文本，前端无需重复维护映射。
- **要点**：列表查询使用 `select_related` 预加载关联对象，避免序列化阶段逐条触发额外查询。
- **要点**：`my-stores` 从 `request.current_user` 取得当前用户，身份来源是 JWT token，不信任任何请求参数。
- **要点**：详情接口的"不存在"分支返回 code=404 且 HTTP 状态码同为 404，与成功响应结构保持一致。

## 5. 应用路由配置

新建文件：

```text
backend/store/urls.py
```

写入：

```python
from django.urls import path

from .views import (
    StoreProvinceListView,
    StoreListView,
    StoreDetailView,
    MyStoreListView,
)

urlpatterns = [
    path("provinces/", StoreProvinceListView.as_view()),
    path("stores/", StoreListView.as_view()),
    path("stores/<int:store_id>/", StoreDetailView.as_view()),
    path("my-stores/", MyStoreListView.as_view()),
]
```

`<int:store_id>` 转换器限定该段必须为整数，非整数的详情请求不会命中该路由。

**本章要点**：

- **要点**：应用路由只写相对路径，`/api/store/` 前缀由项目总路由提供。
- **要点**：类视图通过 `.as_view()` 转换为可被 `path` 接收的函数。
- **要点**：路径参数使用 `int` 转换器，天然过滤非法 ID 格式。

```bash
  -H "Content-Type: application/json" \
```


复制 zhangsan 的 `access_token`，再请求：

```bash
curl -X GET http://127.0.0.1:8000/api/store/my-stores/ \
  -H "Authorization: Bearer 你的zhangsan_access_token"

```

### 8.2 不带 token 的请求

直接请求：

```bash
curl -X GET http://127.0.0.1:8000/api/store/stores/
```

应返回：

```json
{
  "code": 401,
  "message": "未提供 access_token",
  "data": null
}
```

说明接口已被登录保护。

**本章要点**：

- **要点**：不同用户的 `my-stores` 结果不同，用户身份完全来自 token。
- **要点**：缺少 Authorization 头时统一返回 401，而非空列表或错误页。

## 常见问题与排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 请求返回 `{"code": 401, "message": "未提供 access_token"}` | 未携带 Authorization 请求头，接口受 `login_required` 保护 | 先调用 `/api/login/` 获取 `access_token`，以 `Bearer <token>` 形式加入请求头 |
| 门店详情返回 `门店不存在`（404） | 路径中的 `store_id` 在 `t_store` 中无对应记录 | 通过门店列表接口或 `t_store` 表确认有效 ID |
| `keyword` 筛选无结果 | 门店名称中不含该关键词；`icontains` 为子串匹配 | 换用更短的关键词重试，如用"广州"代替完整门店名 |
| `is_operating` 筛选不生效 | 后端仅当取值为 `"0"` 或 `"1"` 时才应用该过滤条件 | 该参数只传 0 或 1 |
| 经纬度字段返回为字符串 | Decimal 值在序列化函数中统一转为字符串，避免 JSON 序列化问题 | 属接口约定，接收方按字符串解析 |
| `my-stores` 返回空列表 | 阶段 13 的 `y_user_store` 关系数据未初始化 | 执行 `python manage.py init_business_data` 后核对用户门店关系 |
