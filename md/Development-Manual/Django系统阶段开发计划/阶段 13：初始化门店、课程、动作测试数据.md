- **要点**：写入顺序由引用链条决定：省份 → 门店 → 用户门店关系 → 分类 → 课程/动作 → 收藏与排期。

## 4. 创建初始化命令目录

初始化命令统一放在 `store` app 下面。先创建目录。

Windows PowerShell：

```bash
mkdir store\management\commands
```

目录已存在时跳过此步即可。

macOS / Linux：

```bash
mkdir -p store/management/commands
```

随后确认以下两个空文件存在，缺失时手动创建：

```text
backend/store/management/__init__.py
backend/store/management/commands/__init__.py
```

这两个 `__init__.py` 文件使 `management` 与 `commands` 成为 Python 包，Django 才能发现目录下的管理命令。

**本章要点**：

- **要点**：命令文件必须位于 `store/management/commands/` 目录内，Django 按此约定注册管理命令。
- **要点**：两个 `__init__.py` 空文件缺一不可，否则命令不会被识别。
- **要点**：Windows 与 macOS / Linux 的建目录命令不同，路径分隔符按平台使用。

## 5. 实现 init_business_data 命令

### 5.1 文件位置

新建文件：

```text
backend/store/management/commands/init_business_data.py
```

### 5.2 写入顺序

命令内部按以下编号步骤依次写入：

```text
1. 获取已有用户和角色
2. 初始化省份/区域
3. 初始化门店
4. 初始化用户门店关系
5. 初始化课程分类
6. 初始化课程
7. 初始化用户课程收藏
8. 初始化门店课程排期
9. 初始化动作分类
10. 初始化动作
11. 初始化用户动作收藏
```

所有写入均使用 `get_or_create`：先按定位字段查询，存在则复用，不存在则按 `defaults` 创建，因此命令可重复执行。

```python
        self.stdout.write("- 用户课程收藏")
        self.stdout.write("- 门店课程排期")
        self.stdout.write("- 动作分类")
        self.stdout.write("- 动作")
        self.stdout.write("- 用户动作收藏")
```

**本章要点**：

- **要点**：命令类继承 `BaseCommand`，`help` 字段说明用途，全部逻辑写在 `handle` 方法中。
- **要点**：第一步从 `rbac.models` 读取 `admin`、`zhangsan` 用户与 `admin`、`user` 角色，缺失时输出错误并终止。
- **要点**：所有业务表写入统一使用 `get_or_create`，定位字段放参数、其余字段放 `defaults`，保证重复执行不产生重复数据。
- **要点**：课程排期的排期日期基于 `date.today()` 计算（今天、明天、后天），重复执行时因日期条件不同会产生新排期。
- **要点**：每一步写入后通过 `self.style.SUCCESS` 输出进度，便于确认执行到哪一步。

## 常见问题与排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 输出 `缺少 admin 或 zhangsan 用户，请先执行：python manage.py init_rbac_data` | 阶段 3 的 RBAC 测试数据未初始化 | 依次执行 `python manage.py init_rbac_data` 与 `python manage.py init_business_data` |
| 输出 `缺少 admin 或 user 角色，请先执行：python manage.py init_rbac_data` | RBAC 角色数据缺失 | 执行 `python manage.py init_rbac_data` 后重试 |
| 报错 `Table 'rbac_db.t_store' doesn't exist` | 阶段 12 的迁移未执行成功 | 依次执行 `python manage.py makemigrations store`、`python manage.py makemigrations course`、`python manage.py makemigrations exercise`、`python manage.py migrate`，再重新执行 `python manage.py init_business_data` |
| 重复执行后主要数据没有翻倍，但排期新增了一条 | 大多数数据以 `get_or_create` 创建；课程排期的定位条件包含 `store`、`course`、`course_date`、`start_time` | 属预期行为：排期日期按执行当天计算，不同日期执行会产生新排期 |
