# 八、常见问题
## 1. 报错：缺少 admin 或 zhangsan 用户
错误类似：

```latex
缺少 admin 或 zhangsan 用户，请先执行：python manage.py init_rbac_data
```

解决：

```bash
python manage.py init_rbac_data
python manage.py init_business_data
```

---

## 2. 报错：表不存在
例如：

```latex
Table 'rbac_db.t_store' doesn't exist
```

说明阶段 12 没有迁移成功。

解决：

```bash
python manage.py makemigrations store
python manage.py makemigrations course
python manage.py makemigrations exercise
python manage.py migrate
```

然后重新执行：

```bash
python manage.py init_business_data
```

---

## 3. 重复执行会不会重复插入？
大多数数据使用了：

```python
get_or_create
```

所以重复执行不会重复创建主要数据。

但是课程排期这里的判断条件包含：

```latex
store
course
course_date
start_time
```

如果你每天执行，日期不同，会创建新的排期，这是正常现象。
