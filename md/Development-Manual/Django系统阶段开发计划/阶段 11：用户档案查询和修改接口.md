## 阶段导语

本阶段在阶段 10 建成的 `sys_user_profile` 表之上，向档案主线接入接口层。通过单一地址 `/api/profile/me/` 同时提供查询（GET）与修改（PUT）两种能力，接口依托 JWT 确认当前用户身份，用户只能操作属于自己的档案。

当用户尚无档案时，接口会自动创建一条空档案，保证查询不报错。Vue3 档案页面、头像上传、管理员查看他人档案与档案权限的 RBAC 控制均不在本阶段范围内。

## 1. 接口设计与最终效果

### 1.1 接口设计

新增一个接口地址 `/api/profile/me/`，支持两种请求方式：

| 请求方式 | 地址 | 作用 | 是否需要登录 |
|----------|------|------|--------------|
| GET | `/api/profile/me/` | 查询当前用户档案 | 需要 |
| PUT | `/api/profile/me/` | 修改当前用户档案 | 需要 |

### 1.2 最终效果

用户登录后，携带 `access_token` 请求：

```text
GET /api/profile/me/
```

后端依据令牌识别当前用户，返回该用户的档案。例如 admin 登录后请求返回：

```json
{
  "code": 200,
  "message": "获取档案成功",
  "data": {
    "profile_id": 1,
    "user_id": 1,
    "username": "admin",
    "real_name": "管理员",
    "level": 10,
    "gender": 1,
    "gender_text": "男",
    "birthday": "1998-01-01",
    "height_cm": "175.00",
    "weight_kg": "70.00",
    "avatar_url": "",
    "intro": "管理员账号",
    "create_time": "2026-05-26 10:00:00",
    "join_time": "2026-05-26 10:00:00",
    "expire_date": "2030-12-31"
  }
}
```

**要点**：

- **要点**：同一地址以 HTTP 方法区分查询与修改，语义清晰。
- **要点**：响应统一为 `code` / `message` / `data` 三段结构。
- **要点**：`gender_text` 由 `get_gender_display()` 派生，与数字 `gender` 并存返回。

## 4. 数据转换工具函数

在 `views.py` 中 `get_json_body` 函数下方追加以下工具函数，负责日期、小数、档案对象的格式化与解析。

```python
def format_date_value(value):
    """
    把日期格式化成字符串
    """

    if value is None:
        return None

    return value.strftime("%Y-%m-%d")


def format_datetime_value(value):
    """
    把日期时间格式化成字符串
    """

    if value is None:
        return None

    return value.strftime("%Y-%m-%d %H:%M:%S")


def format_decimal_value(value):
    """
    把 Decimal 转成字符串
    """

    if value is None:
        return None

    return str(value)


def parse_date_value(value, field_name):
    """
    解析日期字段

    前端传入格式：
    2026-05-26
    """

    if value in [None, ""]:
        return None

    try:
        return date.fromisoformat(value)
    except ValueError:
        raise ValueError(f"{field_name} 格式错误，正确格式是 YYYY-MM-DD")


def parse_datetime_value(value, field_name):
    """
    解析日期时间字段

    前端传入格式：
    2026-05-26 10:30:00
    或：
    2026-05-26T10:30:00
    """

    if value in [None, ""]:
        return None

    try:
        value = value.replace("T", " ")
        return datetime.fromisoformat(value)
    except ValueError:
        raise ValueError(f"{field_name} 格式错误，正确格式是 YYYY-MM-DD HH:MM:SS")


def parse_decimal_value(value, field_name):
    """
    解析小数字段
    """

    if value in [None, ""]:
        return None

    try:
        return Decimal(str(value))
    except InvalidOperation:
        raise ValueError(f"{field_name} 必须是数字")


def serialize_profile(profile):
    """
    把用户档案对象转换成 JSON 字典
    """

    user = profile.user

    return {
        "profile_id": profile.profile_id,
        "user_id": user.user_id,
        "username": user.username,
        "real_name": user.real_name,

        "level": profile.level,
        "gender": profile.gender,
        "gender_text": profile.get_gender_display() if profile.gender is not None else None,
        "birthday": format_date_value(profile.birthday),
        "height_cm": format_decimal_value(profile.height_cm),
        "weight_kg": format_decimal_value(profile.weight_kg),
        "avatar_url": profile.avatar_url,
        "intro": profile.intro,
        "create_time": format_datetime_value(profile.create_time),
        "join_time": format_datetime_value(profile.join_time),
        "expire_date": format_date_value(profile.expire_date),
    }


def get_or_create_user_profile(user):
    """
    获取当前用户档案

    如果没有档案，就自动创建一条空档案。
    """

    profile = SysUserProfile.objects.filter(
        user=user
    ).order_by("profile_id").first()

    if profile:
        return profile

    profile = SysUserProfile.objects.create(
        user=user,
        create_time=datetime.now(),
    )

    return profile
```

各函数职责如下：

| 函数 | 作用 |
|------|------|
| `format_date_value` | 将日期格式化为 `YYYY-MM-DD` 字符串，空值返回 `None` |
| `format_datetime_value` | 将日期时间格式化为 `YYYY-MM-DD HH:MM:SS` 字符串 |
| `format_decimal_value` | 将 `Decimal` 转为字符串 |
| `parse_date_value` | 解析前端日期字符串（如 `2026-05-26`）为 `date` 对象，格式错误抛 `ValueError` |
| `parse_datetime_value` | 解析日期时间字符串（兼容空格与 `T` 分隔）为 `datetime` 对象 |
| `parse_decimal_value` | 将输入转为 `Decimal`，非数字抛 `ValueError` |
| `serialize_profile` | 将档案对象转为可 JSON 化的字典，供响应使用 |
| `get_or_create_user_profile` | 取用户最早的一条档案，无档案时自动创建空档案 |

数据库对象不能直接返回给前端，需以 `serialize_profile` 转为字典后再响应；用户无档案时由 `get_or_create_user_profile` 兜底创建，使查询接口不会因缺档案而报错。

**要点**：

- **要点**：`format_*` 系列用于出参、`parse_*` 系列用于入参，方向相反。
- **要点**：`parse_datetime_value` 以 `replace("T", " ")` 同时兼容 `2026-05-26 10:30:00` 与 `2026-05-26T10:30:00` 两种格式。
- **要点**：`get_or_create_user_profile` 按 `profile_id` 升序取第一条，保证返回结果稳定。

## 5. 档案接口视图 ProfileMeView

在 `views.py` 文件末尾追加以下视图类：

```python
@method_decorator(csrf_exempt, name="dispatch")
class ProfileMeView(View):
    """
    当前登录用户档案接口

    GET /api/profile/me/   查询当前用户档案
    PUT /api/profile/me/   修改当前用户档案
    """

    @login_required
    def get(self, request):
        user = request.current_user

        profile = get_or_create_user_profile(user)

        return json_response(
            data=serialize_profile(profile),
            message="获取档案成功",
        )

    @login_required
    def put(self, request):
        user = request.current_user

        data = get_json_body(request)

        if data is None:
            return json_response(
                message="请求体不是合法 JSON",
                code=400,
                status=400,
            )

        profile = get_or_create_user_profile(user)

        try:
            if "level" in data:
                level = data.get("level")
                profile.level = None if level in [None, ""] else int(level)

            if "gender" in data:
                gender = data.get("gender")

                if gender in [None, ""]:
                    profile.gender = None
                else:
                    gender = int(gender)

                    if gender not in [0, 1, 2]:
                        return json_response(
                            message="gender 只能是 0、1、2",
                            code=400,
                            status=400,
                        )

                    profile.gender = gender

            if "birthday" in data:
                profile.birthday = parse_date_value(
                    data.get("birthday"),
                    "birthday"
                )

            if "height_cm" in data:
                profile.height_cm = parse_decimal_value(
                    data.get("height_cm"),
                    "height_cm"
                )

            if "weight_kg" in data:
                profile.weight_kg = parse_decimal_value(
                    data.get("weight_kg"),
                    "weight_kg"
                )

            if "avatar_url" in data:
                avatar_url = data.get("avatar_url")

                if avatar_url and len(avatar_url) > 255:
                    return json_response(
                        message="avatar_url 长度不能超过 255",
                        code=400,
                        status=400,
                    )

                profile.avatar_url = avatar_url

            if "intro" in data:
                profile.intro = data.get("intro")

            if "create_time" in data:
                profile.create_time = parse_datetime_value(
                    data.get("create_time"),
                    "create_time"
                )

            if "join_time" in data:
                profile.join_time = parse_datetime_value(
                    data.get("join_time"),
                    "join_time"
                )

            if "expire_date" in data:
                profile.expire_date = parse_date_value(
                    data.get("expire_date"),
                    "expire_date"
                )

        except ValueError as error:
            return json_response(
                message=str(error),
                code=400,
                status=400,
            )

        profile.save()

        return json_response(
            data=serialize_profile(profile),
            message="修改档案成功",
        )
```

**要点**：

- **要点**：视图类以 `@method_decorator(csrf_exempt, name="dispatch")` 免除 CSRF 校验，两个方法均加 `@login_required`。
- **要点**：PUT 逐字段以 `if "字段" in data` 判断，仅更新请求体中出现的字段，未出现字段保持原值。
- **要点**：`gender` 限定为 0/1/2、`avatar_url` 限长 255，越界即返回 400。
- **要点**：解析异常统一被 `except ValueError` 捕获并转为 400 响应。

## 6. 接口处理流程

### 6.1 查询档案

```text
1. 检查 access_token
2. 解析当前用户
3. 查询 sys_user_profile
4. 如果没有档案，自动创建一条
5. 返回档案信息
```

### 6.2 修改档案

```text
1. 检查 access_token
2. 解析当前用户
3. 获取请求体 JSON
4. 查询当前用户档案
5. 修改 level、gender、birthday 等字段
6. 保存到数据库
7. 返回修改后的档案
```

**要点**：

- **要点**：两条流程都以令牌校验与用户解析开头，保证只操作本人档案。
- **要点**：查询流程含「无档案则自动创建」的兜底步骤。
- **要点**：修改流程在保存后再序列化返回，响应即为最新数据。

- **要点**：未携带令牌返回 401，验证 `@login_required` 生效。

## 9. 数据格式说明

| 字段 | 格式要求 | 示例 |
|------|----------|------|
| `gender` | 枚举：0 未知、1 男、2 女 | `1` |
| `birthday` | 必须为 `YYYY-MM-DD` | `1998-01-01` |
| `join_time` | 建议 `YYYY-MM-DD HH:MM:SS`，也接受 `YYYY-MM-DDTHH:MM:SS` | `2026-05-26 10:30:00` |
| `height_cm` / `weight_kg` | 可传字符串或数字 | `"175.50"`、`"70.25"` |

`height_cm`、`weight_kg` 的请求体示例：

```json
{
  "height_cm": "175.50",
  "weight_kg": "70.25"
}
```

**要点**：

- **要点**：`birthday`、`expire_date` 为纯日期，`create_time`、`join_time` 为日期时间。
- **要点**：`join_time` 兼容空格与 `T` 两种分隔符。
- **要点**：小数字段字符串与数字均可，后端统一转为 `Decimal`。

## 常见问题与排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 请求 `/api/profile/me/` 返回 401 | 未携带或 `access_token` 失效 | 重新登录获取 token，请求头加 `Authorization: Bearer <token>` |
| 修改时返回「gender 只能是 0、1、2」 | 传入的 `gender` 不在枚举内 | 仅在 0/1/2 中取值 |
| 修改时返回字段格式错误 | 日期或小数不符合约定格式 | 按 `YYYY-MM-DD`、`YYYY-MM-DD HH:MM:SS` 与数字格式传入 |
| 请求体无字段被更新 | 请求体不是合法 JSON | 检查 JSON 格式，返回 400 时先修正请求体 |
| avatar_url 返回长度错误 | `avatar_url` 超过 255 字符 | 缩短地址或改存对象存储链接 |
| zhangsan 查到了 admin 的档案 | 使用了错误的 token | 确认请求头携带的是 zhangsan 的 `access_token` |
