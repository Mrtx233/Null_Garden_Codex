本阶段目标：

```plain
1. 查询课程分类列表
2. 查询课程列表
3. 查询课程详情
4. 查询当前用户收藏的课程
5. 收藏课程
6. 取消收藏课程
7. 查询门店课程排期
```

本阶段基于你前面设计的这些表：

```plain
t_course_category          课程分类表
t_course                   健身课程主数据表
y_user_course_favorite     用户收藏课程表
t_store_course_schedule    门店课程排期表
```

这些表结构来自你上传的 SQL 文件，其中课程表关联课程分类，课程收藏表关联用户和课程，门店课程排期表关联门店、课程和教练用户。

# 一、本阶段新增接口
我们把课程相关接口统一放在：

```plain
/api/course/
```

最终接口如下：

| 请求方式 | 接口 | 作用 | 是否需要登录 |
| --- | --- | --- | --- |
| GET | `/api/course/categories/` | 课程分类列表 | 需要 |
| GET | `/api/course/courses/` | 课程列表 | 需要 |
| GET | `/api/course/courses/<course_id>/` | 课程详情 | 需要 |
| GET | `/api/course/my-favorites/` | 我的课程收藏 | 需要 |
| POST | `/api/course/favorites/` | 收藏课程 | 需要 |
| DELETE | `/api/course/favorites/<favorite_id>/` | 取消收藏课程 | 需要 |
| GET | `/api/course/schedules/` | 门店课程排期 | 需要 |

## 1. 课程分类列表
```plain
GET /api/course/categories/
```

返回：

```json
{
  "code": 200,
  "message": "获取课程分类成功",

      "category_id": 1,
      "category_name": "力量训练",
      "category_url": "https://example.com/course-strength.jpg",
      "description": "提升肌肉力量、基础动作能力和训练稳定性。",
      "status": 1,
      "status_text": "启用"
    }
  ]
}
```

## 2. 课程列表
```plain
GET /api/course/courses/
```

支持筛选：

```plain
category_id          按分类筛选
course_difficulty    按难度筛选
status               按状态筛选
keyword              按课程名称模糊搜索
```

例如：

```plain
GET /api/course/courses/?category_id=1
GET /api/course/courses/?keyword=HIIT
GET /api/course/courses/?course_difficulty=1
```

---

## 3. 课程详情
```plain
GET /api/course/courses/1/
```

返回某一个课程的详细信息。

---

## 4. 我的课程收藏
```plain
GET /api/course/my-favorites/
```

后端会根据 JWT 找到当前用户，然后返回这个用户收藏的课程。

---

## 5. 收藏课程
```plain
POST /api/course/favorites/
```

请求体：

```json
{
  "course_id": 1
}
```

---

## 6. 取消收藏课程
```plain
DELETE /api/course/favorites/1/
```

这里的 `1` 是收藏记录的 `favorite_id`，不是课程 ID。

---

## 7. 门店课程排期
```plain
GET /api/course/schedules/
```

支持筛选：

```plain
store_id       按门店筛选
course_id      按课程筛选
course_date    按日期筛选，格式 YYYY-MM-DD
status         按状态筛选
```

例如：

```plain
GET /api/course/schedules/?store_id=1
GET /api/course/schedules/?course_date=2026-05-26
GET /api/course/schedules/?store_id=1&course_date=2026-05-26
```

把内容替换成下面完整代码。

## `backend/course/views.py`
```python
import json
from datetime import date

from django.views import View
from django.views.decorators.csrf import csrf_exempt
from django.utils.decorators import method_decorator

from rbac.auth import login_required
from rbac.responses import json_response

from .models import (
    CourseCategory,
    Course,
    UserCourseFavorite,
    StoreCourseSchedule,
)


def get_json_body(request):
    """
    获取 JSON 请求体
    """

    try:
        body = request.body.decode("utf-8")

        if not body:
            return {}

        return json.loads(body)

    except json.JSONDecodeError:
        return None


def format_datetime_value(value):
    """
    datetime 转字符串
    """

    if value is None:
        return None

    return value.strftime("%Y-%m-%d %H:%M:%S")


def format_date_value(value):
    """
    date 转字符串
    """

    if value is None:
        return None

    return value.strftime("%Y-%m-%d")


def parse_date_value(value, field_name):
    """
    解析日期字段

    前端传入格式：
    2026-05-26
    """

    if value in [None, ""]:
        return None

    try:
        return date.fromisoformat(value)
    except ValueError:
        raise ValueError(f"{field_name} 格式错误，正确格式是 YYYY-MM-DD")


def serialize_category(category):
    """
    课程分类对象转 JSON 字典
    """

    return {
        "category_id": category.category_id,
        "category_name": category.category_name,
        "category_url": category.category_url,
        "description": category.description,
        "status": category.status,
        "status_text": category.get_status_display(),
    }


def serialize_course(course, current_user=None):
    """
    课程对象转 JSON 字典
    """

    is_favorite = False
    favorite_id = None

    if current_user:
        favorite = UserCourseFavorite.objects.filter(
            user=current_user,
            course=course
        ).first()

        if favorite:
            is_favorite = True
            favorite_id = favorite.favorite_id

    return {
        "course_id": course.course_id,
        "course_name": course.course_name,

        "category_id": course.category_id,
        "category_name": course.category.category_name,

        "course_difficulty": course.course_difficulty,
        "duration_minutes": course.duration_minutes,
        "max_participants": course.max_participants,
        "schedule_info": course.schedule_info,
        "description": course.description,

        "status": course.status,
        "status_text": course.get_status_display(),

        "is_favorite": is_favorite,
        "favorite_id": favorite_id,
    }


def serialize_favorite(favorite):
    """
    用户课程收藏对象转 JSON 字典
    """

    course = favorite.course

    return {
        "favorite_id": favorite.favorite_id,
        "created_at": format_datetime_value(favorite.created_at),
        "course": serialize_course(course, favorite.user),
    }


def serialize_schedule(schedule):
    """
    门店课程排期对象转 JSON 字典
    """

    store = schedule.store
    course = schedule.course
    coach = schedule.coach

    return {
        "schedule_id": schedule.schedule_id,

        "store_id": store.store_id,
        "store_name": store.store_name,
        "store_type": store.store_type,
        "store_type_text": store.get_store_type_display(),

        "course_id": course.course_id,
        "course_name": course.course_name,
        "category_id": course.category_id,
        "category_name": course.category.category_name,

        "coach_id": coach.user_id if coach else None,
        "coach_username": coach.username if coach else None,
        "coach_real_name": coach.real_name if coach else None,

        "course_date": format_date_value(schedule.course_date),
        "start_time": format_datetime_value(schedule.start_time),
        "classroom_name": schedule.classroom_name,

        "status": schedule.status,
        "status_text": schedule.get_status_display(),

        "created_at": format_datetime_value(schedule.created_at),
        "updated_at": format_datetime_value(schedule.updated_at),
    }


class CourseCategoryListView(View):
    """
    课程分类列表接口

    GET /api/course/categories/
    """

    @login_required
    def get(self, request):
        categories = CourseCategory.objects.all().order_by("category_id")

        data = []

        for category in categories:
            data.append(serialize_category(category))

        return json_response(
            data=data,
            message="获取课程分类成功",
        )


class CourseListView(View):
    """
    课程列表接口

    GET /api/course/courses/

    可选查询参数：
    category_id
    course_difficulty
    status
    keyword
    """

    @login_required
    def get(self, request):
        current_user = request.current_user

        queryset = Course.objects.select_related("category").all().order_by("course_id")

        category_id = request.GET.get("category_id")
        course_difficulty = request.GET.get("course_difficulty")
        status_value = request.GET.get("status")
        keyword = request.GET.get("keyword")

        if category_id:
            queryset = queryset.filter(category_id=category_id)

        if course_difficulty:
            queryset = queryset.filter(course_difficulty=course_difficulty)

        if status_value in ["0", "1"]:
            queryset = queryset.filter(status=int(status_value))

        if keyword:
            queryset = queryset.filter(course_name__icontains=keyword)

        data = []

        for course in queryset:
            data.append(serialize_course(course, current_user))

        return json_response(
            data=data,
            message="获取课程列表成功",
        )


class CourseDetailView(View):
    """
    课程详情接口

    GET /api/course/courses/<course_id>/
    """

    @login_required
    def get(self, request, course_id):
        current_user = request.current_user

        course = Course.objects.select_related("category").filter(
            course_id=course_id
        ).first()

        if course is None:
            return json_response(
                message="课程不存在",
                code=404,
                status=404,
            )

        return json_response(
            data=serialize_course(course, current_user),
            message="获取课程详情成功",
        )


class MyCourseFavoriteListView(View):
    """
    当前用户课程收藏列表接口

    GET /api/course/my-favorites/
    """

    @login_required
    def get(self, request):
        current_user = request.current_user

        favorites = UserCourseFavorite.objects.select_related(
            "user",
            "course",
            "course__category",
        ).filter(
            user=current_user
        ).order_by("-created_at")

        data = []

        for favorite in favorites:
            data.append(serialize_favorite(favorite))

        return json_response(
            data=data,
            message="获取我的课程收藏成功",
        )


@method_decorator(csrf_exempt, name="dispatch")
class CourseFavoriteCreateView(View):
    """
    收藏课程接口

    POST /api/course/favorites/

    请求体：
    {
        "course_id": 1
    }
    """

    @login_required
    def post(self, request):
        current_user = request.current_user

        data = get_json_body(request)

        if data is None:
            return json_response(
                message="请求体不是合法 JSON",
                code=400,
                status=400,
            )

        course_id = data.get("course_id")

        if not course_id:
            return json_response(
                message="course_id 不能为空",
                code=400,
                status=400,
            )

        course = Course.objects.select_related("category").filter(
            course_id=course_id
        ).first()

        if course is None:
            return json_response(
                message="课程不存在",
                code=404,
                status=404,
            )

        favorite, created = UserCourseFavorite.objects.get_or_create(
            user=current_user,
            course=course,
        )

        if not created:
            return json_response(
                data=serialize_favorite(favorite),
                message="你已经收藏过该课程",
            )

        return json_response(
            data=serialize_favorite(favorite),
            message="收藏课程成功",
        )


@method_decorator(csrf_exempt, name="dispatch")
class CourseFavoriteDeleteView(View):
    """
    取消收藏课程接口

    DELETE /api/course/favorites/<favorite_id>/
    """

    @login_required
    def delete(self, request, favorite_id):
        current_user = request.current_user

        favorite = UserCourseFavorite.objects.select_related(
            "user",
            "course",
            "course__category",
        ).filter(
            favorite_id=favorite_id,
            user=current_user,
        ).first()

        if favorite is None:
            return json_response(
                message="收藏记录不存在",
                code=404,
                status=404,
            )

        favorite.delete()

        return json_response(
            message="取消收藏成功",
        )


class StoreCourseScheduleListView(View):
    """
    门店课程排期列表接口

    GET /api/course/schedules/

    可选查询参数：
    store_id
    course_id
    course_date
    status
    """

    @login_required
    def get(self, request):
        queryset = StoreCourseSchedule.objects.select_related(
            "store",
            "course",
            "course__category",
            "coach",
        ).all().order_by("course_date", "start_time")

        store_id = request.GET.get("store_id")
        course_id = request.GET.get("course_id")
        course_date = request.GET.get("course_date")
        status_value = request.GET.get("status")

        if store_id:
            queryset = queryset.filter(store_id=store_id)

        if course_id:
            queryset = queryset.filter(course_id=course_id)

        if course_date:
            try:
                parsed_date = parse_date_value(course_date, "course_date")
            except ValueError as error:
                return json_response(
                    message=str(error),
                    code=400,
                    status=400,
                )

            queryset = queryset.filter(course_date=parsed_date)

        if status_value in ["0", "1"]:
            queryset = queryset.filter(status=int(status_value))

        data = []

        for schedule in queryset:
            data.append(serialize_schedule(schedule))

        return json_response(
            data=data,
            message="获取门店课程排期成功",
        )
```

# 十、常见问题
## 1. 报错：`No module named course.urls`
说明你还没有创建：

```plain
backend/course/urls.py
```

或者 `config/urls.py` 写错了：

```python
path("api/course/", include("course.urls")),
```

---

## 2. 报错：`Table 'rbac_db.t_course' doesn't exist`
说明阶段 12 的迁移没有执行成功。

执行：

```bash
python manage.py makemigrations course
python manage.py migrate
```

然后再执行：

```bash
python manage.py init_business_data
```

---

## 3. 课程列表是空的
说明阶段 13 的业务测试数据没有初始化。

执行：

```bash
python manage.py init_business_data
```

---

## 4. 收藏课程报重复错误
正常情况下不会报数据库错误，因为接口用了：

```python
UserCourseFavorite.objects.get_or_create()
```

如果已经收藏过，会返回：

```plain
你已经收藏过该课程
```

---

## 5. 取消收藏返回 404
原因通常是：

```plain
1. favorite_id 写错了
2. 这个收藏不是当前登录用户的收藏
3. 收藏记录已经被删除
```

你可以先查：

```plain
GET /api/course/my-favorites/
```

拿到正确的 `favorite_id` 后再删除。
