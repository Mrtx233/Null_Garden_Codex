## 阶段导语

本阶段是后端接口向用户界面转化的环节。阶段 14 至阶段 16 已在后端建立 `store`、`course`、`exercise` 三个业务模块的查询与收藏接口，本阶段在前端以 Vue3 建立对应页面，通过封装的请求工具调用这些接口，把结构化数据渲染为可交互的表格与操作按钮。

页面均使用组合式 API（Composition API）的 `<script setup>` 语法编写，属于单文件组件（Single-File Component，SFC）。本阶段聚焦接口连通与数据展示，采用原生 HTML 元素与最小样式，不引入组件库，以便完整暴露请求、响应与渲染的对应关系。

## 3. API 封装层

三个领域的接口各自封装为一个文件，统一从 `../utils/request` 引入请求实例。

### 3.1 门店接口 `frontend/src/api/store.js`

新建文件：

```text
frontend/src/api/store.js
```

写入：

```javascript
import request from "../utils/request"

export function getProvinceListApi() {
  return request.get("/store/provinces/")
}

export function getStoreListApi(params) {
  return request.get("/store/stores/", {
    params
  })
}

export function getStoreDetailApi(storeId) {
  return request.get(`/store/stores/${storeId}/`)
}

export function getMyStoreListApi() {
  return request.get("/store/my-stores/")
}
```

对应的后端接口：

| 方法 | 路径 | 参数 | 返回说明 |
|------|------|------|----------|
| GET | `/api/store/provinces/` | 无 | 省份列表 |
| GET | `/api/store/stores/` | `params` 查询参数 | 门店列表 |
| GET | `/api/store/stores/<store_id>/` | 路径参数 `store_id` | 门店详情 |
| GET | `/api/store/my-stores/` | 无 | 当前用户关联门店列表 |

对应的后端接口：

| GET | `/api/course/my-favorites/` | 无 | 当前用户课程收藏列表 |

```javascript
import request from "../utils/request"

}
```

对应的后端接口：

| 方法 | 路径 | 参数 | 返回说明 |
|------|------|------|----------|
| GET | `/api/exercise/categories/` | 无 | 动作分类列表 |
| GET | `/api/exercise/actions/` | `params` 查询参数 | 动作列表 |
| GET | `/api/exercise/actions/<action_id>/` | 路径参数 `action_id` | 动作详情 |

- **要点**：API 封装层的路径省略 `/api` 前缀，前缀由请求实例的 `baseURL` 统一提供。
- **要点**：列表类接口以 `params` 传递查询条件，详情与删除类接口以模板字符串拼接路径参数。
- **要点**：课程收藏接口路径中的 `favorite_id` 与动作收藏接口中的 `favorite_id` 分属不同记录表，互不通用。

```vue
import { onMounted, reactive, ref } from "vue"

import {
  getProvinceListApi,
  getStoreListApi,
  getMyStoreListApi
} from "../api/store"

const provinces = ref([])
const stores = ref([])
const myStores = ref([])

const query = reactive({
  province_id: "",
  store_type: "",
  is_operating: "",
  keyword: ""
})

async function loadProvinces() {
  const res = await getProvinceListApi()

  if (res.code === 200) {
    provinces.value = res.data
  } else {
    alert(res.message || "获取省份失败")
  }
}

async function loadStores() {
  const params = {}

  if (query.province_id) {
    params.province_id = query.province_id
  }

  if (query.store_type) {
    params.store_type = query.store_type
  }

  if (query.is_operating !== "") {
    params.is_operating = query.is_operating
  }

  if (query.keyword) {
    params.keyword = query.keyword
  }

  const res = await getStoreListApi(params)

  if (res.code === 200) {
    stores.value = res.data
  } else {
    alert(res.message || "获取门店失败")
  }
}

async function loadMyStores() {
  const res = await getMyStoreListApi()

  if (res.code === 200) {
    myStores.value = res.data
  } else {
    alert(res.message || "获取我的门店失败")
  }
}

function resetQuery() {
  query.province_id = ""
  query.store_type = ""
  query.is_operating = ""
  query.keyword = ""

  loadStores()
}

onMounted(async () => {
  await loadProvinces()
  await loadStores()
  await loadMyStores()
})
</script>
```

```javascript
import { createRouter, createWebHistory } from "vue-router"

import { useAuthStore } from "../stores/auth"

import Login from "../views/Login.vue"
import Home from "../views/Home.vue"
import UserList from "../views/UserList.vue"
import StoreList from "../views/StoreList.vue"
import CourseList from "../views/CourseList.vue"

import Forbidden from "../views/Forbidden.vue"

const routes = [
  {
    path: "/login",
    component: Login
  },
  {
    path: "/",
    component: Home,
    meta: {
      requiresAuth: true
    }
  },
  {
    path: "/users",
    component: UserList,
    meta: {
      requiresAuth: true,
      permission: "user:list"
    }
  },
  {
    path: "/store",
    component: StoreList,
    meta: {
      requiresAuth: true
    }
  },
  {
    path: "/course",
    component: CourseList,
    meta: {
      requiresAuth: true
    }
  },
  {
    path: "/exercise",
    component: ExerciseList,
    meta: {
      requiresAuth: true
    }
  },
  {
    path: "/favorites",
    component: MyFavorites,
    meta: {
      requiresAuth: true
    }
  },
  {
    path: "/403",
    component: Forbidden
  }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

router.beforeEach((to, from, next) => {
  const authStore = useAuthStore()

  if (to.meta.requiresAuth && !authStore.isLogin) {
    next("/login")
    return
  }

  if (to.path === "/login" && authStore.isLogin) {
    next("/")
    return
  }

  if (to.meta.permission && !authStore.hasPermission(to.meta.permission)) {
    next("/403")
    return
  }

  next()
})

export default router
```

## 常见问题与排查

| 现象 | 原因 | 处理方式 |
|------|------|----------|
| 页面报 404 | 路由未注册对应 `path` 与 `component` | 核对 `/store`、`/course`、`/exercise`、`/favorites` 的路由条目是否完整 |
| 页面请求接口返回 401 | 请求未携带 token | 检查 `frontend/src/utils/request.js` 是否设置 ``config.headers.Authorization = `Bearer ${accessToken}` ``，并确认浏览器 Local Storage 中存在 `access_token` |
| 门店 / 课程 / 动作列表为空 | 阶段 13 数据未初始化 | 在后端执行 `python manage.py init_business_data` |
| 收藏失败，提示记录不存在 | 取消收藏时传入的是 `course_id`/`action_id` 而非 `favorite_id` | 课程取消走 `DELETE /api/course/favorites/<favorite_id>/`，动作取消走 `DELETE /api/exercise/favorites/<favorite_id>/` |
