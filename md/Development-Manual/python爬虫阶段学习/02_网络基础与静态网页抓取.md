## 1. HTTP/HTTPS 网络协议基础

### 1.1 请求与响应模型

```
你（客户端）                  服务器
   │                          │
   ├── 请求 (Request) ──────→ │
   │                          ├── 处理中...
   │ ←───── 响应 (Response) ──┤
   │                          │
```

一次 HTTP 请求 = 你问服务器要东西 + 服务器给你回复。

```python
# 用代码理解这个过程
import http.client

# 1. 建立连接
conn = http.client.HTTPSConnection("www.example.com")

# 2. 发送请求
conn.request("GET", "/")

# 3. 获取响应
response = conn.getresponse()

# 4. 读取内容
print(f"状态码: {response.status}")       # 200
print(f"响应头: {response.getheaders()}")  # 一大堆头部信息
data = response.read()                     # 页面的 HTML 内容
conn.close()
```

实际爬虫中你不会用 `http.client`（太底层），而是用 `requests` 库。但理解这个流程很重要。

### 1.2 常见请求方法

```python
# ── 最常用的两个 ──
# GET：从服务器获取资源（看网页、搜东西）
# POST：向服务器提交数据（登录、提交表单）

# 生活中的类比：
# GET  = 你看着菜单点菜（只读，不改变服务器状态）
# POST = 你提交反馈表单（写入数据到服务器）

# ── 其他方法（了解即可）──
# PUT：更新资源（覆盖）
# DELETE：删除资源
# PATCH：部分更新
```

### 1.3 Request Headers（请求头）

请求头是你在请求时"告诉服务器你是谁、你要什么"的元信息。

```python
headers = {
    # ── 最重要的 ──
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    # 告诉服务器"我是一个浏览器"。反爬虫最基础的手段就是检查这个，不设置直接拒绝。

    "Referer": "https://www.google.com/",
    # "你从哪个页面跳过来的" → 防止盗链、统计来源

    "Cookie": "session_id=abc123; user=zhangsan",
    # 携带登录状态/身份信息。服务器靠这个认出你是谁。

    # ── 其他常用的 ──
    "Accept": "text/html,application/json,*/*",
    # "我能接受什么格式的响应" → 可以用来要求返回 JSON 而不是 HTML

    "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",
    # "我要什么语言" → 决定返回中文还是英文

    "Authorization": "Bearer token123",
    # 身份认证令牌（API 调用常用）
}

# 为什么要设置 Headers？
# 不设置 User-Agent 的请求，很多网站直接返回 403 拒绝访问
# 设置得像正常浏览器，服务器就把你当成普通用户
```

### 1.4 常见状态码

```python
status_codes = {
    # ── 2xx 成功 ──
    200: "OK - 请求成功，响应中有数据",
    201: "Created - 创建成功（POST 请求后常见）",
    204: "No Content - 请求成功但没内容返回（DELETE 后常见）",

    # ── 3xx 重定向 ──
    301: "Moved Permanently - 永久重定向（地址变了）",
    302: "Found - 临时重定向（暂时跳到别处）",
    304: "Not Modified - 内容没变，用缓存（跟浏览器缓存机制有关）",

    # ── 4xx 客户端错误 ──
    400: "Bad Request - 请求格式不对",
    401: "Unauthorized - 没登录/没认证",
    403: "Forbidden - 服务器拒绝（反爬虫最常见！）",
    404: "Not Found - 页面不存在",
    429: "Too Many Requests - 请求太频繁，被限流了",

    # ── 5xx 服务器错误 ──
    500: "Internal Server Error - 服务器内部错误",
    502: "Bad Gateway - 网关错误（服务器上游挂了）",
    503: "Service Unavailable - 服务器暂时忙不过来",
}

# 爬虫实战：根据状态码决定行为
def handle_response(status_code):
    if status_code == 200:
        return "解析数据"
    elif status_code == 301 or status_code == 302:
        return "跟随重定向"
    elif status_code == 403:
        return "被屏蔽了，换代理或加 Headers"
    elif status_code == 429:
        return "请求太快，等一会儿再试"
    elif status_code >= 500:
        return "服务器挂了，等一会儿重试"
    else:
        return "其他情况"
```

### 2.2 GET 请求

```python
import requests

# ── 最简单的 GET ──
response = requests.get("https://api.example.com/users")
print(response.text)          # 响应内容（字符串）
print(response.content)       # 响应内容（字节，下载图片用这个）
print(response.status_code)   # 状态码 200
print(response.headers)       # 响应头（字典）
print(response.url)           # 最终请求的 URL（可能被重定向了）

# ── 带参数的 GET ──
# 方法 1：直接拼在 URL 里
response = requests.get("https://api.example.com/search?q=手机&page=1")

# 方法 2：用 params 参数（推荐，自动处理编码）
params = {
    "q": "手机",
    "page": 1,
    "sort": "price"
}
response = requests.get("https://api.example.com/search", params=params)
# 实际请求的 URL：https://api.example.com/search?q=%E6%89%8B%E6%9C%BA&page=1&sort=price

# ── 带 Headers 的 GET ──
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    "Accept": "text/html,application/json,*/*",
}
response = requests.get("https://example.com", headers=headers)

# ── 设置超时（绝对要设！不然可能卡死）──
response = requests.get("https://example.com", timeout=10)
# timeout=10 表示连接+读取总共最多 10 秒
# 也可以分别设：(连接超时, 读取超时)
response = requests.get("https://example.com", timeout=(5, 10))

# ── 处理编码 ──
response = requests.get("https://example.com")
response.encoding = "utf-8"   # 手动指定编码（有时自动检测不准）
print(response.text)          # 用指定编码解码后的文本
```

### 2.4 requests.Session() — 会话维持

```python
import requests

# ── 不用 Session 的问题 ──
# 每次请求都是独立的，不会携带 Cookie
requests.get("https://example.com/login", data={"user": "admin", "pass": "123"})
# 上面刚登录成功
requests.get("https://example.com/profile")  # 但这里又需要登录了！

# ── 用 Session 解决 ──
session = requests.Session()
# Session 对象会自动保存响应中的 Cookie，并在后续请求中自动带上

# 登录
login_data = {"username": "admin", "password": "123456"}
session.post("https://example.com/login", data=login_data)
# 这里服务器返回的 Set-Cookie 被 session 自动记住了

# 访问需要登录的页面
response = session.get("https://example.com/profile")
# 自动带上了刚才的 Cookie，服务器认出了你是谁

# ── Session 的其他好处 ──
session.headers.update({"User-Agent": "Mozilla/5.0"})
# 设置一次，所有请求都生效

# ── 爬虫实战：模拟登录获取数据 ──
def login_and_get_data(username, password):
    """模拟登录并获取登录后的数据"""
    session = requests.Session()

    # 1. 先访问登录页面，获取必要的 Cookie 和 token
    login_page = session.get("https://example.com/login")
    # 解析出可能需要的 csrf_token（如果有的话）

    # 2. 提交登录
    login_data = {
        "username": username,
        "password": password,
        # "csrf_token": csrf_token  # 某些网站需要这个
    }
    resp = session.post("https://example.com/login", data=login_data)

    if resp.status_code == 200:
        # 3. 用同一个 session 访问需要登录的页面
        profile = session.get("https://example.com/my/profile")
        return profile.text
    else:
        print("登录失败")
        return None
```

### 2.5 代理设置

```python
import requests

# ── 设置代理 ──
proxies = {
    "http": "http://127.0.0.1:7890",    # HTTP 代理
    "https": "http://127.0.0.1:7890",   # HTTPS 代理（通常和 HTTP 同一个）
}
response = requests.get("https://example.com", proxies=proxies)

# ── 带认证的代理 ──
proxies = {
    "http": "http://user:password@127.0.0.1:7890",
    "https": "http://user:password@127.0.0.1:7890",
}

# ── 爬虫实战：轮换代理 ──
import random

proxy_list = [
    "http://proxy1.com:8080",
    "http://proxy2.com:8080",
    "http://proxy3.com:8080",
]

def fetch_with_proxy(url):
    """使用随机代理请求"""
    proxy = random.choice(proxy_list)
    try:
        response = requests.get(
            url,
            proxies={"http": proxy, "https": proxy},
            timeout=10
        )
        return response
    except requests.exceptions.ProxyError:
        print(f"代理 {proxy} 不可用，换下一个")
        return fetch_with_proxy(url)  # 递归重试
```

### 2.6 异常处理

```python
import requests

def safe_request(url, max_retries=3):
    """健壮的请求函数"""
    for i in range(max_retries):
        try:
            response = requests.get(url, timeout=10)

            # 检查状态码
            response.raise_for_status()  # 4xx 或 5xx 会抛出异常
            return response

        except requests.exceptions.Timeout:
            print(f"超时（第 {i+1} 次）")
        except requests.exceptions.ConnectionError:
            print(f"连接失败（第 {i+1} 次）")
        except requests.exceptions.HTTPError as e:
            print(f"HTTP 错误: {e}")
            if response.status_code == 403:
                print("被屏蔽了，需要换代理")
            elif response.status_code == 429:
                import time
                time.sleep(5)  # 被限流了，等一会儿
            else:
                return None
        except requests.exceptions.RequestException as e:
            print(f"请求异常: {e}")

    return None
```

## 3. 数据解析（三大神器）

拿到 HTML 响应后，关键一步是**从 HTML 中提取你需要的数据**。

### 3.1 正则表达式（re）

> 正则是用"模式"匹配文本的工具。爬虫中适用于：提取结构简单的数据、替换文本。

```python
import re

# ── 基本元字符（背熟这 8 个够用 90% 场景）──
# .   匹配任意单个字符（除了换行）
# *   前一个字符出现 0 次或多次
# +   前一个字符出现 1 次或多次
# ?   前一个字符出现 0 次或 1 次（也用于非贪婪）
# \d  数字（0-9）
# \w  字母/数字/下划线（等价于 [a-zA-Z0-9_]）
# \s  空白字符（空格、制表符、换行）
# []  字符集合，匹配其中任意一个

# ── 简单例子 ──
text = "我的电话是 138-1234-5678，请保存"

# 匹配电话号码
pattern = r"\d{3}-\d{4}-\d{4}"
phone = re.search(pattern, text)
if phone:
    print(phone.group())  # 138-1234-5678

# ── 常用函数 ──
text = "price: 29.9, count: 100, score: 8.5"

# re.findall：找到所有匹配项，返回列表
prices = re.findall(r"\d+\.?\d*", text)
print(prices)  # ['29.9', '100', '8.5']

# re.search：找到第一个匹配，返回 Match 对象
first_num = re.search(r"\d+", text)
print(first_num.group())  # 29

# re.sub：替换匹配的文本
cleaned = re.sub(r"\s", "", text)  # 去掉所有空格
print(cleaned)  # "price:29.9,count:100,score:8.5"

# ── 贪婪 vs 非贪婪 ──
html = "<div>内容1</div><div>内容2</div>"

# 贪婪（默认）：尽可能多匹配
greedy = re.findall(r"<div>(.*)</div>", html)
print(greedy)  # ['内容1</div><div>内容2']  ← 匹配到了最后一个 </div>

# 非贪婪：尽可能少匹配（加 ?）
non_greedy = re.findall(r"<div>(.*?)</div>", html)
print(non_greedy)  # ['内容1', '内容2']  ← 正确！

# ── 分组提取 ──
text = "张三: 25岁, 李四: 30岁, 王五: 22岁"
pattern = r"(\w+): (\d+)岁"
matches = re.findall(pattern, text)
print(matches)  # [('张三', '25'), ('李四', '30'), ('王五', '22')]
for name, age in matches:
    print(f"{name} 的年龄是 {age}")

# ── 爬虫实战：从 HTML 中提取数据 ──
html = """
<div class="movie">
    <h2>流浪地球2</h2>
    <span class="score">8.3</span>
    <span class="year">2023</span>
</div>
<div class="movie">
    <h2>哪吒</h2>
    <span class="score">9.0</span>
    <span class="year">2025</span>
</div>
"""

# 提取所有电影信息
pattern = r'<h2>(.*?)</h2>.*?<span class="score">(.*?)</span>.*?<span class="year">(.*?)</span>'
movies = re.findall(pattern, html, re.DOTALL)
for title, score, year in movies:
    print(f"{title} | {score}分 | {year}年")
    # 流浪地球2 | 8.3分 | 2023年
    # 哪吒 | 9.0分 | 2025年
```

### 3.2 XPath（lxml）— 爬虫首选解析方式

> XPath 是通过"路径"在 XML/HTML 中定位元素的语言。
> **爬虫中最常用、最高效的解析方式**。

```bash
pip install lxml
```

```python
from lxml import html

# ── 准备要解析的 HTML ──
html_str = """
<div class="container">
    <ul id="movie-list">
        <li class="item active">
            <span class="title">流浪地球2</span>
            <span class="score">8.3</span>
        </li>
        <li class="item">
            <span class="title">满江红</span>
            <span class="score">7.4</span>
        </li>
        <li class="item">
            <span class="title">哪吒</span>
            <span class="score">9.0</span>
        </li>
    </ul>
</div>
"""

# 解析 HTML
doc = html.fromstring(html_str)

# ══════════════════════════════════════
# 核心 XPath 语法（背熟这些够用 95%）
# ══════════════════════════════════════

# ── 1. 基本路径选择 ──
doc.xpath("//li")               # 所有 <li> 元素
doc.xpath("//ul/li")            # <ul> 下的所有 <li>
doc.xpath("/html/body/div")     # 从根开始的绝对路径（不常用）

# ── 2. 通过属性筛选 ──
doc.xpath("//li[@class='item']")     # class="item" 的 <li>
doc.xpath("//li[@class='active']")   # class 精确匹配
doc.xpath("//*[@id='movie-list']")   # id="movie-list" 的任意元素

# ── 3. 提取文本 ──
doc.xpath("//li[1]/span[1]/text()")  # 第一个 span 的文本 → ['流浪地球2']

# ── 4. 提取属性 ──
doc.xpath("//li/@class")             # 所有 <li> 的 class 属性值 → ['item active', 'item', 'item']

# ── 5. 位置和索引 ──
doc.xpath("//li[1]")                 # 第一个 <li>（索引从 1 开始！）
doc.xpath("//li[last()]")            # 最后一个 <li>
doc.xpath("//li[last()-1]")          # 倒数第二个
doc.xpath("//li[position()>1]")      # 第二个开始往后所有

# ── 6. 条件组合 ──
doc.xpath("//li[@class='item' and .//span[contains(text(),'哪吒')]]")
# class="item" 且包含"哪吒"文本的 <li>

# ── 7. 模糊匹配 ──
doc.xpath("//span[contains(@class, 'title')]/text()")  # class 包含 "title" 的 span
doc.xpath("//span[starts-with(@class, 'tit')]/text()") # class 以 "tit" 开头

# ── 8. 轴定位（处理复杂关系）──
doc.xpath("//span[text()='8.3']/../span[1]/text()")
# 找到文本是"8.3"的 span → 去它的父节点 → 找父节点下的第一个 span → 取文本

# ══════════════════════════════════════
# 爬虫实战：完整提取所有电影信息
# ══════════════════════════════════════

# 方法 1：分别提取
titles = doc.xpath("//li/span[@class='title']/text()")
scores = doc.xpath("//li/span[@class='score']/text()")
for t, s in zip(titles, scores):
    print(f"{t}: {s}分")

# 方法 2：遍历每个 li 提取（推荐，结构清晰）
for li in doc.xpath("//li"):
    title = li.xpath("span[@class='title']/text()")[0]
    score = li.xpath("span[@class='score']/text()")[0]
    print(f"{title}: {score}分")
```

**XPath 速查口诀：**
```
// 任意位置  / 直接子节点
@  属性     text() 文本     [n] 第 n 个
contains 模糊匹配    starts-with 开头匹配
```

### 3.3 BeautifulSoup（bs4）— 容错率高的选择

> 适合 HTML 不规范、结构混乱的页面。但速度比 lxml 慢，小项目用。

```bash
pip install beautifulsoup4 lxml
```

```python
from bs4 import BeautifulSoup

html_str = """
<div class="container">
    <ul id="movie-list">
        <li class="item active">
            <span class="title">流浪地球2</span>
            <span class="score">8.3</span>
        </li>
        <li class="item">
            <span class="title">满江红</span>
            <span class="score">7.4</span>
        </li>
    </ul>
</div>
"""

# 解析（第二个参数指定解析器，用 lxml 速度更快）
soup = BeautifulSoup(html_str, "html.parser")  # 内置解析器，不用额外装
# soup = BeautifulSoup(html_str, "lxml")  # 更快，需要 pip install lxml

# ── 1. 通过标签名查找 ──
soup.find("li")           # 第一个 <li>
soup.find_all("li")       # 所有 <li> → 返回列表

# ── 2. 通过属性查找 ──
soup.find("li", class_="item")        # class="item" 的 <li>（注意 class_ 有下划线）
soup.find("li", attrs={"class": "item"})  # 通用属性写法
soup.find(id="movie-list")            # id="movie-list" 的元素

# ── 3. CSS 选择器（推荐，和前端习惯一致）──
soup.select("li")                          # 所有 <li>
soup.select(".item")                       # class="item" 的元素
soup.select("#movie-list")                 # id="movie-list" 的元素
soup.select("ul > li")                     # 直接子节点
soup.select("li.item")                     # <li class="item">
soup.select("li:first-child")              # 第一个 <li>
soup.select("li:nth-of-type(2)")           # 第二个 <li>

# ── 4. 提取文本和属性 ──
item = soup.find("li")
print(item.text)                    # 所有文本（包括子元素的）→ "流浪地球28.3"
print(item.get_text(strip=True))    # 去掉首尾空白
print(item.get_text(separator="|")) # 自定义分隔符 → "流浪地球2|8.3"

# 提取 class 属性
print(item.get("class"))            # ['item', 'active']
print(item["class"])                # 同上，但不存在会报错

# ── 5. 节点关系 ──
item = soup.find("li")
print(item.parent)             # 父节点（<ul>）
print(item.parents)            # 所有祖先节点（生成器）
print(item.children)           # 直接子节点（生成器）不能用 len() 检查
print(item.contents)           # 直接子节点（列表）
print(item.next_sibling)       # 下一个兄弟节点（第二个 li）
print(item.previous_sibling)   # 上一个兄弟节点（None，因为第一个）

# ── 爬虫实战：提取所有电影信息 ──
movies = []
for li in soup.select("li"):
    title = li.find("span", class_="title").text
    score = li.find("span", class_="score").text
    movies.append({"title": title, "score": score})

for m in movies:
    print(f"{m['title']}: {m['score']}分")
```

### 3.4 三种解析方式对比

| 特性 | 正则 (re) | XPath (lxml) | BeautifulSoup |
|------|-----------|--------------|---------------|
| 学习曲线 | 陡峭 | 中等 | 平缓 |
| 执行速度 | 最快 | 快 | 较慢 |
| 容错性 | 低 | 中 | 高 |
| HTML 结构依赖 | 不依赖 | 依赖 | 依赖 |
| 适用场景 | 提取简单规则数据 | 结构清晰的页面 | 结构混乱的页面 |
| **爬虫推荐** | 辅助工具 | **主力** | 备选 |

## 学习建议

1. **XPath 是主力，正则和 BS4 是辅助**：优先学 XPath，能解决 80% 的提取需求。正则处理简单文本，BS4 处理不规范页面。
2. **用 Chrome DevTools 验证 XPath**：在浏览器 Console 里输入 `$x("//你的/xpath")` 就能测试，不用每次跑代码。
3. **Headers 是反爬第一道防线**：大部分网站只要你加上像样的 User-Agent 就不会拦你。
4. **一定设 timeout**：不设 timeout 的请求可能卡住你的爬虫直到天荒地老。
5. **尊重 robots.txt**：抓取前先看 `https://example.com/robots.txt`，了解哪些路径不允许抓取。
