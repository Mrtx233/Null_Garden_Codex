### 第一阶段：Python 语言底座（基石）
*学习目标：熟练掌握 Python 语法，理解面向对象和计算机操作系统底层的 I/O 与并发概念，为编写复杂爬虫打下基础。*

*   **基础语法与数据结构**
    *   变量与基本类型（数字、字符串、布尔值）
    *   核心数据结构操作（List, Tuple, Dict, Set 的增删改查及底层逻辑）
    *   控制流（if-else, for, while）
*   **函数与模块化**
    *   函数的定义、参数传递、作用域（LEGB）
    *   匿名函数（lambda）、高阶函数（map, filter, reduce）
    *   **闭包与装饰器**（重点：爬虫中常用于重试机制、日志记录）
*   **面向对象编程 (OOP)**
    *   类与对象、封装、继承、多态
    *   魔术方法（如 `__init__`, `__call__`, `__str__`）
    *   在爬虫中的应用：封装各种爬虫类、下载器类。
*   **文件与 I/O 操作**
    *   文件读写模式（r, w, a, rb, wb）
    *   上下文管理器（`with` 语句）
    *   JSON、CSV 文件的序列化与反序列化
*   **字符串编码与基础加密（预备知识）**
    *   字符编码原理：ASCII, Unicode, UTF-8, GBK 的转换（`encode` 与 `decode`）
    *   URL 编码（`urllib.parse.quote/unquote`）
    *   Base64 编码原理与 Python 实现

### 第二阶段：网络基础与静态网页抓取（入门）
*学习目标：理解 HTTP 协议，掌握基本的请求发送和页面内容提取。*

*   **HTTP/HTTPS 网络协议基础**
    *   请求与响应模型
    *   常见请求方法（GET, POST, PUT, DELETE）
    *   Request Headers（User-Agent, Cookie, Referer, Accept 等重点字段）
    *   常见状态码（200, 301, 302, 403, 404, 500 等）
*   **基础请求库**
    *   `requests` 库的基本使用（发送 GET/POST 请求、传递参数、处理代理）
    *   **`requests.Session()` 的应用**（保持连接、自动携带和处理 Cookie、模拟登录）
*   **数据解析与提取（三大神器）**
    *   **正则表达式 (`re`)**：原生字符串、基本元字符、贪婪与非贪婪匹配、`re.findall` / `re.search`。
    *   **XPath (`lxml` 库)**：节点选择、谓词、轴定位（爬虫中最常用、最高效的提取方式）。
    *   **BeautifulSoup (`bs4`)**：CSS 选择器、节点遍历（适合容错率高的不规范 HTML）。
*   **实战小项目**
    *   抓取豆瓣电影 Top250（练习 requests + XPath）
    *   某网站模拟登录（练习 Session）

### 第三阶段：动态网页与浏览器自动化（进阶）
*学习目标：解决现代 Web 页面中 JavaScript 渲染、异步加载带来的数据抓取难题。*

*   **前端基础与异步请求 (AJAX)**
    *   HTML/CSS/JS 基础认知
    *   什么是 AJAX 和 Fetch API？
    *   **浏览器抓包技巧**：熟练使用 Chrome DevTools（Network 面板的 XHR/Fetch 过滤，寻找真实的 JSON 数据接口）。
*   **浏览器自动化工具（三大框架对比与实战）**
    *   **`Selenium`**：
        *   环境搭建（WebDriver 配置）
        *   元素定位、模拟点击/输入、页面滚动
        *   三种等待机制（强制、隐式、显式等待）
        *   修改 `window.navigator.webdriver` 绕过基础检测。
    *   **`Playwright` (微软开源，现代化利器)**：
        *   无缝支持异步 (`async/await`)
        *   自动等待机制、网络拦截 (Network Interception)
        *   `codegen` 录制脚本功能
        *   避开检测的高级技巧。
    *   **工具对比选型总结**：
        *   *`requests`*：速度最快，资源占用极小；但无法执行 JS，需要自己分析接口和加密。
        *   *`Selenium`*：老牌，生态好；但速度慢，资源占用大，容易被特征识别。
        *   *`Playwright`*：速度较快，支持异步，API 现代，防屏蔽能力强；替代 Selenium 的首选。

### 第四阶段：高并发与高性能爬虫（提速）
*学习目标：突破单线程的瓶颈，实现海量数据的快速抓取。*

*   **并发理论基础**
    *   进程 vs 线程 vs 协程 的区别
    *   同步 vs 异步、阻塞 vs 非阻塞
    *   Python 的 GIL (全局解释器锁) 对并发的影响（CPU 密集型 vs IO 密集型）。
*   **多线程与多进程 (IO操作最佳实践)**
    *   `threading` 模块基础，线程锁（Lock）。
    *   `multiprocessing` 模块基础，进程间通信（Queue）。
    *   **线程池与进程池**：`concurrent.futures.ThreadPoolExecutor` 和 `ProcessPoolExecutor`（实战中最常用）。
*   **异步协程 (Asynchronous I/O)**
    *   `asyncio` 核心概念：事件循环 (Event Loop)、`async`/`await` 关键字、Task。
    *   **`aiohttp` 库**：异步 HTTP 请求（替代 requests）。
    *   限制并发量（`asyncio.Semaphore`）。

### 第五阶段：Scrapy 爬虫框架（工程化）
*学习目标：掌握工业级爬虫框架，规范化开发流程。*

*   **Scrapy 核心架构**
    *   五大组件：Engine（引擎）、Spider（爬虫）、Scheduler（调度器）、Downloader（下载器）、Item Pipeline（管道）。
    *   数据流向分析。
*   **Scrapy 基础操作**
    *   创建项目与 Spider (`scrapy startproject`, `scrapy genspider`)
    *   使用 `yield` 提交 Request 和 Item。
    *   Scrapy 内置选择器（CSS & XPath）的使用。
*   **高级中间件 (Middlewares)**
    *   **Downloader Middleware**：动态设置 User-Agent、接入代理 IP 池、集成 Playwright/Selenium 渲染动态页面。
    *   **Spider Middleware**：处理异常响应。
*   **数据清洗与持久化 (Pipelines)**
    *   清洗不规范数据。
    *   异步存入数据库。
*   **分布式爬虫（拓展）**
    *   `Scrapy-Redis` 的原理。
    *   实现多台机器共享同一个队列抓取。

### 第六阶段：反爬虫对抗与 JS 逆向（深水区/高薪核心）
*学习目标：解决现代网站复杂的安全防护策略，获取加密数据。*

*   **常见反爬策略与应对**
    *   IP 封禁 -> 搭建/购买代理 IP 池。
    *   字体反爬 -> 动态解析 WOFF 字体文件。
    *   验证码识别 -> OCR 库 (`ddddocr`)、打码平台、滑动/点选验证码的轨迹模拟。
*   **加密与解密算法（Python 实现）**
    *   哈希算法：MD5, SHA 系列。
    *   对称加密：AES, DES（理解模式 ECB/CBC、填充机制、秘钥、偏移量 IV）。
    *   非对称加密：RSA。
*   **JavaScript 逆向工程**
    *   **浏览器调试技巧**：断点调试（XHR 断点、事件监听断点）、Call Stack 分析、Overrides 替换。
    *   **常见混淆与防护**：代码压缩、OB 混淆 (Obfuscator)、Webpack 打包机制。
    *   **扣取与执行 JS 代码**：
        *   使用 `PyExecJS` 或 `subprocess` 调用 Node.js 执行原生 JS。
        *   环境补充（补 BOM/DOM 对象，如 `window`, `document`, `navigator`）。
    *   **AST 抽象语法树（了解）**：用于解混淆 JS 代码。

### 第七阶段：数据存储与部署（收尾）
*学习目标：妥善保存抓取的数据，并将爬虫部署到服务器上自动化运行。*

*   **数据存储方案**
    *   **关系型数据库**：MySQL / PostgreSQL（使用 `pymysql` 或 `SQLAlchemy`，适合结构化数据）。
    *   **非关系型数据库**：
        *   MongoDB（使用 `pymongo`，非常适合存储 JSON 等爬虫数据）。
        *   Redis（用于缓存、去重、维护代理池和分布式队列）。
*   **爬虫部署**
    *   Linux 基础操作。
    *   使用 `Scrapyd` 部署和管理 Scrapy 爬虫。
    *   使用 `Docker` 容器化你的爬虫环境（避免环境冲突）。
    *   定时任务：Linux `crontab` 或 Python `APScheduler`。

### 💡 给你的学习建议：
1. **先做加法，再做减法**：前三个阶段是核心，一定要多写代码。很多网站只需要 `requests` + `xpath` 就能搞定，不要一开始就陷入工具选择困难症。
2. **Playwright 是现在的风口**：在第三阶段，如果你时间有限，可以大致了解 Selenium 的原理，但把主要精力放在 **Playwright** 上，它在现代前端页面中的表现优异得多。
3. **JS 逆向不要死磕**：第六阶段（JS 逆向）非常消耗时间，建议结合实际案例去学（比如某易云音乐评论、某翻译接口），不要纯学理论。
4. **敬畏法律**：学习爬虫一定要遵循 `robots.txt`，注意请求频率，**不碰隐私数据，不搞黑产，不要把人家服务器搞垮**。
