## 1. 前端基础与 AJAX

### 1.1 为什么静态请求拿不到数据？

```html
<!-- 传统页面：数据直接在 HTML 里 -->
<div class="movie">流浪地球2</div>
<!-- requests 直接拿 HTML 就能提取 ✓ -->

<!-- 现代页面：HTML 是空的，JS 动态填充 -->
<div id="movie-list"></div>
<script>
    // 这段 JS 在浏览器里执行，动态加载数据
    fetch("/api/movies")
        .then(r => r.json())
        .then(data => {
            document.getElementById("movie-list").innerHTML =
                data.map(m => `<div>${m.title}</div>`).join("");
        });
</script>
<!-- requests 拿到的 HTML 只有 <div id="movie-list"></div> × -->
```

**解决办法有两种：**
1. **抓 AJAX 接口**（最佳方案）— 找到浏览器背后调用的 API，直接请求 JSON 数据
2. **浏览器自动化**（万能方案）— 用 Playwright/Selenium 操控真实浏览器

### 1.2 什么是 AJAX？

AJAX = Asynchronous JavaScript And XML（异步加载数据的技术）

```javascript
// 这是浏览器里执行的 JavaScript（理解原理就行，不需要会写）
// 最常见的 AJAX 写法

// 方法 1：fetch API（现代浏览器）
fetch("https://api.example.com/movies?page=1")
    .then(response => response.json())
    .then(data => console.log(data));

// 方法 2：XMLHttpRequest（老式）
const xhr = new XMLHttpRequest();
xhr.open("GET", "https://api.example.com/movies?page=1");
xhr.onload = () => console.log(JSON.parse(xhr.responseText));
xhr.send();
```

**爬虫的核心思路**：与其用浏览器执行这些 JS，不如**直接找到这个 API 地址**用 `requests` 请求。

## 2. 浏览器抓包技巧

> 抓包 = 在浏览器里监控所有网络请求，找到背后调用的 API。

### 2.1 Chrome DevTools Network 面板

```
打开方式：F12（或右键 → 检查）→ 切换到 Network 面板
```

**操作步骤：**

```text
1. 打开 DevTools → Network 面板
2. 勾选 "Preserve log"（保留日志，页面跳转后不丢失）
3. 刷新页面或触发你关心的操作（搜索、翻页等）
4. 在请求列表中找 XHR / Fetch 请求（这些是 AJAX 调用）
5. 点击请求查看详情：
   - Headers：请求的 URL、方法、参数、Cookie
   - Preview / Response：返回的数据（通常是 JSON 格式）
   - Initiator：谁发起的这个请求（定位 JS 代码）
```

### 2.2 用 Python 模拟找到的 API

```python
import requests

# 比如你在 DevTools 里找到了这个 API：
# 请求 URL: https://api.example.com/v1/movies?page=1&size=20
# 返回格式: JSON

# 直接用 requests 模拟
headers = {
    "User-Agent": "Mozilla/5.0 ...",
    "Accept": "application/json",
    # 有些 API 需要特定的 Referer 或 Origin
    "Referer": "https://example.com/movies",
    # 某些 API 需要 Authorization Token
    # "Authorization": "Bearer eyJxxx..."
}

params = {
    "page": 1,
    "size": 20
}

response = requests.get(
    "https://api.example.com/v1/movies",
    headers=headers,
    params=params
)

# 返回的是 JSON，直接解析
data = response.json()
for movie in data["data"]["list"]:
    print(movie["title"], movie["score"])
```

## 3. Playwright（主力推荐）

### 3.1 什么是 Playwright？

微软开源的浏览器自动化工具。比 Selenium 更新、更快、更稳定。

**核心能力：**
- 操控 Chromium、Firefox、Safari 三种浏览器
- 自动等待元素出现（不用手动 sleep）
- 网络拦截（修改请求/响应）
- 生成测试脚本（codegen 录制）
- 天然支持异步

### 3.2 安装

```bash
pip install playwright
playwright install        # 安装浏览器内核（约 300MB）
playwright install chromium  # 只装 Chromium，更快
```

### 3.3 基本使用

```python
from playwright.sync_api import sync_playwright

# ── 最简单的例子：打开百度搜索 ──
with sync_playwright() as p:
    # 启动浏览器（headless=False 可以看到浏览器界面）
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()

    # 打开网页
    page.goto("https://www.baidu.com")

    # 截图
    page.screenshot(path="baidu.png")

    # 等待 3 秒让你看看
    page.wait_for_timeout(3000)

    browser.close()
```

### 3.4 核心操作

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    # 创建一个浏览器上下文（相当于一个独立的浏览器会话）
    context = browser.new_context()
    page = context.new_page()

    # ── 1. 页面导航 ──
    page.goto("https://example.com")
    page.goto("https://example.com/login", timeout=30000)  # 超时 30 秒

    # ── 2. 元素定位（类似 CSS 选择器）──
    page.locator("#username")              # id="username"
    page.locator(".login-btn")             # class="login-btn"
    page.locator("input[name='password']") # input 标签 name="password"
    page.locator("button:has-text('登录')")  # 文本包含"登录"的按钮
    page.locator("//*[@id='list']/li[1]")  # 也支持 XPath！

    # ── 3. 模拟操作 ──
    page.fill("#username", "admin")         # 输入文本（先清空再输入）
    page.type("#username", "admin")         # 模拟键盘输入（一个字一个字打）
    page.click(".login-btn")               # 点击
    page.dblclick(".item")                 # 双击
    page.check("#agree")                   # 勾选 checkbox
    page.select_option("#city", "北京")     # 选择下拉框

    # ── 4. 键盘操作 ──
    page.keyboard.press("Enter")
    page.keyboard.press("Tab")
    page.keyboard.type("Hello")

    # ── 5. 滚动页面 ──
    page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
    # 滚动到底部（触发懒加载）
    page.locator("#footer").scroll_into_view_if_needed()  # 滚动到元素可见

    # ── 6. 提取页面内容 ──
    # 文本
    title = page.locator("h1").text_content()
    all_titles = page.locator(".item .title").all_text_contents()

    # 属性
    href = page.locator("a").get_attribute("href")

    # HTML
    html = page.locator("#content").inner_html()

    # ── 7. 等待元素 ──
    # Playwright 自动等待元素可见，但有时需要显式等待
    page.wait_for_selector(".result")          # 等待元素出现
    page.wait_for_load_state("networkidle")    # 等待网络请求完成
    page.wait_for_timeout(2000)                # 硬等 2 秒（不推荐）

    # ── 8. 执行 JS 代码 ──
    result = page.evaluate("1 + 2")           # 在浏览器里执行 JS
    page.evaluate("window.scrollTo(0, 1000)")
    # 获取页面数据（绕过解析）
    data = page.evaluate("JSON.parse(localStorage.getItem('movies'))")

    browser.close()
```

```python
"""
Playwright 最强大的特性：自动等待。
大多数操作会自动等待元素"可见、可用"再执行，不用手动 sleep。
"""

# Playwright 的点击操作会等待：
# 1. 元素出现在 DOM 中
```

### 3.6 网络拦截（拦截和修改请求/响应）

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()

    # ── 拦截请求 ──
    def handle_request(request):
        print(f"请求: {request.method} {request.url}")
        if "tracking" in request.url:
            # 拦截追踪请求，不发送
            request.abort()
        elif "api/movies" in request.url:
            # 继续请求
            request.continue_()

    page.on("request", handle_request)

    # ── 拦截响应 ──
    def handle_response(response):
        if "api/movies" in response.url:
            print(f"API 响应: {response.status}")
            data = response.json()
            print(f"电影数量: {len(data['data'])}")

    page.on("response", handle_response)

    page.goto("https://example.com/movies")
    page.wait_for_timeout(5000)
    browser.close()

# ── 更实用的方式：等待特定 API 响应 ──
with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()

    # 监听 API 响应（在触发操作之前注册）
    with page.expect_response(lambda r: "api/movies" in r.url) as response_info:
        page.goto("https://example.com/movies")

    response = response_info.value
    data = response.json()
    print(f"直接拿到了 API 返回的数据: {data}")

    # 然后再用 requests 去请求这个 API（无需浏览器）
    # 这是终极技巧：用 Playwright 拿到 API 的 Cookie/Token
    # 然后用 requests 模拟请求

    browser.close()
```

### 3.9 完整爬虫示例

```python
"""
用 Playwright 抓取需要 JavaScript 渲染的页面
场景：翻页列表，每页数据由 JS 动态加载
"""
from playwright.sync_api import sync_playwright
import json
import time


class PlaywrightCrawler:
    """基于 Playwright 的爬虫"""

    def __init__(self, headless=True):
        self.headless = headless
        self.all_data = []

    def start(self):
        """启动爬虫"""
        with sync_playwright() as p:
            # 启动浏览器
            browser = p.chromium.launch(headless=self.headless)
            context = browser.new_context(
                user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
                viewport={"width": 1920, "height": 1080},
            )

            # 注入反检测脚本
            context.add_init_script("""
                Object.defineProperty(navigator, 'webdriver', {
                    get: () => undefined
                });
            """)

            page = context.new_page()

            # 拦截 API 响应
            api_responses = []

            def on_response(response):
                if "api/list" in response.url:
                    data = response.json()
                    api_responses.append(data)

            page.on("response", on_response)

            # 访问页面
            page.goto("https://example.com/list", timeout=30000)

            # 等待列表加载
            page.wait_for_selector(".item-list", timeout=10000)

            # 翻页抓取
            for page_num in range(1, 6):
                print(f"正在抓取第 {page_num} 页...")

                # 等待当前页数据加载完成
                page.wait_for_load_state("networkidle")

                # 提取数据（直接从 DOM 取）
                items = page.evaluate("""
                    () => {
                        const items = document.querySelectorAll('.item');
                        return Array.from(items).map(item => ({
                            title: item.querySelector('.title')?.textContent?.trim(),
                            price: item.querySelector('.price')?.textContent?.trim(),
                        }));
                    }
                """)
                self.all_data.extend(items)

                # 翻页（点击下一页按钮）
                next_btn = page.locator(".next-page")
                if next_btn.is_disabled() or not next_btn.is_visible():
                    print("没有更多页了")
                    break

                next_btn.click()
                # 等待新页面加载
                page.wait_for_timeout(2000)

            browser.close()

        # 如果有拦截到的 API 数据，也可以合并
        if api_responses:
            self.all_data.extend(api_responses)

        return self.all_data

    def save(self, filename="playwright_results.json"):
        """保存结果"""
        with open(filename, "w", encoding="utf-8") as f:
            json.dump(self.all_data, f, ensure_ascii=False, indent=2)
        print(f"已保存 {len(self.all_data)} 条数据到 {filename}")


# 使用
# crawler = PlaywrightCrawler(headless=False)
# data = crawler.start()
# crawler.save()
```

### 4.4 Selenium 完整示例

```python
"""
Selenium 爬虫：抓取动态加载的列表
"""
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.chrome.options import Options
import json
import time


class SeleniumCrawler:
    def __init__(self, headless=True):
        options = Options()
        if headless:
            options.add_argument("--headless=new")  # 无头模式
        options.add_argument("--disable-blink-features=AutomationControlled")
        options.add_experimental_option("excludeSwitches", ["enable-automation"])

        self.driver = webdriver.Chrome(options=options)
        self.wait = WebDriverWait(self.driver, 10)

    def fetch_page(self, url):
        """请求页面"""
        self.driver.get(url)
        # 等待某个关键元素出现
        self.wait.until(EC.presence_of_element_located((By.CLASS_NAME, "item")))
        # 可能需要滚动来触发懒加载
        self.driver.execute_script("window.scrollTo(0, document.body.scrollHeight)")
        time.sleep(1)  # 等图片懒加载
        return self.driver.page_source

    def parse(self):
        """解析数据"""
        items = self.driver.find_elements(By.CLASS_NAME, "item")
        data = []
        for item in items:
            title = item.find_element(By.CLASS_NAME, "title").text
            price = item.find_element(By.CLASS_NAME, "price").text
            data.append({"title": title, "price": price})
        return data

    def run(self, url):
        html = self.fetch_page(url)
        data = self.parse()
        self.driver.quit()
        return data

# crawler = SeleniumCrawler(headless=True)
# result = crawler.run("https://example.com/list")
```

| 特性 | requests | Playwright | Selenium |

| **执行 JS** | ❌ 不能 | ✅ 能 | ✅ 能 |
| **速度** | ⚡⚡⚡ 最快 | ⚡⚡ 较快 | ⚡ 较慢 |
| **资源占用** | 极小 | 较大 | 很大 |
| **安装复杂度** | `pip install` | `pip install` + 下载浏览器 | `pip install` + 下载驱动 |
| **API 设计** | 简洁 | 现代、优雅 | 较老、啰嗦 |
| **防屏蔽** | 依赖 Headers/Cookie | 强（自动等待 + 可注入脚本） | 弱（特征明显） |
| **异步支持** | ❌ | ✅ 原生异步 | ❌ |
| **适用场景** | 静态页面或已知 API | 动态页面 | 老项目维护 |

## 学习建议

1. **优先找 API**：能用 `requests` 搞定的，不要上浏览器。浏览器是"核武器"，杀鸡不用牛刀。
2. **Playwright 是现代首选**：新项目无脑选 Playwright，Selenium 了解基本概念就行。
3. **善用网络拦截**：Playwright 的网络拦截是杀手级功能，可以在浏览器跑页面时自动抓取 API 请求，拿到数据后转用 requests。
4. **headless=False 调试**：写脚本时先不隐藏浏览器，看着它操作能快速发现问题。
5. **Codegen 是效率神器**：复杂操作先用 `playwright codegen` 录制，再微调代码。
