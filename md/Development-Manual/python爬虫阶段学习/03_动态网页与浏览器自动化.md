## 阶段导语

现代网站大量使用 JavaScript 渲染页面内容，`requests` 返回的 HTML 仅含页面骨架，不包含目标数据。本阶段围绕两条主线展开：其一，通过浏览器抓包定位实际承载数据的 JSON 接口，继续使用轻量高效的 requests 完成抓取；其二，在接口不可直接复用时，使用 Playwright 或 Selenium 由程序操控真实浏览器完成渲染与交互。浏览器自动化是处理动态页面的兜底能力，也是后续高并发抓取与 JS 逆向阶段的基础。

## 1. 前端基础与 AJAX 原理

### 1.1 静态请求无法获取数据的原因

```html
<!-- 传统页面：数据直接写入 HTML -->
<div class="movie">流浪地球2</div>
<!-- requests 获取 HTML 后即可直接提取数据 -->

<!-- 现代页面：HTML 为空，数据由 JS 动态填充 -->
<div id="movie-list"></div>
<script>
    // 这段 JS 在浏览器中执行，动态加载数据
    fetch("/api/movies")
        .then(r => r.json())
        .then(data => {
            document.getElementById("movie-list").innerHTML =
                data.map(m => `<div>${m.title}</div>`).join("");
        });
</script>
<!-- requests 返回的 HTML 仅含 <div id="movie-list"></div>，不含数据 -->
```

对应两种解决路径：

1. **抓取 AJAX 接口**（优先方案）：定位浏览器背后调用的 API，直接请求 JSON 数据。
2. **浏览器自动化**（兜底方案）：使用 Playwright/Selenium 由程序操控真实浏览器完成渲染。

### 1.2 AJAX 概述

异步 JavaScript 请求（AJAX, Asynchronous JavaScript and XML）指网页在不重新加载整页的前提下，于后台向服务器请求并处理数据的技术。

```javascript
// 以下代码在浏览器中执行，理解原理即可，不要求掌握编写

// AJAX 的两种常见写法

// 方式 1：fetch API（现代浏览器）
fetch("https://api.example.com/movies?page=1")
    .then(response => response.json())
    .then(data => console.log(data));

// 方式 2：XMLHttpRequest（早期写法）
const xhr = new XMLHttpRequest();
xhr.open("GET", "https://api.example.com/movies?page=1");
xhr.onload = () => console.log(JSON.parse(xhr.responseText));
xhr.send();
```

**爬虫的核心思路**：与其驱动浏览器执行这些 JS，不如直接定位这个 API 地址，用 `requests` 请求原始 JSON 数据。

- **要点**：JavaScript 渲染页面的数据不在初始 HTML 中，而由前端脚本动态填充。
- **要点**：动态页面抓取存在两条路径——接口抓取优先，浏览器自动化兜底。
- **要点**：AJAX 的本质是浏览器在不刷新页面的情况下向后台接口发起异步数据请求。
- **要点**：能定位到 JSON 接口时，requests 方案在速度与资源占用上全面优于浏览器方案。

## 2. 浏览器抓包技巧

> 抓包即监控浏览器发出的全部网络请求，从中定位页面背后调用的 API。

### 2.1 Chrome DevTools Network 面板

开发者工具（DevTools, Developer Tools）的打开方式：

```text
按 F12（或右键 → 检查）→ 切换到 Network 面板
```

操作步骤：

```text
1. 打开 DevTools 的 Network 面板
2. 勾选 "Preserve log"（保留日志，页面跳转后请求记录不丢失）
3. 刷新页面或触发目标操作（搜索、翻页等）
4. 在请求列表中筛选 XHR / Fetch 类型请求（此类请求即 AJAX 调用）
5. 点击请求查看详情：
   - Headers：请求的 URL、方法、参数、Cookie
   - Preview / Response：返回的数据（通常为 JSON 格式）
   - Initiator：发起该请求的 JS 代码位置
```

### 2.2 用 Python 模拟 API 请求

```python
import requests

# 示例：DevTools 中定位到的 API
# 请求 URL: https://api.example.com/v1/movies?page=1&size=20
# 返回格式: JSON

# 使用 requests 复现该请求
headers = {
    "User-Agent": "Mozilla/5.0 ...",
    "Accept": "application/json",
    # 部分 API 要求特定的 Referer 或 Origin
    "Referer": "https://example.com/movies",
    # 某些 API 需要 Authorization Token
    # "Authorization": "Bearer eyJxxx..."
}

params = {
    "page": 1,
    "size": 20
}

response = requests.get(
    "https://api.example.com/v1/movies",
    headers=headers,
    params=params
)

# 响应为 JSON，直接解析
data = response.json()
for movie in data["data"]["list"]:
    print(movie["title"], movie["score"])
```

## 3. Playwright（首选方案）

### 3.1 Playwright 概述

Playwright 是微软开源的浏览器自动化工具，相比 Selenium 架构更新、执行更快、运行更稳定。

核心能力：

- 支持 Chromium、Firefox、Safari 三种浏览器内核
- 自动等待元素出现，无需手动 sleep
- 网络拦截（Network Interception）：可监控并修改请求与响应
- 支持 codegen 录制并生成操作脚本
- 原生支持异步编程模型

### 3.2 安装

```bash
pip install playwright
playwright install           # 安装浏览器内核（约 300MB）
playwright install chromium  # 仅安装 Chromium，速度更快
```

### 3.3 基本使用

```python
from playwright.sync_api import sync_playwright

# 最简示例：打开百度搜索
with sync_playwright() as p:
    # 启动浏览器（headless=False 时可见浏览器界面）
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()

    # 打开网页
    page.goto("https://www.baidu.com")

    # 截图
    page.screenshot(path="baidu.png")

    # 等待 3 秒便于观察页面行为
    page.wait_for_timeout(3000)

    browser.close()
```

### 3.4 核心操作

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    # 创建浏览器上下文（相当于一个独立的浏览器会话）
    context = browser.new_context()
    page = context.new_page()

    # 1. 页面导航
    page.goto("https://example.com")
    page.goto("https://example.com/login", timeout=30000)  # 超时 30 秒

    # 2. 元素定位（语法与 CSS 选择器一致）
    page.locator("#username")              # id="username"
    page.locator(".login-btn")             # class="login-btn"
    page.locator("input[name='password']") # input 标签 name="password"
    page.locator("button:has-text('登录')")  # 文本包含"登录"的按钮
    page.locator("//*[@id='list']/li[1]")  # 同样支持 XPath

    # 3. 模拟操作
    page.fill("#username", "admin")         # 输入文本（先清空再输入）
    page.type("#username", "admin")         # 模拟键盘逐字输入
    page.click(".login-btn")               # 点击
    page.dblclick(".item")                 # 双击
    page.check("#agree")                   # 勾选 checkbox
    page.select_option("#city", "北京")     # 选择下拉框

    # 4. 键盘操作
    page.keyboard.press("Enter")
    page.keyboard.press("Tab")
    page.keyboard.type("Hello")

    # 5. 滚动页面
    page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
    # 滚动至页面底部（触发懒加载）
    page.locator("#footer").scroll_into_view_if_needed()  # 滚动至元素可见

    # 6. 提取页面内容
    # 文本
    title = page.locator("h1").text_content()
    all_titles = page.locator(".item .title").all_text_contents()

    # 属性
    href = page.locator("a").get_attribute("href")

    # HTML
    html = page.locator("#content").inner_html()

    # 7. 等待元素
    # Playwright 会自动等待元素可见，特殊场景需显式等待
    page.wait_for_selector(".result")          # 等待元素出现
    page.wait_for_load_state("networkidle")    # 等待网络请求完成
    page.wait_for_timeout(2000)                # 固定等待 2 秒（不推荐）

    # 8. 执行 JS 代码
    result = page.evaluate("1 + 2")           # 在浏览器中执行 JS
    page.evaluate("window.scrollTo(0, 1000)")
    # 读取页面数据（绕过 HTML 解析）
    data = page.evaluate("JSON.parse(localStorage.getItem('movies'))")

    browser.close()
```

- **要点**：Playwright 通过 launch 启动浏览器，以 context/page 两级结构管理会话与页面。
- **要点**：元素定位统一使用 `locator()`，同时支持 CSS 选择器、文本匹配与 XPath。
- **要点**：内容提取分为文本（text_content）、属性（get_attribute）与 HTML（inner_html）三类。
- **要点**：`page.evaluate()` 可在浏览器上下文中执行 JS，直接从内存数据结构取数。

### 3.5 自动等待机制（Playwright 的核心机制）

```python
"""
Playwright 的核心特性：自动等待。
大多数操作会自动等待元素"可见、可用"后再执行，无需手动 sleep。
"""

# Playwright 的点击操作会依次等待：
# 1. 元素出现在 DOM 中
# 2. 元素可见（无 display:none / visibility:hidden）
# 3. 元素稳定（无进行中的动画）
# 4. 元素可接收事件（未被其他元素遮挡）
# 5. 元素处于启用状态（无 disabled 属性）

# 因此以下代码通常无需额外添加 sleep：
page.goto("https://example.com")
page.click("#submit")              # 自动等待按钮可见、可点击
page.wait_for_selector(".result")  # 自动等待结果出现
text = page.locator(".result").text_content()
```

### 3.6 网络拦截（Network Interception）

网络拦截（Network Interception）指在浏览器发出请求与接收响应的过程中进行监控、修改或阻断，是 Playwright 在爬虫场景中最有价值的能力之一。

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()

    # 拦截请求
    def handle_request(request):
        print(f"请求: {request.method} {request.url}")
        if "tracking" in request.url:
            # 拦截追踪请求，不再发送
            request.abort()
        elif "api/movies" in request.url:
            # 放行请求
            request.continue_()

    page.on("request", handle_request)

    # 拦截响应
    def handle_response(response):
        if "api/movies" in response.url:
            print(f"API 响应: {response.status}")
            data = response.json()
            print(f"电影数量: {len(data['data'])}")

    page.on("response", handle_response)

    page.goto("https://example.com/movies")
    page.wait_for_timeout(5000)
    browser.close()

# 更实用的方式：等待特定 API 响应
with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()

    # 监听 API 响应（需在触发操作之前注册）
    with page.expect_response(lambda r: "api/movies" in r.url) as response_info:
        page.goto("https://example.com/movies")

    response = response_info.value
    data = response.json()
    print(f"直接获取到 API 返回的数据: {data}")

    # 之后可用 requests 请求该 API（无需浏览器）
    # 一种高效模式：用 Playwright 获取 API 所需的 Cookie/Token
    # 再交由 requests 复现请求

    browser.close()
```

### 3.7 规避自动化特征检测的实践

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    # 1. 修改浏览器启动参数
    browser = p.chromium.launch(
        headless=False,
        args=[
            "--disable-blink-features=AutomationControlled",  # 移除自动化标记
        ]
    )

    # 2. 通过上下文配置覆盖浏览器特征
    context = browser.new_context(
        viewport={"width": 1920, "height": 1080},  # 设置窗口尺寸
        user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    )

    page = context.new_page()

    # 3. 在页面加载前执行 JS，覆盖 webdriver 属性
    page.add_init_script("""
        // 隐藏 WebDriver 特征
        Object.defineProperty(navigator, 'webdriver', {
            get: () => undefined
        });
        // 补齐 Chrome 特征
        window.chrome = {
            runtime: {},
            loadTimes: function() {},
            csi: function() {},
            app: {}
        };
    """)

    page.goto("https://bot.sannysoft.com/")  # 用于验证反爬检测效果的测试网站
    page.wait_for_timeout(5000)
    browser.close()
```

### 3.9 完整爬虫示例

```python
"""
使用 Playwright 抓取需要 JavaScript 渲染的页面
场景：翻页列表，每页数据由 JS 动态加载
"""
from playwright.sync_api import sync_playwright
import json
import time


class PlaywrightCrawler:
    """基于 Playwright 的爬虫"""

    def __init__(self, headless=True):
        self.headless = headless
        self.all_data = []

    def start(self):
        """启动爬虫"""
        with sync_playwright() as p:
            # 启动浏览器
            browser = p.chromium.launch(headless=self.headless)
            context = browser.new_context(
                user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
                viewport={"width": 1920, "height": 1080},
            )

            # 注入反检测脚本
            context.add_init_script("""
                Object.defineProperty(navigator, 'webdriver', {
                    get: () => undefined
                });
            """)

            page = context.new_page()

            # 拦截 API 响应
            api_responses = []

            def on_response(response):
                if "api/list" in response.url:
                    data = response.json()
                    api_responses.append(data)

            page.on("response", on_response)

            # 访问页面
            page.goto("https://example.com/list", timeout=30000)

            # 等待列表加载
            page.wait_for_selector(".item-list", timeout=10000)

            # 翻页抓取
            for page_num in range(1, 6):
                print(f"正在抓取第 {page_num} 页...")

                # 等待当前页数据加载完成
                page.wait_for_load_state("networkidle")

                # 提取数据（直接从 DOM 读取）
                items = page.evaluate("""
                    () => {
                        const items = document.querySelectorAll('.item');
                        return Array.from(items).map(item => ({
                            title: item.querySelector('.title')?.textContent?.trim(),
                            price: item.querySelector('.price')?.textContent?.trim(),
                        }));
                    }
                """)
                self.all_data.extend(items)

                # 翻页（点击下一页按钮）
                next_btn = page.locator(".next-page")
                if next_btn.is_disabled() or not next_btn.is_visible():
                    print("没有更多页了")
                    break

                next_btn.click()
                # 等待新页面加载
                page.wait_for_timeout(2000)

            browser.close()

        # 若拦截到 API 数据，可一并合并
        if api_responses:
            self.all_data.extend(api_responses)

        return self.all_data

    def save(self, filename="playwright_results.json"):
        """保存结果"""
        with open(filename, "w", encoding="utf-8") as f:
            json.dump(self.all_data, f, ensure_ascii=False, indent=2)
        print(f"已保存 {len(self.all_data)} 条数据到 {filename}")


# 使用
# crawler = PlaywrightCrawler(headless=False)
# data = crawler.start()
# crawler.save()
```

- **要点**：自动等待覆盖元素出现、可见、稳定、可交互等条件，可替代大部分手动等待。
- **要点**：`page.expect_response()` 配合 `page.on("response")` 可直接捕获 API 返回的 JSON 数据。
- **要点**：规避自动化特征检测需组合启动参数、上下文配置与初始化脚本三层手段。
- **要点**：codegen 录制可快速生成操作原型，再人工调整选择器与等待逻辑即可投产。
- **要点**：完整爬虫可将 DOM 提取与 API 拦截两种取数方式结合，提高数据完整性。

### 4.2 基本使用

```python

from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
```

### 4.4 Selenium 完整示例

```python
"""
Selenium 爬虫：抓取动态加载的列表
"""
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.chrome.options import Options
import json
import time


class SeleniumCrawler:
    def __init__(self, headless=True):
        options = Options()
        if headless:
            options.add_argument("--headless=new")  # 无头模式
        options.add_argument("--disable-blink-features=AutomationControlled")
        options.add_experimental_option("excludeSwitches", ["enable-automation"])

        self.driver = webdriver.Chrome(options=options)
        self.wait = WebDriverWait(self.driver, 10)

    def fetch_page(self, url):
        """请求页面"""
        self.driver.get(url)
        # 等待关键元素出现
        self.wait.until(EC.presence_of_element_located((By.CLASS_NAME, "item")))
        # 滚动页面以触发懒加载
        self.driver.execute_script("window.scrollTo(0, document.body.scrollHeight)")
        time.sleep(1)  # 等待图片懒加载
        return self.driver.page_source

    def parse(self):
        """解析数据"""
        items = self.driver.find_elements(By.CLASS_NAME, "item")
        data = []
        for item in items:
            title = item.find_element(By.CLASS_NAME, "title").text
            price = item.find_element(By.CLASS_NAME, "price").text
            data.append({"title": title, "price": price})
        return data

    def run(self, url):
        html = self.fetch_page(url)
        data = self.parse()
        self.driver.quit()
        return data


# 使用
# crawler = SeleniumCrawler(headless=True)
# result = crawler.run("https://example.com/list")
```

- **要点**：Selenium 基于 WebDriver 协议工作，需浏览器驱动进程配合，API 风格较为传统。
- **要点**：等待方式分为强制等待、隐式等待与显式等待三种，推荐针对特定元素的显式等待。
- **要点**：Options 配置与 CDP 命令注入可隐藏部分自动化特征，但整体对抗能力弱于 Playwright。
- **要点**：`driver.page_source` 返回渲染后的完整 HTML，可交由解析库处理。

## 5. 工具对比与选型

| 维度 | requests | Playwright | Selenium |
|------|----------|------------|----------|
| **请求能力** | 直接构造并发送 HTTP 请求 | 通过真实浏览器发出请求，可拦截复用 | 通过真实浏览器发出请求 |
| **JS 渲染** | 不支持 | 支持 | 支持 |
| **速度** | 最快 | 较快 | 较慢 |
| **资源占用** | 极小 | 较大 | 很大 |
| **异步支持** | 不支持（需借助并发库） | 原生支持异步 | 不支持 |
| **反检测能力** | 依赖 Headers/Cookie 配置 | 强（自动等待 + 可注入脚本） | 弱（自动化特征明显） |
| **适用场景** | 静态页面或已定位的 API | 动态渲染页面、新项目首选 | 老项目维护、特定 IE 支持 |

补充维度（结论保留）：安装复杂度方面，requests 仅需 `pip install`，Playwright 需额外下载浏览器内核，Selenium 需额外管理浏览器驱动；API 设计方面，requests 简洁，Playwright 现代，Selenium 相对陈旧且冗长。

## 6. 学习建议

1. **优先定位 API**：可由 `requests` 完成的抓取任务不启用浏览器自动化，浏览器方案应作为兜底手段。
2. **Playwright 为现代首选**：新项目优先选择 Playwright，Selenium 了解基本概念即可。
3. **善用网络拦截**：网络拦截是 Playwright 的核心能力，可在浏览器渲染页面时自动捕获 API 请求，取得数据后转由 requests 抓取。
4. **headless=False 调试**：脚本开发阶段保持浏览器界面可见，观察操作过程可快速定位问题。
5. **Codegen 提升效率**：复杂操作流程先用 `playwright codegen` 录制生成原型，再人工调整代码。

- **要点**：动态页面抓取的标准工作流为"先找接口、再自动化、最后评估是否转回 requests"。
- **要点**：调试期使用可视化浏览器与录制工具，投产前再切换为无头模式与精修脚本。

## 阶段小结

| 知识模块 | 核心要点 | 在爬虫中的作用 |
|----------|----------|----------------|
| AJAX 与动态渲染 | 数据由 JS 异步请求后填充，不在初始 HTML 中 | 判断静态请求失败的根本原因，确定抓取路线 |
| 浏览器抓包 | DevTools Network 面板筛选 XHR/Fetch 请求，查看 Headers/Response/Initiator | 定位实际承载数据的 JSON 接口，实现 requests 直接抓取 |
| Playwright 基本操作 | goto、locator、fill/click、text_content 等 API 覆盖导航、交互与取数 | 渲染动态页面并从 DOM 提取内容 |
| Playwright 自动等待 | 操作前自动校验元素出现、可见、稳定、可交互 | 消除手动 sleep，提高脚本稳定性 |
| 网络拦截（Network Interception） | page.on 与 expect_response 捕获请求与响应 | 直接获取 API 的 JSON 数据及 Cookie/Token，转回 requests 抓取 |
| 规避自动化特征检测 | 启动参数、上下文配置与初始化脚本组合隐藏 webdriver 特征 | 降低被网站识别为自动化程序的概率 |
| Selenium 基础 | 三种等待方式与 find_element 定位体系 | 维护存量项目，理解浏览器自动化的通用概念 |
| 工具选型 | requests 优先，Playwright 首选自动化方案，Selenium 用于维护 | 按页面特征与项目约束确定抓取技术栈 |

## 常见问题与排查

| 现象 | 原因 | 处理方式 |
|------|------|----------|
| 元素定位失败或操作超时 | 元素由 JS 延迟渲染，或选择器与实际 DOM 不一致 | 先 `wait_for_selector` 等待元素出现；在 DevTools 中核对渲染后的 DOM；优先使用稳定属性定位 |
| 页面未渲染完成，抓取结果为空 | `goto` 默认仅等待 load 事件，数据请求尚未返回 | 使用 `wait_for_load_state("networkidle")` 或等待关键元素、目标 API 响应 |
| 被网站检测为自动化程序并拦截 | `navigator.webdriver` 等自动化特征暴露 | 添加 `--disable-blink-features=AutomationControlled` 启动参数，注入 init script 覆盖特征，调试期使用 headless=False 与真实窗口尺寸 |
| `response.json()` 解析报错 | 响应并非合法 JSON，或状态码异常返回错误页 | 先检查 `response.status` 与 `response.text` 原文，核对请求头与参数 |
| API 含 sign/token 参数无法复现 | 参数由前端 JS 加密逻辑生成 | 通过 Initiator 定位加密代码位置，进入第六阶段 JS 逆向处理 |
| Playwright 启动提示找不到浏览器 | 浏览器内核未安装 | 执行 `playwright install chromium` 安装对应内核 |
