## 1. 并发理论基础

### 1.1 进程 vs 线程 vs 协程

```python
"""
用一个餐厅的比喻来理解：
─────────────────────────────────────────
进程 = 一个厨房
线程 = 厨房里的一个厨师
协程 = 一个厨师同时照看多个灶台

进程：每个进程有自己的厨房、自己的厨具、互不干扰
      → 适合 CPU 密集型任务（计算、编解码）

线程：同一个厨房里多个厨师，共享厨具和食材
      → 适合 IO 密集型任务（网络请求、文件读写）
      → 但 Python 有 GIL 限制

协程：一个厨师在不同灶台间切换，哪个菜好了就去处理哪个
      → 单线程内实现并发，开销最小
      → 适合大量 IO 等待的任务（爬虫天然适合）
"""

# ── 代码层面的区别 ──
# 进程：完全独立，各有各的内存
# 线程：共享内存，需要注意数据竞争
# 协程：单线程内切换，不涉及系统调度，最轻量
```

### 1.2 IO 密集型 vs CPU 密集型

```python
import time

# ── IO 密集型（爬虫属于这一类）──
# 大部分时间在等待网络响应、磁盘读写
# CPU 很闲，瓶颈在 IO 速度

def io_task():
    time.sleep(1)  # 模拟网络请求（1 秒都在等）
    return "数据"

# 串行执行 10 次 → 10 秒
# 并发执行 10 次 → 约 1 秒（同时发请求）

# ── CPU 密集型（视频编码、科学计算）──
# 大部分时间在计算，CPU 满载

def cpu_task():
    total = 0
    for i in range(10**7):
        total += i
    return total

# 串行执行 → 多核也只用一核
# 多进程执行 → 每个进程跑在不同核上，更快
```

### 1.3 GIL（全局解释器锁）

```python
"""
GIL = Global Interpreter Lock（全局解释器锁）

简单理解：Python 解释器同一时刻只能执行一个线程。
所以多线程在 CPU 密集型任务上**没有加速效果**。

但在 IO 密集型任务上，线程在等待 IO 时会释放 GIL，
其他线程可以趁机执行 → 所以爬虫用多线程仍然有效。
"""
```

### 1.4 同步 vs 异步

```python
"""
同步：做一件事，做完再做下一件事
     排队打饭 → 一个人打好，下一个人再打

异步：同时发起多件事，哪个好了处理哪个
     叫号取餐 → 同时点好几份，哪个好了去拿哪个
"""
```

## 2. 多线程与线程池

### 2.1 threading 基础

```python
import threading
import time

# ── 创建和启动线程 ──
def fetch_url(url):
    print(f"开始请求: {url}")
    time.sleep(2)  # 模拟网络请求
    print(f"完成请求: {url}")

# 创建两个线程
t1 = threading.Thread(target=fetch_url, args=("https://a.com",))
t2 = threading.Thread(target=fetch_url, args=("https://b.com",))

# 启动线程
t1.start()
t2.start()

# 等待线程结束
t1.join()  # 阻塞到 t1 完成
t2.join()

print("全部完成")
# 耗时约 2 秒（而不是 4 秒）
```

### 2.2 线程锁（Lock）

```python
import threading

# ── 为什么需要锁？──
# 多个线程同时修改同一个变量 → 数据错乱

counter = 0

def increment():
    global counter
    for _ in range(100000):
        counter += 1  # 这里不是原子操作！多线程同时执行会出问题

threads = [threading.Thread(target=increment) for _ in range(10)]
for t in threads:
    t.start()
for t in threads:
    t.join()

print(counter)  # 结果不到 1000000！因为数据竞争

# ── 用锁解决 ──
counter = 0
lock = threading.Lock()

def safe_increment():
    global counter
    for _ in range(100000):
        with lock:  # 同一时间只有一个线程能进入
            counter += 1

threads = [threading.Thread(target=safe_increment) for _ in range(10)]
for t in threads:
    t.start()
for t in threads:
    t.join()

print(counter)  # 1000000，正确！

# ── 爬虫实战：线程安全的 URL 队列 ──
import queue

q = queue.Queue()  # 线程安全的队列
q.put("https://example.com/page/1")
q.put("https://example.com/page/2")
q.put("https://example.com/page/3")

def worker():
    while not q.empty():
        url = q.get()
        print(f"处理: {url}")
        time.sleep(1)
        q.task_done()  # 标记任务完成

threads = [threading.Thread(target=worker) for _ in range(3)]
for t in threads:
    t.start()
q.join()  # 等待所有任务完成
print("所有 URL 处理完毕")
```

### 2.3 ThreadPoolExecutor（推荐！）

> 手动管理线程很麻烦。用线程池：把任务扔进去，线程池帮你分配线程。

```python
from concurrent.futures import ThreadPoolExecutor, as_completed
import time


# ── 基本用法 ──
def fetch(url):
    print(f"请求: {url}")
    time.sleep(2)
    return f"{url} 的结果"


urls = [
    "https://a.com",
    "https://b.com",
    "https://c.com",
    "https://d.com",
    "https://e.com",
]

# 创建线程池（最大 3 个线程同时执行）
with ThreadPoolExecutor(max_workers=3) as executor:
    # 方法 1：submit 提交单个任务（返回 Future 对象）
    futures = [executor.submit(fetch, url) for url in urls]

    for future in as_completed(futures):  # 按完成的顺序返回
        result = future.result()
        print(f"拿到结果: {result}")

print("全部完成！")

# ── 方法 2：map（更简洁，按传入顺序返回）──
with ThreadPoolExecutor(max_workers=3) as executor:
    results = executor.map(fetch, urls)
    for result in results:
        print(f"结果: {result}")
```

### 2.4 爬虫实战：多线程加速

```python
"""
多线程爬虫：同时抓取多个页面
"""
from concurrent.futures import ThreadPoolExecutor, as_completed
import requests
import time


class ThreadPoolCrawler:
    """线程池爬虫"""

    def __init__(self, max_workers=5, timeout=10):
        self.max_workers = max_workers
        self.timeout = timeout
        self.session = requests.Session()
        self.session.headers.update({
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
        })

    def fetch_one(self, url):
        """请求单个 URL"""
        try:
            start = time.time()
            resp = self.session.get(url, timeout=self.timeout)
            elapsed = time.time() - start
            return {
                "url": url,
                "status": resp.status_code,
                "size": len(resp.text),
                "time": round(elapsed, 2)
            }
        except Exception as e:
            return {"url": url, "error": str(e)}

    def fetch_many(self, urls):
        """并发请求多个 URL"""
        results = []
        start = time.time()

        with ThreadPoolExecutor(max_workers=self.max_workers) as executor:
            # 提交所有任务
            future_to_url = {executor.submit(self.fetch_one, url): url for url in urls}

            # 按完成顺序收集结果
            for future in as_completed(future_to_url):
                result = future.result()
                results.append(result)
                # 实时打印进度
                status = result.get("status", "ERROR")
                print(f"[{status}] {result['url']} ({result.get('time', '?')}s)")

        total_time = time.time() - start
        print(f"\n共 {len(urls)} 个请求，耗时 {total_time:.2f} 秒")
        print(f"平均每秒 {len(urls)/total_time:.1f} 个请求")

        return results


# 使用
# crawler = ThreadPoolCrawler(max_workers=10)
# urls = [f"https://example.com/page/{i}" for i in range(1, 51)]
# results = crawler.fetch_many(urls)
```

## 3. 多进程与进程池

### 3.1 什么时候用多进程？

```python
"""
多进程适合：CPU 密集型任务（大量计算、编解码、压缩）

爬虫中的应用场景：
1. 对抓取到的数据进行大量处理（如图片处理、数据清洗）
2. 爬虫需要执行 CPU 密集型操作（如解密、破解）
3. 需要绕过 GIL 限制，充分利用多核 CPU

对于纯网络请求的爬虫，多线程就够了，不需要多进程。
"""
```

### 3.2 multiprocessing 基础

```python
from multiprocessing import Process
import time

def work(name):
    print(f"进程 {name} 开始工作")
    time.sleep(2)
    print(f"进程 {name} 完成")

# 创建多进程（和多线程很像）
processes = []
for i in range(4):
    p = Process(target=work, args=(i,))
    processes.append(p)
    p.start()

for p in processes:
    p.join()

print("所有进程完成")
```

### 3.3 进程间通信（Queue）

```python
from multiprocessing import Process, Queue

# 进程不共享内存，需要用 Queue 传递数据

def producer(q):
    """生产者：往队列放数据"""
    for i in range(10):
        q.put(f"数据 {i}")
    q.put(None)  # 结束信号

def consumer(q):
    """消费者：从队列取数据"""
    while True:
        data = q.get()
        if data is None:
            break
        print(f"消费: {data}")

q = Queue()
p1 = Process(target=producer, args=(q,))
p2 = Process(target=consumer, args=(q,))

p1.start()
p2.start()
p1.join()
p2.join()
```

### 3.4 ProcessPoolExecutor

```python
from concurrent.futures import ProcessPoolExecutor
import time

# CPU 密集型任务
def cpu_heavy(n):
    total = 0
    for i in range(10**7):
        total += i
    return f"任务 {n} 完成，结果={total}"

# 多进程执行（利用多核 CPU）
with ProcessPoolExecutor(max_workers=4) as executor:
    results = executor.map(cpu_heavy, range(8))
    for r in results:
        print(r)

# ── 爬虫中的混合使用 ──
# 先用多线程抓取，再用多进程处理

def fetch_data(url):
    time.sleep(1)
    return f"{url} 的原始数据（很大）"

def process_data(data):
    """CPU 密集型处理（如解密、解压）"""
    time.sleep(2)  # 模拟耗时计算
    return f"处理后的: {data}"

# 阶段 1：多线程抓取
from concurrent.futures import ThreadPoolExecutor
urls = [f"https://page/{i}" for i in range(20)]

with ThreadPoolExecutor(max_workers=10) as executor:
    raw_data = list(executor.map(fetch_data, urls))

# 阶段 2：多进程处理
with ProcessPoolExecutor(max_workers=4) as executor:
    processed = list(executor.map(process_data, raw_data))

print(f"处理完成 {len(processed)} 条数据")
```

## 4. 异步协程（asyncio + aiohttp）

> **这是爬虫高性能的终极方案**。单线程内实现并发，开销最小、速度最快。

### 4.1 核心概念

```python
"""
async / await 是 Python 3.5+ 的关键字

async def：定义一个协程函数（可以理解为一个"可暂停的函数"）
await：暂停当前协程，等待某个操作完成

事件循环（Event Loop）：调度协程的"调度员"
  - 管理所有协程
  - 当协程遇到 await 时，把它挂起，去执行其他协程
  - 等 await 的结果回来了，再继续执行

类比：
  你去快餐店点餐
  - 同步：点完餐，站在柜台前等 5 分钟，拿到餐再走
  - 异步：点完餐，拿个叫号器去旁边坐着，号码响了再去取
  - await = "我去坐着等了，好了叫我"
  - 事件循环 = "叫号系统"
"""
```

### 4.2 基础语法

```python
import asyncio


# ── 定义协程 ──
async def say_hello():
    print("你好")
    await asyncio.sleep(1)  # 模拟等待（不阻塞）
    print("世界")

# ── 运行协程 ──
# asyncio.run(say_hello())  # 在事件循环中运行

# ── 用 asyncio.gather 并发执行 ──
async def fetch_one(n):
    print(f"开始任务 {n}")
    await asyncio.sleep(1)  # 模拟网络请求
    print(f"完成 {n}")
    return f"结果 {n}"

async def main():
    # 并发执行 5 个任务（耗时约 1 秒，不是 5 秒）
    tasks = [fetch_one(i) for i in range(5)]
    results = await asyncio.gather(*tasks)
    print(results)

# asyncio.run(main())

# ── 用 asyncio.create_task 创建任务 ──
async def main2():
    # create_task 创建后台任务
    task1 = asyncio.create_task(fetch_one(1))
    task2 = asyncio.create_task(fetch_one(2))

    # 等待所有任务完成
    r1 = await task1
    r2 = await task2
    print(r1, r2)
```

```python
import asyncio
import aiohttp


# ── 基本用法 ──
async def fetch(session, url):
    """单个请求"""
    async with session.get(url) as response:
        return await response.text()


async def main():
    # 创建 ClientSession（类似 requests.Session）
    async with aiohttp.ClientSession() as session:
        html = await fetch(session, "https://example.com")
        print(f"获取到 {len(html)} 字节")


# asyncio.run(main())

# ── 并发请求 ──
async def fetch_json(session, url):
    try:
        async with session.get(url, timeout=aiohttp.ClientTimeout(total=10)) as resp:
            if resp.status == 200:
                return await resp.json()
            else:
                return {"error": f"状态码 {resp.status}"}
    except Exception as e:
        return {"error": str(e)}


async def fetch_all(urls):
    """并发请求所有 URL"""
    # 设置 Headers 和超时
    headers = {"User-Agent": "Mozilla/5.0"}
    timeout = aiohttp.ClientTimeout(total=10)

    # 连接限制（避免把服务器搞崩）
    connector = aiohttp.TCPConnector(
        limit=10,          # 总并发连接数
        limit_per_host=5,  # 同一主机的并发数
    )

    async with aiohttp.ClientSession(
        headers=headers,
        timeout=timeout,
        connector=connector,
    ) as session:
        tasks = [fetch_json(session, url) for url in urls]
        results = await asyncio.gather(*tasks)
        return results
```

### 4.4 限制并发量（Semaphore）

```python
"""
如果不限制并发，一下子发 1000 个请求，会被网站封 IP。
Semaphore（信号量）用来控制同时执行的协程数量。
"""
import asyncio
import aiohttp


class RateLimitedCrawler:
    """带并发限制的异步爬虫"""

    def __init__(self, max_concurrent=10):
        self.max_concurrent = max_concurrent
        self.semaphore = asyncio.Semaphore(max_concurrent)
        self.results = []

    async def fetch_one(self, session, url):
        """带并发限制的请求"""
        async with self.semaphore:  # 超过 max_concurrent 会等待
            try:
                print(f"请求: {url}")
                async with session.get(url, timeout=aiohttp.ClientTimeout(total=10)) as resp:
                    text = await resp.text()
                    self.results.append({
                        "url": url,
                        "status": resp.status,
                        "size": len(text),
                    })
                    return resp.status
            except Exception as e:
                print(f"失败: {url} - {e}")
                return None

    async def run(self, urls):
        headers = {"User-Agent": "Mozilla/5.0"}
        connector = aiohttp.TCPConnector(limit=self.max_concurrent)

        async with aiohttp.ClientSession(
            headers=headers,
            connector=connector,
        ) as session:
            tasks = [self.fetch_one(session, url) for url in urls]
            await asyncio.gather(*tasks)

        return self.results


# 使用
# crawler = RateLimitedCrawler(max_concurrent=10)
# urls = [f"https://example.com/page/{i}" for i in range(100)]
# results = asyncio.run(crawler.run(urls))
```

### 4.5 带重试和超时的完整异步爬虫

```python
"""
一个完整的异步爬虫：并发 + 重试 + 限速 + 错误处理
"""
import asyncio
import aiohttp
from typing import List, Dict, Any
import json


class AsyncCrawler:
    """异步爬虫"""

    def __init__(self, max_concurrent=10, retries=3):
        self.max_concurrent = max_concurrent
        self.retries = retries
        self.semaphore = asyncio.Semaphore(max_concurrent)

    async def fetch(
        self,
        session: aiohttp.ClientSession,
        url: str,
        **kwargs
    ) -> Dict[str, Any]:
        """带重试的请求"""
        last_error = None

        for attempt in range(1, self.retries + 1):
            async with self.semaphore:
                try:
                    async with session.get(url, **kwargs) as resp:
                        text = await resp.text()
                        return {
                            "url": url,
                            "status": resp.status,
                            "content": text,
                            "attempt": attempt,
                        }
                except asyncio.TimeoutError:
                    last_error = "超时"
                    print(f"超时 (第{attempt}次): {url}")
                except aiohttp.ClientError as e:
                    last_error = str(e)
                    print(f"请求失败 (第{attempt}次): {url} - {e}")

                if attempt < self.retries:
                    wait = attempt * 2  # 递增等待：2s, 4s, 6s
                    await asyncio.sleep(wait)

        return {
            "url": url,
            "status": 0,
            "content": None,
            "error": last_error,
            "attempt": self.retries,
        }

    async def run(self, urls: List[str]) -> List[Dict[str, Any]]:
        """并发抓取所有 URL"""
        headers = {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
        }
        timeout = aiohttp.ClientTimeout(total=30)
        connector = aiohttp.TCPConnector(limit=self.max_concurrent)

        async with aiohttp.ClientSession(
            headers=headers,
            timeout=timeout,
            connector=connector,
        ) as session:
            tasks = [self.fetch(session, url) for url in urls]
            results = await asyncio.gather(*tasks)

        return results

    def save(self, results, filename="async_results.json"):
        """保存结果"""
        with open(filename, "w", encoding="utf-8") as f:
            json.dump(results, f, ensure_ascii=False, indent=2)
        success = sum(1 for r in results if r["status"] == 200)
        print(f"成功 {success}/{len(results)}，已保存到 {filename}")


# ── 使用 ──
async def main():
    crawler = AsyncCrawler(max_concurrent=20, retries=3)
    urls = [f"https://example.com/page/{i}" for i in range(50)]
    results = await crawler.run(urls)
    crawler.save(results)


# asyncio.run(main())
```

## 5. 三种方案对比与选型

| 特性 | 多线程 (ThreadPoolExecutor) | 多进程 (ProcessPoolExecutor) | 协程 (asyncio + aiohttp) |
|------|---------------------------|----------------------------|------------------------|
| **适用任务** | IO 密集型 | CPU 密集型 | IO 密集型 |
| **内存占用** | 中等（共享内存） | 高（每个进程独立内存） | **极低** |
| **并发数量** | 几十 ~ 几百 | 取决于 CPU 核心数 | **成千上万** |
| **代码复杂度** | 简单 | 简单 | 中等（需要理解 async） |
| **是否受 GIL 影响** | 是（IO 时释放） | 否（每个进程独立解释器） | 否（单线程） |
| **速度（爬虫场景）** | 快 | 浪费（IO 等待不占 CPU） | **最快** |
| **第三方库支持** | 所有库都支持 | 所有库都支持 | 需要异步版库 |

### 爬虫选型建议

```python
"""
根据你的场景选择：

┌───────────────────────────────────────────────────────────┐
│  少量 URL（< 100 个）                                      │
│  ├─ 用 requests + ThreadPoolExecutor（最简单，够用）        │
│                                                           │
│  大量 URL（> 1000 个）                                     │
│  └─ 用 asyncio + aiohttp（性能最优）                       │
│                                                           │
│  需要密集计算（解密、解压、图像处理）                         │
│  └─ 用 ProcessPoolExecutor                                │
└───────────────────────────────────────────────────────────┘

最佳实践：
  1. 先用 requests + 多线程 上手（最简单）
  2. 等需要性能优化时，换成 asyncio + aiohttp
  3. 只有在需要 CPU 密集型处理时才上多进程
"""
```

## 学习建议

1. **不要过早优化**：如果你只抓几十个页面，单线程就够了。并发是"遇到了瓶颈再去解决问题"。
2. **多线程先从 ThreadPoolExecutor 开始**：别自己造轮子管理线程，用 `concurrent.futures` 简单安全。
3. **协程是最终方案**：`asyncio + aiohttp` 是爬虫性能的终极答案，但学习曲线略陡，可以在第五阶段（Scrapy）之后再深入理解，因为 Scrapy 底层就是协程。
4. **务必限制并发**：无论是多线程还是协程，都要控制并发数量。并发 100 个请求足够把小型网站打挂，你的 IP 也会被封。
5. **"礼貌"爬虫**：设置请求间隔、控制并发数、遵守 `robots.txt`，这是爬虫工程师的基本素养。
