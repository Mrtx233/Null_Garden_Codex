# Null Garden

Null Garden is a personal blog for long-term notes about technical learning, AI tools, project practice, product thinking, and personal observations.

## Tech Stack

- Astro
- TypeScript
- Markdown
- Astro Content Collections
- Native CSS

## Scripts

```bash
npm run dev
npm run build
npm run preview
```

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`
